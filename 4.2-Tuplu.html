Ce este un tuplu în Python? - What Is a Python Tuple?

Tuples and Sequences

Python Tuples

Un tuplu Python este un tip de date încorporat, utilizat pentru a stoca o colecție de elemente într-o ordine specifică, ce nu poate fi modificată după creare. Poate fi comparat cu o listă a cărei structură este fixă ​​și imuabilă.

Caracteristici principale:
Imuabilitate: nu poți adăuga, elimina sau modifica elemente după ce tuplul a fost creat.
Ordonare: elementele au o ordine definită care nu se schimbă, iar accesarea începând de la indicelui 0.
Permite duplicate: același element poate apărea de mai multe ori în cadrul secvenței.
Heterogenitate: poate conține simultan o combinație de tipuri de date diferite (șiruri de caractere, numere întregi, valori booleene sau chiar liste).

A Python tuple is a built-in data type used to store a collection of items in a specific order that cannot be changed after it is created. Compare with a list that is permanently locked in place.

Core Characteristics
Immutable: You cannot add, remove, or modify items once the tuple is made.
Ordered: Items have a defined order that will not change, and you look them up by index (starting at 0).
Allows Duplicates: The same item can appear multiple times within the sequence.
Heterogeneous: It can hold a mix of different data types (strings, integers, booleans, or even lists) at the same time.

Atribuire tupluri(despachetare) - Tuple Assignment(unpacking)

Atribuirea de tupluri (despachetare a tuplurilor sau atribuire paralelă) permite atribuirea unui tuplu de valori unui tuplu de variabile într-o singură linie de cod. Python evaluează întreaga parte dreaptă înainte de a modifica vreo variabilă din partea stângă, ceea ce previne conflictele de atribuire.

Tuple assignment (tuple unpacking or parallel assignment) allows you to assign a tuple of values to a tuple of variables in a single line of code. Python evaluates the entire right side before modifying any variables on the left side, which prevents assignment conflicts

# Cu paranteze
(nume, vârstă, profesie) = ("Linda", 59, "artistă")

# Fără paranteze
nume, vârstă, profesie = "Linda", 59, "artistă"
print(f"{nume} are {vârstă} de ani şi este o {profesie} apreciată.")
==> Linda are 59 de ani şi este o artistă apreciată.

# Tuplul de despachetat
artistă = ("Linda", 28, "Artistă")

# Despachetarea în variabile individuale
nume, vârstă, profesie = artistă

print(nume, vârstă, profesie) ==> Linda 28 Artistă

La despachetare, numărul de variabile din partea stângă trebuie să corespundă numărului de valori din tuplu. În caz contrar, codul generează o eroare.

Pentru a intercepta o eroare în Python atunci când despachetezi un tuplu cu un număr nepotrivit de elemente, folosește un bloc try si except.

When unpacking, the number of variables on the left must match the number of values in the tuple. Otherwise, the code generates an error.

To catch an Error in Python when unpacking a tuple with a mismatched size, use a try and except block.

Indexarea și felierea unui tuplu - Indexing and Slicing a Tuple

Python - Access Tuple Items

Extragerea unei secvențe dintr-un tuplu este la fel de simplă ca extragerea unei secvențe dintr-un șir de caractere sau dintr-o listă Python, respectând aceleași reguli. Pentru a accesa elementele dintr-un tuplu Python, introduceți indicele între paranteze pătrate ([]) imediat după numele tuplului. Python utilizează indexarea bazată pe zero, ceea ce înseamnă că primul element se află la indicele 0.

Slicing a tuple is as simple as slicing a Python string or a list with the same rules. To access items in a Python tuple, pass the index number inside square brackets ([]) immediately following the tuple name. Python utilizes zero-based indexing, meaning the very first item is located at index 0 

tuplu_mixt = (0, [1, 2, 3], (4, 5, 6), 7.0)

Greșeli frecvente de evitat
IndexError: Apare atunci când soliciți un indice care nu există (în afara limitelor).
TypeError: Apare atunci când folosești o valoare care nu este număr întreg sau un șir de caractere ca indice.
TypeError (Atribuire): Tuplurile sunt imuabile. Deși poți accesa elementele prin indexare, nu le poți modifica (e.g, fructe[0] = "măr" generează o eroare).
Common Errors to Avoid
IndexError:When you request an index that does not exist (out of bounds).
TypeError: When you use a non-integer value or string as an index.
TypeError (Assignment): Tuples are immutable. While you access items via indexing, you cannot alter them (e.g., fruits[0] = "aple" throws an error)

Pentru a gestiona în siguranță o eroare de tip IndexError în Python, plasează operațiunea de accesare a tuplului într-un bloc try și capturează excepția specifică folosind un bloc except IndexError. Astfel, previi blocarea întregului program atunci când soliciți un indice care nu există.

To safely handle an IndexError in Python, wrap your tuple access inside a try block and catch the specific exception using an except IndexError block. This prevents your entire program from crashing when you request an index that does not exist.

    print("Eroare: Indicele este în afara intervalului!")

Dacă plasezi un bloc generic de tipul except Exception: la început, acesta va intercepta toate erorile, iar blocurile destinate erorilor specifice, aflate dedesubt, nu se vor executa niciodată.
Order of Exceptions Matter
Always list specific errors (like IndexError or ValueError) before generic errors (like Exception). If you put a generic except Exception: block at the top, it will intercept all errors, and your specific error blocks underneath will never run.

Extragerea mai multor elemente dintr-un tuplu: felierea.
Retrieving Multiple Items From a Tuple: Slicing

tuplu_object[start:stop:step]

Operația de feliere (slicing) extrage o porțiune specifică a secvenței și returnează un nou tuplu, lăsând tuplul original neschimbat, întrucât tuplurile sunt imuabile.

Slicing extracts a specific portion of the sequence and returns a new tuple, leaving the original tuple unchanged since tuples are immutable. 

numere_tuplu = 3, 11, 4, 9, 10, 7

try:
    # Secționare cu un pas de 0
    print(numere_tuplu[::0])
except ValueError as e:
    print(f"Eroare detectată: {e}")
==> Eroare detectată: slice step cannot be zero

Operația de feliere (slicing) nu generează erori în cazul indicilor care depășesc limitele permise. În schimb, aceasta eșuează silențios, returnând un tuplu gol sau o listă parțială, ceea ce poate cauza erori ulterior în programul tău.

Slicing does not throw errors for out-of-bounds numbers. Instead, it fails silently by returning an empty tuple or a partial list, which can cause bugs later in your program.

tuplu = (11, 12, 13, 14, 15)

# Verifică valoarea start pentru slice
start, stop = 5, 10
if start >= len(tuplu):
    print("Atenţie!: Indicele de început este în afara intervalului!")
    ==> Atenţie!: Indicele de început este în afara intervalului!

# Slicing în afara limitelor nu generează o eroare de tip IndexError
rezultat = tuplu[5:10]

Copii ale unui tuplu - Copies of a Tuple

copy — Shallow and deep copy operations

În cazul obiectelor mutabile imbricate (cum ar fi liste în interiorul unui tuplu) sau atunci când este necesar în mod explicit un obiect separat, puteți crea copii folosind metodele detaliate mai jos.

In case of nested mutable objects (like lists inside a tuple) or explicitly require a separate object, you can create copies using the methods detailed below.

Copierea superficială a tuplurilor plate
Încercările de a efectua o copiere superficială vor returna pur și simplu o referință către tuplul original, pentru a economisi memorie.
The Shallow Copying Flat Tuples
Attempts to perform a shallow copy will simply return a reference to the original tuple to conserve memory.

# Ambele variabile indică exact aceeași adresă de memorie

Both variables hold references to the same tuple object and the same items. So, the "copy()" function doesn't make any difference.

Copiere completă (utilizând modulul copy)
Folosește această metodă dacă tuplul tău conține obiecte mutabile (precum listele). O copie profundă creează un tuplu nou și inserează recursiv copii ale obiectelor din tuplul original, asigurându-se astfel că modificările aduse unei liste imbricate nu afectează tuplul original.
Deep Copy (Using the copy module)
Use this if your tuple contains mutable objects (like lists). A deep copy constructs a new tuple and recursively inserts copies of the objects found in the original, ensuring changes to a nested list do not affect the original tuple.

print(id(persoană_info[2]) == id(persoană_profil[2])) ==> False

Modificările aduse obiectului mutabil din persoană_profil nu afectează datele originale din persoană_info. Dacă tuplul copiat în profunzime conține obiecte mutabile, Python creează o copie a acestor obiecte, astfel încât modificările aduse acestora în copie să nu afecteze datele originale.

Changes to the mutable object in persoană_profil don't affect the original data in persoană_info. If the deep-copied tuple contains mutable objects, Python creates a copy of these objects so that mutations to them in the copy won't affect the original data.

O funcție recursivă verifică fiecare element: dacă întâlnește un tuplu, intră în interiorul acestuia și îl inversează; dacă întâlnește un tip de date de bază (precum un întreg sau un șir de caractere), îl lasă neschimbat.

Since real data structures can have deeply nested tuples, static loops or fixed list comprehensions will break if a tuple is buried too deep. A recursive function checks each item: if it finds a tuple, it dives in and reverses it; if it finds a basic data type (like an integer or string), it leaves it alone.

def invers_imbricat(date):
    # Dacă elementul este un tuplu, inversează conținutul și procesează recursiv fiecare sub-element.
    if isinstance(date, tuple):
        return tuple(invers_imbricat(elm) for elm in reversed(date))
    
    # Dacă elementul este o listă, procesează recursiv fiecare element, dar păstrează structura listei.
    elif isinstance(date, list):
        return [invers_imbricat(elm) for elm in date]
    
    # Dacă este un element de bază (int, string etc.), îl returnează ca atare.
    return date

# Tupluri imbricate într-o listă.

rezultat = invers_imbricat(listă_imbricată)
print(rezultat) ==> [(('trei', 2), 1), (((8, 7), 6), (5, 'patru'))]

În Python, tuplurile sunt comparate lexicografic (element cu element, de la stânga la dreapta). Python începe cu primul element ale fiecărui tuplu. Dacă acestea diferă, evaluare determină rezultatul final al comparației. Dacă sunt egale, se trece secvențial la al doilea element și continuă astfel până când se găsește o diferență sau se ajunge la sfârșitul tuplurilor. Folosește operatori de comparare standard, precum ==, !=, <, <=, >, >=.

In Python, tuples are compared lexicographically (element by element, from left to right). Python starts with the first element of each tuple. If they differ, the evaluation determines the final result of the comparison. If they are equal, it proceeds sequentially to the second element and continues in this manner until a difference is found or the end of the tuples is reached. Use standard comparison operators like ==, !=, <, <=, >, >=.

# Egalitatea necesită elemente și lungimi identice

Consistența tipurilor de date: Elementele aflate pe aceeași poziție (la același indice) trebuie să fie compatibile pentru a putea fi comparate. Siguranță strictă a tipurilor: Un tuplu nu este niciodată egal cu o listă, chiar dacă acestea conțin elemente identice; expresia (1, 2) == [1, 2] va avea întotdeauna valoarea False.

Data Type Consistency: Elements at the same index position must be compatible for comparison. Attempting (1, 2) < ("apple", 2) throws a TypeError. Strict Type Safety: A tuple is never equal to a list, even if they hold identical elements. (1, 2) == [1, 2] will always evaluate to False

Pentru a căuta o anumită valoare ascunsă adânc în interiorul unor tupluri și liste imbricate, poți utiliza o funcție de căutare recursivă.

To search for a specific value hidden deep inside nested tuples and lists, you can use a recursive search function.

Căutare simplă (returnează True sau False)
Această funcție parcurge toate nivelurile. Se oprește și returnează True în momentul în care găsește valoarea căutată.
Simple Search (Returns True or False)
This function dives through all layers. It stops and returns True the moment it finds the target value.
def conținut_adânc(date, valoare):
    # Dacă este un tuplu sau o listă, caută recursiv în interiorul fiecărui element.
    if isinstance(date, (tuple, list)):
        return any(conținut_adânc(elment, valoare) for elment in date)
    
    # Cazul de bază: compară valoarea directă.
    return date == valoare

# Exemplu de structură de date.
date_imbricate = [(1, (2, 3)), ((4, 44), (6, (7, 8)))]

print(conținut_adânc(date_imbricate, 44)) ==> True
print(conținut_adânc(date_imbricate, 45)) ==> False

def găsește_locaţia(date, valoare, locaţia_curentă=None):
    if locaţia_curentă is None:
        locaţia_curentă = []
        
    # Dacă este găsită, returnează calea parcursă până aici.
    if date == valoare:
        return locaţia_curentă

    # Dacă este o colecție, parcurge-o folosind indici.
    if isinstance(date, (tuple, list)):
        for indice, element in enumerate(date):
            # Caută pe această ramură.
            rezultat = găsește_locaţia(element, valoare, locaţia_curentă + [indice])
            if rezultat is not None:
                return rezultat
                
    return None

date_adânc_imbricate = [(1, 3), (5, 6, 7), [(2, 4), (4, (8, 9, 44))]]

Diferența dintre tupluri și liste în Python - Difference Between Tuples and Lists in Python

Tuplu vs. Listă: Comparație
Caracteristic Tuple (()) List ([])
Mutabilitate Imutabil (nu se poate modifica) Mutabil (se poate modifica)
Performanță Mai rapid și consumă mai puțină memorie Mai lent și consumă mai multă memorie
Metode Doar 2 (count(), index()) Mai multe (append(), pop(), sort() etc.)
Utilizare Structuri fixe (precum coordonatele x, y) Colecții dinamice care se modifică
Chei de dicționar Da, deoarece suportă hashing Nu, va genera o eroare

După ce codul a fost creat și dorești să te asiguri că nu va fi suprascris sau corupt accidental ulterior în cadrul programului, ar trebui să-l stochezi într-un tuplu în loc de o listă.

Once code has been created and you want to ensure it won't be overwritten or accidentally corrupted later in the program, you should store it in a tuple instead of a list.

Python alocă memorie suplimentară listelor pentru a face loc unor operațiuni viitoare, precum adăugarea de date. Pentru tupluri se alocă exact dimensiunea necesară.

Python allocates extra memory to lists to make room for future operations like appending data. Tuples are allocated the exact size required.

import sys

listă = ["cer", "nour", 123, [321, 11.11], 0.2121]
tuplu = ("cer", "nour", 123, (321, 11.11), 0.2121)
print(f"Mărimea listei: {sys.getsizeof(listă)} bytes")   ==> Mărimea listei: 96 bytes
print(f"Mărimea tuplului: {sys.getsizeof(tuplu)} bytes") ==> Mărimea tuplului: 80 bytes

Listele includ mai multe metode. Tuplurile au acces doar la count() și index() din cauza caracterului lor imuabil.

Tuplurile pot fi folosite drept chei într-un dicționar. Listele vor genera o eroare de tip (TypeError), deoarece sunt mutabile și nu pot fi supuse operației de hashing în condiții de siguranță.

Lists include more methods. Tuples only have access to count() and index() because their immutable status.

Tuples can be used as keys in a dictionary. Lists will throw a TypeError because they are mutable and cannot be safely hashed.

Tuplurile se creează mult mai rapid decât listele. Deoarece tuplurile sunt imutabile, Python optimizează instanțierea acestora direct în bytecode.

Tuples are significantly faster to create than lists. Because tuples are immutable, Python optimizes their instantiation directly in the bytecode.

Tuplurile pot oferi un ușor avantaj în ceea ce privește viteza de iterare și de căutare, deoarece adresele lor de memorie sunt fixe și secvențiale, deși diferența este minimă în cazul colecțiilor de mici dimensiuni.

Tuples can offer a slight edge in iteration and lookup speeds because their memory addresses are fixed and sequential, though the difference is minimal for small collections.
