Ce sunt listele în Python - What are lists in Python

În Python, o listă este un tip de date încorporat, utilizat pentru a stoca o colecție ordonată de elemente. Caracteristicile cheie ale listelor Python includ:

Ordonate:
Elementele dintr-o listă își mențin ordinea de inserare. Aceasta înseamnă că elementele pot fi accesate după poziția lor, cunoscută sub numele de index, începând de la 0 pentru primul element.
Mutabile:
Listele sunt mutabile, ceea ce înseamnă că elementele lor pot fi modificate (adăugate, eliminate sau modificate) după ce lista a fost creată.
Eterogene:
Listele pot conține elemente de diferite tipuri de date în cadrul aceleiași liste, cum ar fi numere întregi, șiruri de caractere, valori booleene sau chiar alte liste.
Definite cu paranteze pătrate:
Listele sunt create prin includerea unei secvențe de elemente separate prin virgulă între paranteze pătrate [].

In Python, a list is a built-in data type used to store an ordered collection of items. Key characteristics of Python lists include:

Ordered:
The elements in a list maintain their insertion order. This means elements can be accessed by their position, known as an index, starting from 0 for the first element.
Mutable:
Lists are mutable, meaning their elements can be changed (added, removed, or modified) after the list has been created.
Heterogeneous:
Lists can contain elements of different data types within the same list, such as integers, strings, booleans, or even other lists.
Defined with Square Brackets:
Lists are created by enclosing a comma-separated sequence of elements within square brackets [].

Listele sunt o structură de date fundamentală și versatilă în Python, utilizată pe scară largă pentru organizarea și manipularea colecțiilor de date. Acestea acceptă diverse operațiuni și metode pentru adăugarea de elemente, eliminarea de elemente, sortare, căutare și multe altele.

Lists are a fundamental and versatile data structure in Python, widely used for organizing and manipulating collections of data. They support various operations and methods for adding elements, removing elements, sorting, searching, and more.

Acces bazat pe index:

Când elementele sunt adăugate la o listă, acestea sunt plasate într-o poziție specifică, iar acea poziție este menținută în raport cu alte elemente.
Iterația în ordine:
Când se iterează printr-o listă (de exemplu, folosind o buclă for), elementele sunt procesate în ordinea în care apar în listă.

Listele sunt mutabile - Lists are mutable

Listele în Python sunt mutabile, indiferent de mediul de execuție. Mutabilitatea înseamnă că elementele pot fi modificate, adăugate sau eliminate dintr-o listă după ce aceasta a fost creată fără a crea o listă nouă and fără a-i altera identitatea memoriei

Deoarece listele sunt mutabile, ele nu pot fi utilizate drept chei în dicționare. Dacă ai nevoie de o versiune imuabilă a unei liste pentru a o folosi drept cheie de dicționar sau element al unei mulțimi, ar trebui să utilizezi în schimb un tuplu imuabil.

Lists in Python are mutable, regardless of the execution environment. Mutability means that elements can be changed, added, or removed from a list after it has been created without creating a new list, without altering its memory identity

Because lists are mutable, they cannot be used as keys in dictionaries. If you need an unchangeable version of a list to use as a dictionary key or set element, you should use an immutable tuple instead.

  • If a list is assigned to another variable (e.g., list2 = list1), both variables will refer to the same object in memory. Any changes made through one of the variables will also affect the other.

Python Access List Items

Accesarea mai multor elemente (slicing) - Accessing Multiple Elements (Slicing)

Secționarea permite extragerea unei subsecțiuni a unei liste folosind formatul [start:end:step].

  • start: Indexul inițial (inclusiv). Dacă este omis, valoarea implicită este 0.
  • end: Indexul final (exclusiv). Dacă este omis, valoarea implicită este sfârșitul listei.
  • step: Incrementul dintre elemente (opțional). Dacă este omis, valoarea implicită este 1.

Slicing allows extraction of a sub-section of a list using the format [start:end:step].

  • start: The starting index (inclusive). If omitted, defaults to 0.
  • end: The ending index (exclusive). If omitted, defaults to the end of the list.
  • step: The increment between elements (optional). If omitted, defaults to 1.

Performanță în timp ce listele cresc în Python - Performance While Growing Lists python

Listele Python sunt implementate ca tablouri dinamice, ceea ce înseamnă că alocarea memoriei lor subiacente se poate modifica pe măsură ce elementele sunt adăugate sau eliminate. Această redimensionare dinamică are impact asupra performanței, în special atunci când listele cresc semnificativ.

Cum afectează creșterea listei performanța:
Alocare inițială:
Când este creată o listă, Python alocă o anumită cantitate de memorie, adesea mai mult decât este necesar imediat, pentru a anticipa adăugările viitoare.
Redimensionare automată:
Când o listă depășește capacitatea alocată curentă, Python efectuează o operațiune de redimensionare. Aceasta implică:
  • Alocarea unui bloc de memorie nou, mai mare.
  • Copierea tuturor elementelor existente din vechea locație de memorie în cea nouă.
  • Adăugarea noului(elor) element(e).
Factor de creștere:
Python folosește un factor de creștere (în jur de 1,125, deși acesta poate varia) pentru a determina noua dimensiune în timpul realocării. Această strategie își propune să minimizeze numărul de operațiuni costisitoare de realocare, evitând în același timp supraalocarea excesivă a memoriei.
Implicații asupra performanței:
Costul redimensionării:
Copierea elementelor în timpul redimensionării este o operațiune relativ costisitoare, în special pentru listele mari. Redimensionarea frecventă poate duce la degradarea performanței.
O(1) amortizat pentru append():
Deși operațiunile individuale append() care declanșează o redimensionare pot fi costisitoare, complexitatea medie generală (amortizată) a timpului pentru append() este încă considerată O(1) deoarece costul redimensionării este distribuit pe mai multe adăugări care nu implică redimensionare.
Optimizarea performanței la creșterea listelor:
Prealocare:
Dacă dimensiunea finală aproximativă a unei liste este cunoscută dinainte, prealocarea acesteia cu o capacitate inițială suficient de mare (de exemplu, listă = [None] * size) poate elimina sau reduce necesitatea redimensionării în timpul atribuirii elementelor.
Înțelegeri ale listelor(List Comprehensions):
Pentru construirea de liste noi bazate pe iterabile existente, înțelegerile listelor sunt în general mai eficiente decât buclele for cu apeluri append() repetate, deoarece acestea pot optimiza adesea alocarea memoriei.
extend() vs. operatorul +:
Atunci când se combină liste, extend() este de obicei mai eficientă decât utilizarea operatorului + pentru concatenare, în special cu liste mari, deoarece extend() modifică lista pe loc fără a crea un nou obiect listă.
Generatoare:
Pentru seturi de date foarte mari unde memoria este o problemă, utilizarea generatoarelor poate fi mai eficientă din punct de vedere al memoriei, deoarece acestea generează elemente pe rând, evitând necesitatea stocării întregii liste în memorie.

Python lists are implemented as dynamic arrays, which means their underlying memory allocation can change as elements are added or removed. This dynamic resizing impacts performance, particularly when lists grow significantly.

How List Growth Affects Performance:
Initial Allocation:
When a list is created, Python allocates a certain amount of memory, often more than immediately needed, to anticipate future additions.
Automatic Resizing:
When a list exceeds its current allocated capacity, Python performs a resizing operation. This involves:
  • Allocating a new, larger block of memory.
  • Copying all existing elements from the old memory location to the new one.
  • Adding the new element(s).
Growth Factor:
Python uses a growth factor (historically around 1.125, though this can vary) to determine the new size during reallocation. This strategy aims to minimize the number of expensive reallocation operations while avoiding excessive memory over-allocation.
Performance Implications:
Cost of Resizing:
The copying of elements during resizing is a relatively expensive operation, especially for large lists. Frequent resizing can lead to performance degradation.
Amortized O(1) for append():
While individual append() operations that trigger a resize can be costly, the overall average (amortized) time complexity for append() is still considered O(1) because the cost of resizing is spread out over many non-resizing appends.
Optimizing Performance When Growing Lists:
Pre-allocation:
If the approximate final size of a list is known beforehand, pre-allocating it with a sufficiently large initial capacity (e.g., my_list = [None] * size) can eliminate or reduce the need for resizing during element assignment.
List Comprehensions:
For building new lists based on existing iterables, list comprehensions are generally more efficient than for loops with repeated append() calls, as they can often optimize memory allocation.
extend() vs. + operator:
When combining lists, extend() is typically more efficient than using the + operator for concatenation, especially with large lists, because extend() modifies the list in place without creating a new list object.
Generators:
For very large datasets where memory is a concern, using generators can be more memory-efficient as they yield elements one at a time, avoiding the need to store the entire list in memory.
