Obiecte bytearray - bytearray Objects

Un obiect de tip bytearray în Python este o secvență mutabilă de numere întregi fără semn pe 8 biți (valori cuprinse între 0 și 255). Acesta reprezintă o versiune dinamică și modificabilă a unui obiect standard de tip bytes.

A bytearray object in Python is a mutable sequence of 8-bit unsigned integers (values ranging from 0 to 255). It it as a dynamic, editable of a standard bytes object.

Compararea tipurilor bytes și bytearray
Caracteristicăbytesbytearray
MutabilitateImutabil (nu poate fi modificat după creare)Mutabil (permite modificări pe loc și redimensionare)
Literal de sintaxăSuportat (de ex., b'salut')Nu există un literal specific; trebuie utilizat constructorul
Metode de modificareNiciuna (generează TypeError la atribuirea unei valori unui element)append(), extend(), insert(), pop() etc.
Cazuri principale de utilizareConstante binare fixe, chei de dicționar, codificări de textModificări dinamice ale fluxurilor I/O, buffere de rețea

Since a bytearray in Python is a mutable sequence of integers ranging from 0 to 255, it supports methods specific to lists and strings.

În sistemul hexazecimal, 0a este egal cu numărul 10 în sistemul zecimal. În standardul de caractere ASCII, numărul 10 reprezintă un caracter de tip Newline / Line Feed (salt la linie nouă), care, în cod, este scris universal sub forma \n.

In the hexadecimal system, 0a equals the number 10 in decimal. In the ASCII character standard, the number 10 represents a Newline / Line Feed character, which is universally written as \n in code.

Gestionarea sigură a erorilor
Deoarece remove() provoacă o eroare dacă elementul nu există, plasează apelul într-un bloc try/except sau verifică mai întâi dacă elementul este prezent:
Handling Errors Safely
Because remove() crashes if the element isn't there, wrap it in a try/except block or check for existence first:
# 122 este codul ASCII pentru litera "z"
litere = bytearray(b"XYZ")

# Verificare prealabilă
if 122 in litere:
    litere.remove(122)

# try/except
try:
    litere.remove(122)
except ValueError:
    print("Valoarea octetului nu a fost găsită!")
==> Valoarea octetului nu a fost găsită!

Pentru a elimina mai multe apariții ale unei valori de tip octet dintr-un bytearray, poți alege între a modifica matricea pe loc sau a crea o copie nouă. Metoda încorporată .remove() elimină doar câte o apariție pe rând, așadar este necesară o strategie diferită, în funcție de obiectivul urmărit.

To remove multiple instances of a byte value from a bytearray, you can choose between changing the array in place or creating a clean copy. The built-in .remove() method only handles one at a time, so you need a different strategy depending on your goal.

# Comprehensiunea listelor (returnează un nou bytearray)
date = bytearray(b"A-B-C-D")
octet_de_eliminat = ord('-')  # Valoare: 45

# Păstrează fiecare octet care nu este țintă
date_filtrate = bytearray(b for b in date if b != octet_de_eliminat)

print(date_filtrate) ==> bytearray(b'ABCD')

# Buclă while (modifică elementul original)
date = bytearray(b"A-B-C-D")
octet_de_eliminat = ord('-')

while True:
    try:
        date.remove(octet_de_eliminat)
    except ValueError:
        break  # Se declanșează atunci când toate instanțele au dispărut

print(date) ==> bytearray(b'ABCD')

Căutare, numărare și informații - Searching, Counting and Information

  • .count(sub[, start[, end]]): Returnează numărul total de apariții (care nu se suprapun) ale unui octet sau ale unei secvențe.
  • .find(sub[, start[, end]]): Returnează cel mai mic indice la care se găsește subsecvența sub (returnează -1 dacă nu este găsită).
  • .index(sub[, start[, end]]): Similar cu .find(), dar generează o eroare de tip ValueError dacă subsecvența lipsește.
  • .startswith(prefix[, start[, end]]): Returnează True dacă datele încep cu prefixul de octeți specificat.
  • .endswith(suffix[, start[, end]]): Returnează True dacă datele se termină cu sufixul de octeți specificat.
  • .count(sub[, start[, end]]): Returns the total non-overlapping occurrences of a byte or slice.
  • .find(sub[, start[, end]]): Returns the lowest index where the subsequence sub is found (returns -1 if not found).
  • .index(sub[, start[, end]]): Like .find(), but raises a ValueError if the subsequence is missing.
  • .startswith(prefix[, start[, end]]): Returns True if the data begins with the specified byte prefix.
  • .endswith(suffix[, start[, end]]): Returns True if the data ends with the specified byte suffix.

bytearray.count(sub[, start[, end]])

Transformări ale textului (Returnează o copie nouă) - Text Transformations (Returns a New Copy)

  • .replace(old, new[, count]): Înlocuiește aparițiile unei secvențe de octeți cu o alta.
  • .split(sep=None, maxsplit=-1): Împarte tabloul binar într-o listă de obiecte bytearray mai mici, folosind un delimitator.
  • .join(iterable): Unește elementele unui obiect iterabil — format din entități de tip bytes — folosind obiectul bytearray curent drept separator.
  • .lower() / .upper(): Convertește caracterele ASCII din fluxul binar în litere mici sau litere mari.
  • .replace(old, new[, count]): Replaces occurrences of a byte sequence with another.
  • .split(sep=None, maxsplit=-1): Splits the binary array into a list of smaller bytearray objects using a delimiter.
  • .join(iterable): Joins an iterable of bytes-like objects together using the current bytearray as the separator.
  • .lower() / .upper(): Converts ASCII characters inside the binary stream to lowercase or uppercase.

Atenție la datele binare
Dacă un bytearray conține date binare arbitrare (cum ar fi imagini sau pachete de rețea), în loc de șiruri de caractere ASCII, utilizarea metodelor .lower() sau .upper() poate duce la alterarea neintenționată a datelor. De exemplu, valoarea de octet 0x41 (65 în sistemul zecimal) reprezintă caracterul ASCII "A". Dacă apelați .lower(), acest octet va fi modificat în 0x61 (97 în sistemul zecimal, adică "a"), chiar dacă, inițial, acesta avea rolul de contor binar sau de identificator.
Binary Data Caution
If your bytearray contains actual arbitrary binary data (like images or network packets) rather than ASCII text strings, running .lower() or .upper() can unintentionally corrupt your data. For example, the byte value 0x41 (decimal 65) represents the ASCII character "A". If you call .lower(), that byte will be altered to 0x61 (decimal 97, which is "a", even if it was originally meant to be a binary counter or identifier.
