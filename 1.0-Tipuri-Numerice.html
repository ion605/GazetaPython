Python oferă trei tipuri numerice de bază pentru gestionarea valorilor numerice. Aceste tipuri numerice acceptă diverse operații aritmetice, cum ar fi adunarea, scăderea, înmulțirea și împărțirea, precum și operații mai specializate, cum ar fi exponențierea și modulul. De asemenea, puteți utiliza funcții încorporate, cum ar fi int(), float() și complex() pentru a converti între diferite tipuri numerice (unde este cazul) sau pentru a crea obiecte numerice din șiruri de caractere.

Python offers three core numeric types for handling numerical values. These numeric types support various arithmetic operations like addition, subtraction, multiplication, and division, as well as more specialized operations like exponentiation and modulus. You can also use built-in functions like int(), float(), and complex() to convert between different numeric types (where appropriate) or to create numeric objects from strings.
