3.7 Set Types -- set, frozenset

  • Tipuri de mulțimi (Set Types)
  • utilizate pentru colecții de valori unice, unde ordinea nu contează.
  • set: o colecție mutabilă de elemente unice; utilă pentru eliminarea valorilor duplicate și pentru efectuarea unor operații matematice cu mulțimi, precum reuniunea sau intersecția.
  • frozenset: o versiune imutabilă a unei mulțimi. Deoarece nu poate fi modificată, poate fi utilizată drept cheie într-un dicționar sau ca element al unei alte mulțimi.
  • Set Types
  • Used for collections of unique values where ordering doesn't matter.
  • set: A mutable collection of unique items; useful for eliminating duplicate values and running mathematical set operations like unions or intersections.
  • frozenset: An immutable version of a set. Because it is unchangeable, it can be used as a dictionary key or an element in another set

În matematică, o mulțime este o colecție bine definită de obiecte distincte, numite elemente sau membri. În lumea modernă, teoria mulțimilor constituie limbajul fundamental al logicii, al clasificării datelor și al rezolvării problemelor.

A set in mathematics is a well-defined collection of distinct objects, known as elements or members. In the Modern world , set theory serves as the foundational language of logic, data classification, and problem-solving.

Concepte și notații fundamentale
Definiție: O colecție de obiecte distincte, numite elemente sau membri (de exemplu, A = {1, 2, 3, 4, 5}). Literele mari desemnează mulțimi; literele mici desemnează elemente (a ∈ A).
Modalități de descriere a mulțimilor:
Metoda enumerării (sau tabelară): Enumerarea explicită a fiecărui element între acolade: V = {a, e, i, o, u}).
Descrierea unei reguli sau condiții pe care trebuie să o îndeplinească elementele: {x | x este o vocală}.
Mulțimea universală (U): Colecția tuturor obiectelor posibile luate în considerare într-un anumit context.
Mulțimea vidă/nulă ({}): Nu conține niciun element.
Cardinalitatea n(A): Numărul total de elemente distincte dintr-o mulțime finită.
Core Concepts and Notations
Definition: A collection of distinct objects, which are called elements or members (e.g., A = {1, 2, 3, 4, 5}). Capital letters denote sets; lowercase letters denote elements (a ∈ A).
Ways to Describe Sets:
Roster Method (Tabular): Listing every element explicitly inside curly braces: V = {a, e, i, o, u}).
Describing a rule or condition that elements must satisfy: {x | x is a vowel}.
Universal Set (U): The total collection of all possible objects under consideration in a specific context.
Empty/Null Set ({}: A set containing no elements.
Cardinality n(A): The total count of unique elements in a finite set.
Tipuri de mulțimi
Mulțime finită: O mulțime cu un număr finit și determinabil de elemente.
Mulțime infinită: O mulțime cu un număr nelimitat de elemente (cum ar fi mulțimea numerelor naturale N).
Submulțime (A ⊆ B): Fiecare element al mulțimii A aparține și mulțimii B. Numărul total de submulțimi ale unei mulțimi cu n elemente este 2n.
Mulțimi disjuncte: Două mulțimi care nu au niciun element comun (intersecția lor este vidă).
Types of Sets
Finite Set: A set with a countable, exact number of elements.
Infinite Set: A set with endless elements (such as natural numbers N).
Subset (A ⊆ B): Every element of set A also belongs to set B. The total number of subsets for a set with n elements is 2n.
Disjoint Sets: Two sets that share no common elements (their intersection is empty).
Operații de bază cu mulțimi
Reuniune (A ∪ B): Combină toate elementele unice din ambele mulțimi, A și B.
Intersecție (A ∩ B): Păstrează doar elementele comune mulțimilor A și B.
Complementară (Ac): Conține toate elementele din mulțimea universală U care nu se află în A.
Diferență de mulțimi (A - B): Conține elementele prezente în A, dar excluzând elementele din B.
Produs cartezian (A × B): Formează toate perechile ordonate posibile (a, b) în care a ∈ A și b ∈ B.
Basic Set Operations
Union (A ∪ B): Combines all unique elements from both A and B.
Intersection (A ∩ B): Retains only the elements shared by both A and B.
Complement (Ac)): Contains all elements in the universal set U that are not in A.
Set Difference (A - B): Contains elements present in A but removed from B.
Cartesian Product (A × B): Forms all possible ordered pairs (a, b) where a ∈ A and b ∈ B

Diagramele Venn: Reprezentări geometrice dreptunghiulare și circulare, introduse de John Venn, care ilustrează vizual relațiile, suprapunerile și diferențele dintre mulțimi.

Utilitate practică: Teoria mulțimilor și diagramele Venn sunt utilizate în viața cotidiană pentru cereri ale bazelor de date, filtrarea rezultatelor în motoarele de căutare, analiza datelor din sondaje, calculul probabilităților și clasificarea informațiilor categorice.

Venn Diagrams: Rectangular and circular geometric drawings introduced by John Venn that visually map out relationships, overlaps, and differences between sets.

Real-World Utility: Set theory and Venn diagrams are used in modern life for database queries, search engine filtering, survey data analysis, probability, and sorting categorical information.

Definirea unei mulțimi - Defining a Set

Python Sets

Sets Objects

În Python, poți defini o mulțime folosind acoladele {} sau constructorul set(). O mulțime este o colecție neordonată de elemente unice, ceea ce înseamnă că duplicatele sunt eliminate automat, iar elementele nu au un indice fix.

In Python, you can define a set using curly braces {} or the set() constructor. A set is an unordered collection of unique elements, meaning duplicates are automatically removed and the items do not have a fixed index

# Definirea unei mulțimi cu acolade
fructe = {"mere", "pere", "caise", "mere"}
print(fructe) ==> {'mere', 'caise', 'pere'}

# Utilizarea constructorului set()
# Conversia unei liste într-un set pentru a filtra duplicatele
listă_numere = [1, 2, 2, 3, 4, 4]
numere_unice = set(listă_numere)
print(numere_unice) ==> {1, 2, 3, 4}

Pentru a crea o mulțime vidă, trebuie să folosești set(). Utilizarea unor acolade vide {} va crea un dicționar vid.

To create an empty set, you must use set(). Using empty curly braces {} will create an empty dictionary.

# Modul corect de a defini o mulțime vidă
mulțime_vidă = set()
print(type(mulțime_vidă))   ==> <class 'set'>

# Modul incorect (aceasta creează un dicționar vid)
nu_este_un_set = {}
print(type(nu_este_un_set)) ==> <class 'dict'>

Python set cannot contain absolutely any type of element. A single set can store a mixture of different data types, can only contain elements that are immutable and hashable.

Dimensiune și apartenență - Size and membership

Pentru a afla numărul de elemente dintr-o mulțime, se utilizează funcția len() şi va număra doar intrările unice.

Pentru a verifica dacă un element face parte dintr-o mulțime, se folosesc operatorii de apartenență in și not in.

Verificarea apartenenței este extrem de optimizată și se execută cu o complexitate temporală medie de O(1).

To find the number of elements in a set, use the len() function and will only count unique entries.

To check if an element is part of a set, use the in and not in membership operators.

Membership testing is highly optimized and runs in O(1) average time complexity.

# Inițializează o mulțime
fructe = {"mere", "pere", "caise", "mere"}
print(fructe)  ==> {'mere', 'pere', 'caise'}

# Obțineți dimensiunea (lungimea) setului
lungime = len(fructe)

print(f"Lungimea mulțimii: {lungime}")
==> Lungimea mulțimii: 3

# Inițializează o mulțime
fructe = {"mere", "pere", "caise", "mere"}

# Testarea apartenenței
if "pere" in fructe:
    print("Pere sunt in set!")
==> Pere sunt in set!
if "gutuii" not in fructe:
    print("Gutui nu sunt in set.")
==> Gutui nu sunt in set.

Metode care nu modifică mulțimea (disponibile atât pentru set, cât și pentru frozenset)
Reuniune (|): Combină elementele mulțimilor. a.union(b)
Intersecție (&): Elemente prezente în ambele mulțimi. a.intersection(b)
Diferență (−): Elemente în a, nu și în b. a.difference(b)
Diferență simetrică (^): Elemente într-o mulțime, dar nu în ambele. a.symmetric_difference(b)
Non-Mutating Methods (Available on both set and frozenset)
Union (|): Combines elements from both sets. a.union(b)
Intersection (&): Elements present in both sets. a.intersection(b)
Difference (−): Elements in a but not in b. a.difference(b)
Symmetric Difference (^): Elements in either set, but not both. a.symmetric_difference(b)
# Inițializarea seturilor
set_a = {1, 2, 3, 4}
set_b = {3, 4, 5, 6}
set_c = {3, 6, 7, 9}

# Uniune (Union) operator
print(set_a | set_b)             ==> {1, 2, 3, 4, 5, 6}            

# intersecţie (Intersection) operator
print(set_a & set_b) ==> {3, 4}     

# Diferenţă (Difference) operator 
print(set_a - set_b)             ==> {1, 2}              

# Diferență simetrică (Symmetric Difference) operator
print(set_a ^ set_b)             ==> {1, 2, 5, 6}

# Evaluează de la stânga la dreapta: (set_a ^ set_b) ^ set_c
print(set_a ^ set_b ^ set_c)   ==> {1, 2, 3, 5, 7, 9}

a = {1, 2, 3}
b = {2, 3, 4}

# intersecţie (Intersection) metodă

# Diferenţă (Difference) metodă
print(b.difference(c))       ==> {2}

print(a.difference(b, c))    ==> {1}

# Diferență simetrică (Symmetric Difference)  metodă
print(a.symmetric_difference(b)) ==> {1, 4}

Python - Access Set Items

În Python, nu poți accesa elementele unei mulțimi folosind un indice sau o cheie, deoarece mulțimile sunt colecții neordonate și fără indici. Încercarea de a utiliza o sintaxă precum my_set[0] va genera o eroare de tip TypeError.

În schimb, poți accesa sau verifica elementele dintr-o mulțime folosind bucle, teste de apartenență, iteratori sau conversia tipului de date.

In Python, you cannot access set items using an index or a key because sets are unordered and unindexed collections. Attempting to use syntax like my_set[0] will raise a TypeError.

Instead, you can access or check items within a set using loops, membership tests, iterators, or type conversion.

fructe = {"gutui", "prune", "struguri"}

Modifică un element - Modify an Item

Python set sunt colecții neordonate de elemente unice, nu poți modifica un element al mulțimii direct.

Pentru a modifica un element, trebuie să parcurgi un proces în doi pași: elimini elementul vechi și adaugi elementul nou.

Python sets are unordered collections of unique items, you cannot modify a set item in place.

To modify an item, you must use a two-step process: remove the old item and add the new item.

Modificarea unui element specific
Dacă cunoști valoarea exactă pe care dorești să o modifici, folosește .discard() pentru a o elimina în siguranță (nu va genera o eroare dacă elementul nu există) și .add() pentru a insera versiunea actualizată.
Modify a Specific Item
If you know the exact value you want to change, use .discard() to safely remove it (it won't throw an error if the item isn't there) and .add() to insert the updated version.
fructe = {"mere", "pere", "gutui"}

# Inlocuieste "pere" cu "struguri"
if "pere" in fructe:
    fructe.discard("pere")
    fructe.add("struguri")
print(fructe) ==> {'struguri', 'mere', 'gutui'}
Modificarea tuturor elementelor (set comprehension)
Dacă dorești să aplici o modificare fiecărui element dintr-o mulțime (de exemplu, transformarea tuturor șirurilor de caractere în majuscule), o construcție de tip set comprehension reprezintă cea mai elegantă și rapidă metodă.
Modify All Items (Set Comprehension)
If you want to apply a change to every item in the set (for example, converting all strings to uppercase), a set comprehension is the cleanest and fastest way.
fructe = {"mere", "pere", "gutui"}

# Convertește toate elementele la majuscule
fructe = {fruct.upper() for fruct in fructe}

print(fructe) ==> {'GUTUI', 'PERE', 'MERE'}
Modificare prin conversia într-o listă
Dacă trebuie să modifici un element aflat într-o anumită poziție logică, poți converti mulțimea într-o listă, poți modifica elementul folosind indicele acestuia și apoi poți converti lista înapoi într-o mulțime.
Modify via List Conversion
If you need to change an item at a specific logical position, you can convert the set to a list, modify the element using its index, and then convert it back into a set.
fructe = {"mere", "pere", "gutui"}

# Convertește, modifică indexul 1, reconvertește
fructe_lista = list(fructe)
fructe_lista[1] = "smochine"
fructe = set(fructe_lista)

print(fructe) ==> {'mere', 'smochine', 'gutui'}

frozenset mulțimi imutabile

Python frozenset

frozenset este o versiune încorporată, imuabilă și care permite calcularea unei valori hash a unei mulțimi standard. În timp ce o mulțime standard îți permite să adaugi sau să elimini elemente după bunul plac, un frozenset fixează datele în momentul creării.

frozenset is a built-in, immutable and hashable version of a standard set. While a standard set allows you to add or remove items at will, a frozenset locks the data in place upon creation.

Un frozenset este o versiune imuabilă a unei mulțimi (set) în Python. Deși împărtășesc caracteristici precum faptul că pot conține doar elemente unice, neordonate, ele diferă în ceea ce privește mutabilitatea și cazurile de utilizare.

A frozenset is an immutable version of a Python set. While they share characteristics like holding only unique, unordered elements, they differ in mutability and use cases.

Operații care nu modifică mulțimile - Non Mutating Set Operations

a = frozenset([1, 2, 3])
b = frozenset([3, 4, 5])

# Reuniune (toate elementele unice din ambele)
print(a | b)      ==> frozenset({1, 2, 3, 4, 5})                
print(a.union(b)) ==> frozenset({1, 2, 3, 4, 5})        

# Intersecție (elemente prezente în ambele)
print(a & b)             ==> frozenset({3})
print(a.intersection(b)) ==> frozenset({3})

a = frozenset([1, 2, 3])
b = frozenset([3, 4, 5])

# Diferență (elemente prezente în a, dar nu și în b)
print(a - b)           ==> frozenset({1, 2})                 
print(a.difference(b)) ==> frozenset({1, 2})

# Diferență simetrică (elemente care se află fie în a, fie în b, dar nu în ambele)
print(a ^ b) ==> frozenset({1, 2, 4, 5}) 
print(a.symmetric_difference(b)) ==> frozenset({1, 2, 4, 5})
Cazuri principale de utilizare
Chei în dicționare: Indiferent de ordinea acestora.
Mulțimi imbricate: Este posibil doar dacă mulțimile interioare sunt obiecte de tip frozenset.
Integritatea datelor: Asigurarea faptului că o colecție de constante sau configurații nu poate fi modificată accidental de alte părți ale codului dumneavoastră.
Primary Use Cases
Dictionary Keys: Regardless of their order.
Nested Sets: Is only possible if the inner sets are frozenset objects.
Data Integrity: Ensuring that a collection of constants or configurations cannot be accidentally modified by other parts of your code.

Aplatizează seturile imbricate - Flatten the nested sets

# O mulțime de mulțimi

set_plat = {item for s in set_imbricat for item in s}
print(set_plat) ==> {1, 2, 3, 4}
