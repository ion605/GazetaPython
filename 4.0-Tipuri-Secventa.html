O listă în Python este o colecție predefinită, ordonată și mutabilă (modificabilă), utilizată pentru a stoca mai multe elemente într-o singură variabilă.

A Python list is a built-in, ordered, and mutable (changeable) collection used to store multiple items in a single variable.

Caracteristici
Ordonată: Elementele își păstrează o ordine de inserare definită și fixă.
Mutabilă: Elementele pot fi modificate, adăugate sau eliminate după crearea listei.
Eterogenă: O singură listă poate conține tipuri de date mixte (cum ar fi numere întregi, șiruri de caractere, valori booleene sau chiar alte liste).
Duplicarea permisă: Aceeași valoare poate apărea de mai multe ori.
Characteristics
Ordered: Items maintain a defined, fixed insertion order.
Mutable: You can change, add, or remove items after the list is created.
Heterogeneous: A single list can hold mixed data types (such as integers, strings, booleans, or even other lists).
Duplicates allowed: The same value can appear more than once.
Sintaxă de bază și creare
O listă se definește folosind paranteze pătrate [] sau constructorul list()
Indexare și feliere (slicing)
Python utilizează indexarea bazată pe zero (primul element are indicele 0). De asemenea, se pot folosi numere negative pentru a număra invers, de la sfârșit (-1 reprezintă ultimul element).
Basic Syntax and Creation
You define a list using square brackets [] or the list() constructor
Indexing and Slicing
Python uses zero-based indexing (the first item is at index 0). You can also use negative numbers to count backward from the end (-1 is the last item).

Un tuplu este un tip de date încorporat în Python, utilizat pentru a stoca o colecție ordonată, imuabilă (care nu poate fi modificată) cu elemente eterogene. Spre deosebire de liste, odată ce un tuplu a fost creat, elementele sale nu mai pot fi modificate, adăugate sau eliminate.

tuple is a built-in Python data type used to store an ordered, immutable (unchangeable), and heterogeneous collection of items. Unlike lists, once a tuple is created, its elements cannot be modified, added, or removed.

Crearea unui tuplu
Tuplurile sunt definite folosind paranteze rotunde () și separând elementele prin virgule.
Pentru a crea un tuplu care conține un singur element, trebuie să adaugi o virgulă la final ("gutuie",). În caz contrar, Python îl va trata ca pe un tip de date obișnuit, inclus între paranteze ("gutuie").
Accesarea și felierea elementelor
Tuplurile suportă indexarea de la zero și felierea, la fel ca listele.
Proprietăți și comportament cheie
Imuabilitate: Nu poți modifica structura de date odată ce a fost definită.
Despachetarea tuplurilor: Elementele pot fi extrase în variabile individuale.
Metode încorporate: Datorită imutabilității, tuplurile dispun de două metode încorporate:
count(valoare): Returnează numărul de apariții ale unei valori.
index(valoare): Returnează indicele primei apariții a unei valori.
Creating a Tuple
Tuples are defined using parentheses () and separating items with commas.
To create a tuple containing only one element, you must include a trailing comma ("gutuie",). Otherwise, Python will treat it as a regular data type wrapped in parentheses ("gutuie").
Accessing and Slicing Elements
Tuples support zero-based indexing and slicing just like lists.
Key Properties and Behavior
Immutability: You cannot alter the data structure once defined.
Tuple Unpacking: Can be extracted items into individual variables.
Built-in Methods: Because of immutablity, tuples have two built-in methods:
count(value): Returns the number of times a value occurs.
index(value): Returns the index of the first occurrence of a value.

În Python, termenul "hash" se referă, în principal, la două concepte distincte: funcția încorporată hash(), utilizată pentru căutarea rapidă a datelor în dicționare, și hashing-ul criptografic securizat, realizat prin intermediul modulului hashlib.

In Python, "hash" primarily refers to two distinct concepts: the built-in hash() function used for fast data lookups in dictionaries, and secure cryptographic hashing via the hashlib module

Python aleatorizează hash-urile șirurilor de caractere la fiecare rulare a scriptului, pentru a preveni atacurile de tip Denial of Service (DoS). Nu utilizați funcția hash() pentru a salva valori într-o bază de date externă.

Python randomizes string hashes on every script launch to prevent Denial of Service (DoS) attacks. Do not use hash() to save values to an external database.

Funcția range() generează o secvență imutabilă de numere întregi. Aceasta este utilizată cel mai frecvent pentru a controla numărul de execuții ale unei bucle for sau pentru a parcurge indicii unei liste.

range() function generates an immutable sequence of integers. It is most commonly used to control the execution count of a for loop or to loop through list indices.

Cum se utilizează
VarianteExemplu de codSecvență rezultată
parametru (stop)range(5)0, 1, 2, 3, 4
parametri (start, stop)range(2, 7)2, 3, 4, 5, 6
parametri (start, stop, pas)range(0, 10, 2)0, 2, 4, 6, 8
Pas negativ (numărătoare inversă)range(5, 0, -1)5, 4, 3, 2, 1
Proprietăți principale
Eficiență a memoriei: range() returnează un obiect iterabil de tip lazy (evaluat la cerere), în loc să genereze o listă propriu-zisă în memorie. Numerele sunt calculate pe parcurs, în momentul în care sunt necesare.
Conversia într-o listă: Pentru a afișa sau a vizualiza imediat toate numerele, utilizați constructorul list(): list(range(5)).
Doar numere întregi: Funcția încorporată range() acceptă exclusiv valori întregi. Dacă aveți nevoie să generați secvențe de numere cu virgulă mobilă (zecimale), utilizați alternativa oferită de o bibliotecă externă: numpy.arange().
Key Properties
Memory Efficient: range() returns a lazy iterable range object rather than generating an actual list in memory. It calculates numbers on the fly.
Converting to a List: To print out or see the raw numbers instantly, wrap it inside a list constructor: list(range(5)).
Integers Only: The built-in range() function only accepts integer values. If you need to generate float/decimal sequences, use the third-party library alternative numpy.arange()
