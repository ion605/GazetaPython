Crearea dicționarelor în Python - Creating Dictionaries in Python

Python Dictionaries

Dicționarele sunt utilizate pentru a stoca valori de date sub formă de perechi cheie-valoare. Un dicționar este o colecție ordonată, modificabilă și care nu permite duplicate. În Python 3.6 și versiunile anterioare, dicționarele sunt neordonate.

Dictionaries are used to store data values in key:value pairs. A dictionary is a collection which is ordered, changeable and do not allow duplicates. In Python 3.6 and earlier, dictionaries are unordered.

Dicționar literal (acolade {}) - Dictionary Literals (Curly Braces {})

Aceasta este cea mai comună și simplă metodă de a crea un dicționar, prin specificarea directă a perechilor cheie-valoare între acolade.

This is the most common and straightforward way to create a dictionary by directly specifying key-value pairs within curly braces.

# Dicționar gol
dict_gol = {}

# Dicționar cu perechi cheie-valoare inițiale
nume = {"Cristina": 60, "Andrei": 50, "Mihai": 75, "Vasile": 67, "Alexandru": 39, "Elena": 41, "Ioana": 19}
persoană = {"nume": "Cristina", "vârstă": 50, "oraş": "Severin"}
print(type(persoană )) ==> <class 'dict'>

Cheile trebuie să fie obiecte hashabile, cum ar fi numere, șiruri de caractere sau tupluri.
The keys must be hashable objects like numbers, strings, or tuples.

Atribuirea manuală a cheilor unui dicționar - Assigning keys manually to a dictionar

persoană = {} # Inițializează un dicționar gol

Adăugarea de chei la un dicționar într-o buclă for - Adding keys to a dictionary within a for loop

Atribuire directă: Aceasta este cea mai simplă metodă. Puteți atribui direct o valoare unei noi chei în cadrul buclei. Dacă cheia există deja, valoarea acesteia va fi actualizată.

Direct Assignment: This is the most straightforward method. You can directly assign a value to a new key within the loop. If the key already exists, its value will be updated.

pătrate = {}
for intreg in range(1, 10):
    pătrate[intreg] = intreg**2
    
print(pătrate)
==> {1: 1, 2: 4, 3: 9, 4: 16, 5: 25, 6: 36, 7: 49, 8: 64, 9: 81}

produs = {}
for i in range(3):
    cheie = f"cheie_{i}"
    valoare = i * 10
    produs[cheie] = valoare
print(produs)
==> {'cheie_0': 0, 'cheie_1': 10, 'cheie_2': 20}

Metoda update(): permite să adăugați mai multe perechi cheie-valoare simultan sau să actualizați cele existente, prin transmiterea unui alt dicționar sau a unui iterabil de perechi cheie-valoare.

update() Method: allows you to add multiple key-value pairs at once, or update existing ones, by passing another dictionary or an iterable of key-value pairs.

actualizare = {}
persoană = [("nume", "Cristina"), ("vârstă", 50), ("oraş", "Severin")]
for cheie, valoare in persoană:
    actualizare.update({cheie: valoare})
print(actualizare) ==> {'nume': 'Cristina', 'vârstă': 50, 'oraş': 'Severin'}

Metoda setdefault(): Această metodă vă permite să adăugați o cheie cu o valoare implicită numai dacă cheia nu există deja în dicționar. Dacă cheia există, aceasta returnează valoarea sa curentă fără a o modifica.

setdefault() Method: This method allows you to add a key with a default value only if the key does not already exist in the dictionary. If the key exists, it returns its current value without modifying it.

fructe = {"măr": 50}
for i in range(3):
    cheie = f"element_{i}"
    valoare_implicită = f"valoare_implicită_{i}"
    fructe.setdefault(cheie, valoare_implicită)  # Aceasta nu va schimba cheie_existentă
fructe.setdefault("măr", 20)
print(fructe)
==> {'măr': 50, 'element_0': 'valoare_implicită_0', 'element_1': 'valoare_implicită_1', 'element_2': 'valoare_implicită_2'}
  • Explicație:
  • Sintaxă validă pentru dicționar: Perechile cheie-valoare dintr-un dicționar trebuie să fie incluse între acolade {} și separate prin virgule. Cheile de tip șir de caractere, cum ar fi măr, trebuie să fie incluse între ghilimele.
  • Sintaxă validă pentru șiruri f: Șirurile f f"element_{i}" și f"valoare_implicită_{i}" formatează corect cheia și valoarea implicită prin încorporarea variabilei de buclă i în șiruri.
  • Metoda setdefault(): Metoda setdefault(cheie, valoare_implicită) verifică dacă cheia există în dicționar. Dacă cheia există, nu se întreprinde nicio acțiune. Dacă cheia nu există, inserează cheia cu valoarea implicită specificată.
  • Buclare: Bucla for i in range(3) execută corect blocul de cod inclus de trei ori (for i=0, i=1 și i=2), creând și adăugând noi perechi cheie-valoare în dicționarul fructe.
  • Explanation:
  • Valid dictionary syntax: Key-value pairs in a dictionary must be enclosed in curly braces {} and separated by commas. String keys, such as măr, must be enclosed in quotes.
  • Valid f-string syntax: The f-strings f"element_{i}" and f"valoare_implicită_{i}" correctly format the key and default value by embedding the loop variable i into the strings.
  • setdefault() method: The setdefault(key, default_value) method checks if key exists in the dictionary. If the key exists, no action is taken. If the key does not exist, it inserts the key with the specified default_value.
  • Looping: The for i in range(3) loop correctly executes the enclosed block of code three times (for i=0, i=1, and i=2), creating and adding new key-value pairs to the fructe dictionary.

Metoda clasei .fromkeys() - .fromkeys() Class Method

Sintaxă: dict.fromkeys(iterable, value=None)

Metoda dict.fromkeys() din Python este utilizată pentru a crea un nou dicționar dintr-un iterabil de chei și o valoare opțională.

Parametri:
iterabil: Un argument obligatoriu care specifică cheile noului dicționar. Acesta poate fi orice obiect iterabil, cum ar fi o listă, un tuplu, un set sau un șir de caractere.
valoare: Un argument opțional care specifică valoarea care va fi atribuită tuturor cheilor din noul dicționar. Dacă acest argument nu este furnizat, valoarea implicită atribuită fiecărei chei va fi None.
Funcționalitate:
Metoda fromkeys() iterează prin iterabilul furnizat și creează un nou dicționar în care fiecare element din iterabil devine o cheie. Fiecăreia dintre aceste chei i se atribuie apoi valoarea furnizată în al doilea argument. Dacă nu este dată nicio valoare, tuturor cheilor li se atribuie None.

The dict.fromkeys() method in Python is used to create a new dictionary from an iterable of keys and an optional value.

Parameters:
iterable: A required argument that specifies the keys of the new dictionary. This can be any iterable object like a list, tuple, set, or string.
value: An optional argument that specifies the value to be assigned to all keys in the new dictionary. If this argument is not provided, the default value assigned to each key will be None.
Functionality:
The fromkeys() method iterates through the provided iterable and creates a new dictionary where each element from the iterable becomes a key. Each of these keys is then assigned the value provided in the second argument. If no value is given, all keys are assigned None.
# Creați un dicționar cu chei dintr-o listă și o valoare implicită de None
lista_cheilor = ["măr", "pară", "cireșă", "caisă", "smochină"]
dicţionar_none = dict.fromkeys(lista_cheilor)
print(f"Dicţionar cu valori nule: {dicţionar_none}")
==> Dicţionar cu valori nule: {'măr': None, 'pară': None, 'cireșă': None, 'caisă': None, 'smochină': None}

# Creați un dicționar cu chei dintr-un tuplu și o valoare specifică
chei_culori = ('verede', 'galbenă', 'roșie', 'galbenă', "roz")
# Elimină duplicatele
dicţionar_culoare = dict.fromkeys(chei_culori, "culoare")
print(f"Dicţionar cu valori culoare: {dicţionar_culoare}")
==> Dicţionar cu valori culoare: {'verede': 'culoare', 'galbenă': 'culoare', 'roșie': 'culoare', 'roz': 'culoare'}

# Creați un dicționar dintr-un șir de caractere (fiecare caracter devine o cheie)
șirul_de_dicte = dict.fromkeys("python", 0)
print(f"Dicţionar cu valori zero: {șirul_de_dicte}")
==> Dicţionar cu valori zero: {'p': 0, 'y': 0, 't': 0, 'h': 0, 'o': 0, 'n': 0}

Atenție la obiectele mutabile - Attention to Mutable Object

Notă importantă privind valorile mutabile.
Atunci când se utilizează un obiect mutabil (cum ar fi o listă sau un dicționar) ca valoare în fromkeys(), toate cheile din noul dicționar vor face referire la același obiect mutabil. Modificarea acestui obiect printr-o cheie va afecta valoarea asociată cu toate celelalte chei. Pentru a evita acest lucru și a vă asigura că fiecare cheie are propriul obiect mutabil independent, ar trebui utilizată o înțelegere (comprehension) sau o buclă pentru a crea dicționarul.
Important Note on Mutable Values.
When using a mutable object (like a list or dictionary) as the value in fromkeys(), all keys in the new dictionary will reference the same mutable object. Modifying this object through one key will affect the value associated with all other keys. To avoid this and ensure each key has its own independent mutable object, a dictionary comprehension or a loop should be used to create the dictionary.
# Crearea unui dicționar cu liste goale pentru gestionarea mai multor chei
chei = ["dimineață", "după-amiază"]
programare = dict.fromkeys(chei, [])

# Adăugarea unei activități la cheia "după-amiază" modifică ambele chei
programare["după-amiază"].append("studiu")

print(programare)

==> {'dimineață': ['studiu'], 'după-amiază': ['studiu']}

chei = ["dimineață", "după-amiază"]

programare = {cheie: [] for cheie in chei}

# Modifică numai cheia "după-amiază" 
programare["după-amiază"].append("studiu")

print(programare)
==> {'dimineață': [], 'după-amiază': ['studiu']}


chei = ["dimineață", "după-amiază"]
programare = {}

for cheie in chei:
    programare[cheie] = []

# Adăuga activități la chei în mod independent
programare["după-amiază"].append("studiu")
print(programare)
==> {'dimineață': [], 'după-amiază': ['studiu']}

Dicționar din Diferența Simetrică - Dictionary from Symmetric Difference

Python Set symmetric_difference() Method

În Python, diferența simetrică a două mulțimi este o mulțime nouă ce conține toate elementele prezente în oricare dintre cele două mulțimi, dar nu în ambele. În esență, aceasta elimină intersecția (elementele comune) și păstrează elementele unice din fiecare mulțime.

Metoda .symmetric_difference() permite ca argumentul să fie orice obiect iterabil (precum o listă, un tuplu sau un dicționar). Python va converti automat acel obiect iterabil într-o mulțime, în fundal, pentru a efectua comparația.

Așadar, pentru a obține un dicționar nou care să conțină perechile cheie-valoare ale căror chei se află în diferența simetrică a cheilor dicționarelor originale, puteți itera prin chei unice și puteți recupera valorile corespunzătoare din dicționarele originale.

In Python, the symmetric difference of two sets is a new set containing all elements that are present in either of the sets, but not in both. Essentially, it removes the intersection (common elements) and keeps the unique elements from each set.

The .symmetric_difference() Method allows the argument to be any iterable (like a list, tuple, or dictionary). Python will automatically convert that iterable into a set behind the scenes to perform the comparison.

Therefore, to obtain a new dictionary containing the key-value pairs whose keys are in the symmetric difference of the original dictionaries' keys, you can iterate through the unique keys and retrieve the corresponding values from the original dictionaries.

dict1 = {'a': 1, 'b': 2, 'c': 3}
dict2 = {'c': 4, 'd': 5, 'e': 6}

chei_in_a = set(dict1.keys())
chei_in_b = set(dict2.keys())
chei_unice = chei_in_a.symmetric_difference(chei_in_b)

symmetric_diff_dict = {}
for cheie in chei_unice:
    if cheie in dict1:
        symmetric_diff_dict[cheie] = dict1[cheie]
    elif cheie in dict2:
        symmetric_diff_dict[cheie] = dict2[cheie]

print(symmetric_diff_dict) ==> {'b': 2, 'd': 5, 'e': 6, 'a': 1}

Identifică dicționarul din care inițial provin cheile unice - Find which dictionary the unique keys originally came from.

dict1 = {'a': 1, 'b': 2, 'c': 3}
dict2 = {'c': 4, 'd': 5, 'e': 6}

# Identifică cheile unice pentru fiecare parte
în_dict1 = dict1.keys() - dict2.keys()
în_dict2 = dict2.keys() - dict1.keys()

# Asociază cheile unice cu etichetele sursă corespunzătoare
originea_cheilor = {
    **{k: 'dict1' for k in în_dict1},
    **{k: 'dict2' for k in în_dict2}
}

print(originea_cheilor) ==> {'b': 'dict1', 'a': 'dict1', 'd': 'dict2', 'e': 'dict2'}
  • Condiții pentru următoarele două exemple:
  • Pentru a utiliza .symmetric_difference, una dintre vizualizările cheie trebuie convertită într-o mulțime.
  • Trebuie să convertiți doar primul obiect, metoda acceptă ca argument vizualizarea obișnuită dict_keys a lui dict2.
  • Conditions for the next two examples:
  • To use .symmetric_difference, one of the key views must be converted into a set.
  • You only need to convert the first object, the method accepts the regular dict_keys view of dict2 as its argument.

Compunere condițională de dicționar (pe un singur rând) - Conditional Dict Comprehension (Single Line)

dict1 = {'a': 1, 'b': 2, 'c': 3}
dict2 = {'c': 4, 'd': 5, 'e': 6}
set_1 = set(dict1.keys())

# Iterarea prin diferența simetrică a cheilor
originea_cheilor = {k: ('dict1' if k in dict1 else 'dict2') for k in set_1.symmetric_difference(dict2.keys())}
print(originea_cheilor) ==> {'b': 'dict1', 'e': 'dict2', 'a': 'dict1', 'd': 'dict2'}

Păstrarea valorilor originale alături de origine - Preserving Original Values alongside the Origin.

dict1 = {'a': 1, 'b': 2, 'c': 3}
dict2 = {'c': 4, 'd': 5, 'e': 6}
set_1 = set(dict1.keys())

# Stochează atât valoarea, cât și numele sursei sub formă de tuplu
cheie_valoare_origine = {
    k: (dict1[k], 'dict1') if k in dict1 else (dict2[k], 'dict2') 
    for k in set_1.symmetric_difference(dict2.keys())
}

print(cheie_valoare_origine)
==> {'e': (6, 'dict2'), 'd': (5, 'dict2'), 'b': (2, 'dict1'), 'a': (1, 'dict1')}

Adăugare, actualizare, implicit în dicționar - Add, update, default to Dictionary

Utilizarea notației parantezelor pătrate (atribuire): Aceasta este cea mai comună și simplă metodă pentru adăugarea unei singure perechi cheie-valoare. Dacă cheia există deja, valoarea acesteia va fi actualizată; în caz contrar, se adaugă o nouă pereche cheie-valoare.

Using Square Bracket Notation (Assignment): This is the most common and straightforward method for adding a single key-value pair. If the key already exists, its value will be updated; otherwise, a new key-value pair is added. 

persoană = {"nume":"Virgil"}

# Adaugă o nouă pereche cheie-valoare
persoană["vârstă"] = 30
print(persoană) ==> {'nume': 'Virgil', 'vârstă': 30}

Utilizarea metodei update(): Această metodă permite adăugarea mai multor perechi cheie-valoare simultan sau îmbinarea unui alt dicționar cu unul existent.

Using the update() Method: This method allows adding multiple key-value pairs at once or merging another dictionary into an existing one.

maşină = {"marca": "Dacia"}
culoare = {"culoare": "roşu"}

# Adaugă mai multe articole
maşină.update({"model": "Duster", "anul": 2006})
maşină.update(culoare)
print(maşină) ==> {'marca': 'Dacia', 'model': 'Duster', 'anul': 2006, 'culoare': 'roşu'}

Utilizarea metodei setdefault(): Această metodă adaugă o pereche cheie-valoare numai dacă cheia nu există deja în dicționar. Dacă cheia există, returnează valoarea curentă asociată acelei chei fără a o modifica.

Using the setdefault() Method: This method adds a key-value pair only if the key does not already exist in the dictionary. If the key exists, it returns the current value associated with that key without modifying it. 

oraşe = {"oraş": "Turnu Severin"}

# Adaugă dacă populația nu există
oraşe.setdefault("populație", 79865)

# oraș există deja, nicio modificare
oraşe.setdefault("oraş", "Craiova")
print(oraşe) ==> {'oraş': 'Turnu Severin', 'populație': 79865}
Dicționar despachetare (operator cu asterisc dublu **)
Această metodă creează un dicționar nou care conține perechile cheie-valoare combinate. Dacă există chei duplicate, valoarea din dicționarul din dreapta, în ordinea de despachetare, va suprascrie valorile anterioare.
Dictionary Unpacking (Double Asterisk Operator **)
This method creates a new dictionary containing the combined key-value pairs. If duplicate keys exist, the value from the rightmost dictionary in the unpacking order will overwrite previous values.
dict1 = {'a': 1, 'b': 2}
dict2 = {'c': 3, 'd': 4}
dict3 = {'b': 5, 'e': 6}

dicționare_combinate = {**dict1, **dict2, **dict3}
print(dicționare_combinate) ==> {'a': 1, 'b': 5, 'c': 3, 'd': 4, 'e': 6}
Metoda update()
Metoda update() modifică un dicționar existent prin adăugarea de perechi cheie-valoare dintr-un alt dicționar sau dintr-un iterabil de perechi cheie-valoare. Dacă există chei duplicate, valorile din dicționarul actualizat suprascriu valorile originale.
update() Method
The update() method modifies an existing dictionary by adding key-value pairs from another dictionary or an iterable of key-value pairs. If duplicate keys exist, the values from the updated dictionary overwrite the original values.
dict1 = {'a': 1, 'b': 2}
dict2 = {'c': 3, 'd': 4}
dict3 = {'b': 5, 'e': 6}

dict1.update(dict2)
dict1.update(dict3)
print(dict1)  ==> {'a': 1, 'b': 5, 'c': 3, 'd': 4, 'e': 6}
Operator de îmbinare (|) - Python 3.9+
Introdus în Python 3.9, operatorul | oferă o modalitate concisă de a îmbina dicționarele, creând un dicționar nou fără a modifica originalele. Similar despachetării, valorile din dreapta le suprascriu pe cele anterioare pentru cheile duplicate.
Merge Operator (|) - Python 3.9+
Introduced in Python 3.9, the | operator provides a concise way to merge dictionaries, creating a new dictionary without modifying the originals. Similar to unpacking, rightmost values overwrite previous ones for duplicate keys.
dict1 = {'a': 1, 'b': 2}
dict2 = {'c': 3, 'd': 4}
dict3 = {'b': 5, 'e': 6}

merge_dict = dict1 | dict2 | dict3
print(merge_dict) ==> {'a': 1, 'b': 5, 'c': 3, 'd': 4, 'e': 6}

Operatorul |= din Python, introdus în versiunea 3.9, oferă o modalitate concisă de a îmbina dicționarele in pe loc. Aceasta înseamnă că modifică direct dicționarul din partea stângă a operatorului, în loc să creeze un dicționar nou.

Cum funcționează: Când utilizați dict1 |= dict2, perechile cheie-valoare din dict2 sunt îmbinate în dict1. Dacă există o cheie în ambele dicționare, valoarea din dict2 (operandul din dreapta) va suprascrie valoarea din dict1. Dacă o cheie există doar în dict2, aceasta va fi adăugată la dict1.

Alternativă la update(): Oferă o sintaxă mai compactă pentru aceeași funcționalitate ca dict.update().

The |= operator in Python, introduced in version 3.9, provides a concise way to merge dictionaries in-place. This means it modifies the dictionary on the left side of the operator directly, rather than creating a new dictionary.

How it works: When you use dict1 |= dict2, the key-value pairs from dict2 are merged into dict1. If a key exists in both dictionaries, the value from dict2 (the right-hand operand) will overwrite the value in dict1. If a key exists only in dict2, it will be added to dict1.

Alternative to update(): It provides a more compact syntax for the same functionality as dict.update().

dict1 = {'a': 1, 'b': 2}
dict2 = {'b': 3, 'c': 4}

dict1 |= dict2

print(dict1) ==> {'a': 1, 'b': 3, 'c': 4}

Modulul ChainMap din colecții.
ChainMap oferă o modalitate de a combina mai multe dicționare într-o singură vizualizare actualizabilă. Nu creează un dicționar nou, ci mai degrabă un lanț în care căutările au loc în ordinea dicționarelor furnizate.
Modificările (adăugarea, actualizarea sau ștergerea unei chei) vizează întotdeauna doar primul dicționar din lanț.
Deoarece conține referințe la dicționarele subiacente, orice modificare directă adusă acelor dicționare sursă se reflectă instantaneu în ChainMap.
ChainMap from collections Module.
ChainMap provides a way to combine multiple dictionaries into a single, updatable view. It doesn't create a new dictionary but rather a "chain" where lookups happen in order of the provided dictionaries.
Mutating operations (adding, updating, or deleting a key) always target only the first dictionary in the chain
Because it holds references to the underlying dictionaries, any direct change made to those source dictionaries instantly reflects in the ChainMap.
from collections import ChainMap

dict1 = {'a': 1, 'b': 2}
dict2 = {'c': 3, 'd': 4}
dict3 = {'b': 5, 'e': 6}

# Ordinea contează pentru căutări
îmbinare_chainmap = ChainMap(dict1, dict3, dict2)
print(îmbinare_chainmap) ==> ChainMap({'a': 1, 'b': 2}, {'b': 5, 'e': 6}, {'c': 3, 'd': 4})

# Accesează vlaoarea lui b
print(f"Valoarea lui b este {îmbinare_chainmap['b']}") ==> Valoarea lui b este 2
print(f"Valoarea lui b din îmbinare_chainmap este egală cu valoarea lui b din dict3: {îmbinare_chainmap['b'] == dict3['b']}")
==> Valoarea lui b din îmbinare_chainmap este egală cu valoarea lui b din dict3: False
