Fracții (fractions.Fraction) - Fractions (fractions.Fraction)

fractions — Rational numbers

fractions-realpython

fractions.Fraction din modulul de fracții din Python oferă o modalitate de a reprezenta și efectua operații aritmetice cu numere raționale, numere care pot fi exprimate ca raportul a două numere întregi (numărător și numitor). Acest lucru permite calcule precise, evitând potențialele inexactități asociate cu numerele în virgulă mobilă.

fractions.Fraction in Python's fractions module provides a way to represent and perform arithmetic operations with rational numbers, which are numbers that can be expressed as a ratio of two integers (numerator and denominator). This allows for precise calculations, avoiding the potential inaccuracies associated with floating-point numbers.

from fractions import Fraction

# Din numere întregi
fracţia1 = Fraction(3, 4)  # Reprezintă 3/4
fracţia2 = Fraction(5)     # Reprezintă 5/1 (implicit numitorul este 1)

# Din numere zecimale (cu potențiale probleme de precizie)
fracţia3 = Fraction(0.75)   # Reprezintă 3/4
fracţia4 = Fraction(0.1)    # Poate duce la o fracție mai puțin intuitivă din cauza reprezentării cu număr zecimal

# Din şiruri
fracţia5 = Fraction("1/2")  # Reprezintă 1/2
fracţia6 = Fraction("2.5")  # Reprezintă 5/2

# Din numere cu virgulă sau zecimale (cu atenție la precizie)
fracţia7 = Fraction.from_float(0.75) # Reprezintă 3/4

print(fracţia4) 
==> 3602879701896397/36028797018963968

Operații aritmetice - Arithmetic Operations

Obiectele fracționale acceptă operații aritmetice standard ca (+, -, *, /) cu alte obiecte fracționale, numere întregi, numere cu virgulă mobilă și obiecte zecimale.

Fraction objects support standard arithmetic operations as (+, -, *, /) with other Fraction objects, integers, floats, and Decimal objects.

from fractions import Fraction

adunare = Fraction(1, 3) + Fraction(2, 3)
înmulțire_intreg = Fraction(2, 5) * 3
înmulțire_fracții = Fraction(2, 3) * Fraction(1, 3)

print(adunare)           ==> 1
print(înmulțire_intreg)  ==> 6/5
print(înmulțire_fracții) ==> 2/9

metoda limit_denominator() - limit_denominator() method

Metoda limit_denominator() din Python, parte a modulului fractions, este utilizată pentru a găsi cea mai apropiată aproximare rațională a unui obiect Fraction dat, cu un numitor mai mic sau egal cu o valoare maximă specificată.

The limit_denominator() method in Python, part of the fractions module, is used to find the closest rational approximation of a given Fraction object with a denominator less than or equal to a specified maximum value.

Funcționalitate:
Acesta primește un argument opțional max_denominator, care implicit este 1.000.000 dacă nu este furnizat.
Returnează un nou obiect Fraction care este cea mai bună aproximare rațională a fracției originale, unde numitorul noii fracții nu depășește max_denominator.
Această metodă este utilă în special pentru:
Aproximarea numerelor în virgulă mobilă: Conversia unui număr în virgulă mobilă potențial imprecis într-o fracție mai ușor de citit și mai exactă din punct de vedere matematic.
Recuperarea numerelor raționale din numere cu virgulă mobilă: Dacă un număr cu virgulă mobilă provine dintr-o fracție simplă, limit denominator() poate adesea reconstrui acea fracție originală.
Functionality:
It takes an optional argument max_denominator, which defaults to 1,000,000 if not provided.
It returns a new Fraction object that is the best rational approximation of the original fraction, where the denominator of the new fraction does not exceed max_denominator.
This method is particularly useful for:
Approximating floating-point numbers: Converting a potentially imprecise floating-point number into a more readable and mathematically exact fraction.
Recovering rational numbers from floats: If a float originated from a simple fraction, limit denominator() can often reconstruct that original fraction.

as_integer_ratio()

Metoda as_integer_ratio() este utilizată pentru a reprezenta un număr în virgulă mobilă sau o instanță Decimală ca o fracție în termenii săi cei mai simpli, constând dintr-un numărător și un numitor.

The as_integer_ratio() method is used to represent a floating-point number or a Decimal instance as a fraction in its lowest terms, consisting of a numerator and a denominator.

from fractions import Fraction

fracție = Fraction(3, 7)
numărător, numitor = fracție.as_integer_ratio()
print(f"Numărător: {numărător}, Numitor: {numitor}") ==> Numărător: 3, Numitor: 7

raport = Fraction(15/16).as_integer_ratio()
print(f"(Numărător, Numitor): {raport}")  ==> (Numărător, Numitor): (15, 16)

fracție_negativ = Fraction(-5, 10)
print(f"(Numărător, Numitor): {fracție_negativ.as_integer_ratio()}") ==> (Numărător, Numitor): (-1, 2)

fracție_nesimplificată = Fraction(10, 20)
print(f"(Numărător, Numitor): {fracție_nesimplificată.as_integer_ratio()}") ==> (Numărător, Numitor): (1, 2)
Scop:
Reprezentare exactă: Permite obținerea unei reprezentări fracționare exacte a numerelor, în special a numărului cu virgulă mobilă, care sunt în mod inerent aproximative.
Uniformitate: Oferă o interfață API consistentă între diferite tipuri numerice pentru extragerea raportului lor întreg.
Interoperabilitate: Facilitează operațiunile și conversiile între diferite tipuri numerice, de exemplu, la crearea unei fracții dintr-un număr cu virgulă mobilă sau zecimal.
Purpose:
Exact Representation: It enables obtaining an exact fractional representation of numbers, especially floats, which are inherently approximate.
Uniformity: It provides a consistent API across different numeric types for extracting their integer ratio.
Interoperability: It facilitates operations and conversions between different numeric types, for instance, in creating a Fraction from a float or Decimal.

from_float(flt)

O metodă de clasă pentru a construi o fracție reprezentând valoarea exactă a unui număr cu virgulă.
A class method to construct a Fraction representing the exact value of a float.

from fractions import Fraction
fracție_exactă = Fraction.from_float(0.5) 
fracția_mea = Fraction.from_float(0.2)
print(fracție_exactă) ==> 1/2
print(fracția_mea)    ==> 3602879701896397/18014398509481984

Luați în considerare precizia în virgulă mobilă: Este important de reținut că Fraction.from_float() reprezintă valoarea exactă a numărului cu virgulă mobilă așa cum este stocată în memorie. Datorită naturii reprezentării în virgulă mobilă, aceasta poate să nu fie întotdeauna fracția zecimală exactă la care v-ați aștepta intuitiv.

Consider floating-point precision: It is important to note that Fraction.from_float() represents the exact value of the float as stored in memory. Due to the nature of floating-point representation, this may not always be the exact decimal fraction you might intuitively expect.

fracția_mea = Fraction.from_float(0.3)
print(fracția_mea)  ==> 5404319552844595/18014398509481984

Dacă trebuie să reprezentați un număr zecimal ca o fracție exact așa cum este scris, se recomandă în general să construiți fracția dintr-un șir de caractere sau direct de la numărător și numitor, mai degrabă decât dintr-un număr cu zecimale.

If you need to represent a decimal number as a Fraction exactly as written, it is generally recommended to construct the Fraction from a string or from its numerator and denominator directly, rather than from a float. 

from fractions import Fraction

# Reprezentare exactă din numărător și numitor
fracție_exactă_din_componente = Fraction(7, 10)
print(f"Din părți: {fracție_exactă_din_componente}") ==> 7/10

# Comparație cu from_float
print(f"Din float: {Fraction.from_float(0.7)}") ==> 3152519739159347/4503599627370496

Aproximare pentru un rezultat ușor de utilizat: Dacă aveți nevoie de o reprezentare fracționară mai ușor de utilizat a unui număr cu zecimale (de exemplu, ceva apropiat de 3/10 pentru 0,3), puteți lua în considerare convertirea mai întâi a numărului într-un șir de caractere și apoi utilizarea constructorului bazat pe șiruri de caractere sau utilizarea metodei limit_denominator().

Approximation for User-Friendly Output: If you need a more user-friendly fractional representation of a float (e.g., something close to 3/10 for 0.3), you might consider converting the float to a string first and then using the string-based constructor, or using the limit_denominator() method.

Rounding

Funcția round() încorporată poate fi utilizată pentru a rotunji un număr cu virgulă mobilă, dar nu poate fi utilizată direct cu un obiect Fraction din modulul de fracții Python. Funcția round() este concepută pentru tipuri numerice precum float și int, nu pentru obiecte personalizate precum Fraction, așa că va trebui mai întâi să convertiți Fraction într-un număr cu virgulă mobilă pentru a o utiliza.

Built-in round() function can be used to round a floating-point number, but it cannot be directly used with a Fraction object from Python's fractions module. The round() function is designed for numerical types like float and int, not for custom objects like Fraction, so you would first need to convert the Fraction to a float to use it.

Cum se rotunjește o fracție.
Convertiți fracția într-un număr cu virgulă mobilă: Folosiți constructorul float() pentru a converti obiectul Fraction într-un număr standard cu virgulă mobilă.
Folosiți funcția round(): Aplicați funcția round() la numărul cu virgulă mobilă rezultat pentru a-l rotunji la cel mai apropiat număr întreg sau la un număr specificat de zecimale.
How to round a Fraction.
Convert the Fraction to a float: Use the float() constructor to convert your Fraction object into a standard floating-point number.
Use the round() function: Apply the round() function to the resulting float to round it to the nearest integer or a specified number of decimal places.
from fractions import Fraction

Zecimale (decimal.Decimal)-Decimals (decimal.Decimal)

decimal — Decimal fixed-point and floating-point arithmetic

Crearea obiectelor zecimale.
Obiectele zecimale sunt de obicei create din șiruri de caractere sau numere întregi pentru a evita potențialele inexactități ale conversiei dintr-un număr cu virgulă mobilă.
Modulul zecimal din Python oferă suport pentru aritmetica zecimală cu virgulă fixă ​​și cu virgulă mobilă. Este util în special pentru aplicațiile care necesită o reprezentare zecimală exactă, cum ar fi calculele financiare, unde imprecizia inerentă a numerelor binare cu virgulă mobilă (tip float) poate duce la inexactități.
Principala diferență dintre reprezentările numerice zecimale cu virgulă fixă ​​și cele cu virgulă mobilă constă în modul în care punctul zecimal (baza zecimală) este poziționat și gestionat în timpul calculelor.
Într-un sistem cu virgulă fixă, punctul zecimal rămâne într-o poziție prestabilită și neschimbabilă. Într-un sistem cu virgulă mobilă, punctul zecimal "plutește" sau se deplasează în mod dinamic, deoarece numerele sunt exprimate folosind o parte semnificativă (mantisă) și un exponent, similar notației științifice.
Creating Decimal Objects:
Decimal objects are typically created from strings or integers to avoid the potential inaccuracies of converting from float.
The decimal module in Python provides support for decimal fixed-point and floating-point arithmetic. It is particularly useful for applications requiring exact decimal representation, such as financial calculations, where the inherent imprecision of binary floating-point numbers (float type) can lead to inaccuracies.
The primary difference between decimal fixed-point and floating-point numeric representations is how the radix (decimal) point is positioned and managed during calculations.
In a fixed-point system, the decimal point stays in a predetermined, unchangeable position. In a floating-point system, the decimal point dynamically "floats" or moves around because numbers are expressed using a significand (mantissa) and an exponent, similar to scientific notation.
from decimal import Decimal

# Crearea unui obiect Decimal dintr-un șir de caractere pentru o reprezentare precisă
num1 = Decimal("0.1")
num2 = Decimal("0.2")
decimal1 = Decimal("10.123")
decimal2 = Decimal(7) 
decimal3 = num1 + num2

print(decimal1) ==> 10.123
print(decimal2) ==> 7
print(decimal3, type(decimal3)) ==> 0.3 <class 'decimal.Decimal'>

# Numere cu virgulă mobilă standard
resultat_standard = 0.1 + 0.2
print(resultat_standard) ==> 0.30000000000000004

Explanation:
from decimal import Decimal: This statement imports the Decimal class specifically from the decimal module. This allows direct use of Decimal without needing to prefix it with decimal.
Decimal("0.1"): When creating Decimal objects, it is recommended to initialize them with strings to avoid the inherent floating-point inaccuracies that can occur when using float literals directly.
num1 + num2: Arithmetic operations performed on Decimal objects will maintain the precision and rounding rules defined by the current decimal context.

Controlul preciziei.

Modulul zecimal vă permite să controlați precizia calculelor folosind funcțiile getcontext() și localcontext().

Modulul zecimal folosește un "context" pentru a determina precizia și regulile de rotunjire. În mod implicit, precizia este de 28 de cifre, dar o puteți modifica.

Precizie globală: getcontext().prec setează precizia implicită pentru toate operațiile zecimale ulterioare.

Precizie locală: localcontext() oferă un manager de context pentru a seta temporar precizia pentru un bloc de cod, fără a afecta setările globale.

Precision Control.

The decimal module allows you to control the precision of calculations using the getcontext() and localcontext() functions.

The decimal module uses a "context" to determine precision and rounding rules. By default, the precision is 28 digits, but you can change it.

Global Precision: getcontext().prec sets the default precision for all subsequent Decimal operations.

Local Precision: localcontext() provides a context manager to temporarily set precision for a block of code, without affecting global settings.

from decimal import Decimal, getcontext

# Vizualizați contextul implicit
print(f"Precizie implicită: {getcontext().prec}")   ==> 28

# Setați precizia pentru toate calculele ulterioare
getcontext().prec = 6                               
result = Decimal('1') / Decimal('7')
print(f"Rezultat cu noua precizie: {result}") ==> 0.142857

# Resetarea preciziei la valoarea implicită
getcontext().prec = 28
result = Decimal('1') / Decimal('7')
print(f"Rezultat cu precizie implicită: {result}")  ==> 0.1428571428571428571428571429

from decimal import localcontext

with localcontext(prec=3):
    rezultat = Decimal(72) / Decimal(7)
    print(rezultat) ==> 10.3

rotunjire.
Modulul zecimal oferă diverse moduri de rotunjire, care pot fi setate în context. De exemplu, ROUND_HALF_EVEN este modul implicit, unde numerele care se termină în 0,5 sunt rotunjite la cea mai apropiată cifră pară.

rounding.
The decimal module provides various rounding modes, which can be set in the context. For example, ROUND_HALF_EVEN is the default, where numbers ending in .5 are rounded to the nearest even digit.

Decimal.as_integer_ratio()

as_integer_ratio() oferă o reprezentare exactă sub formă de fracție, ceea ce poate fi util pentru evitarea inexactităților în virgulă mobilă (floating-point).

as_integer_ratio() provides an exact representation as a fraction, which can be useful for avoiding floating-point inaccuracies.

from decimal import Decimal

d = Decimal('0.1')
numărător, numitor = d.as_integer_ratio()
print(f"{d} ca raport întreg: {numărător}/{numitor}") ==> 0.1 ca raport întreg: 1/10
