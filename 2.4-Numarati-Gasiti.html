len(string)

Funcția len() din Python este o funcție încorporată care returnează lungimea (numărul de elemente) unui obiect. Poate fi utilizată cu diverse tipuri de date, inclusiv șiruri de caractere. Când este aplicată unui șir de caractere, returnează numărul de caractere din acel șir. Funcția len() este un instrument fundamental pentru lucrul cu secvențe și colecții în Python, oferind o modalitate simplă de a determina dimensiunea acestora. Pentru a afla lungimea unui șir de caractere, transmiteți șirul ca argument funcției len().

The len() function in Python is a built-in function that returns the length (the number of items) of an object. It can be used with various data types, including strings. When applied to a string, it returns the number of characters in that string. The len() function is a fundamental tool for working with sequences and collections in Python, providing a simple way to determine their size. To find the length of a string, you pass the string as an argument to the len() function.

# Utilizare de bază
# Rețineți că spațiul, virgula și semnul exclamării sunt toate considerate caractere în lungime.

lungime = len(șirul_meu)
print(f"Utilizare de bază: {lungime} de caractere") ==> ... 23 de caractere

# Șir gol
șir_gol = ""
print(f"Lungimea unui șir gol: {len(șir_gol)}") ==> Lungimea unui șir gol: 0

# Șir de caractere cu spații la început și sfârșit
frază = " Salut, programatorilor! "
print(f"Lungimea unui șir cu spații: {len(frază)}") ==> Lungimea unui șir cu spații: 25

Funcția len() numără toate spațiile albe. Dacă doriți să eliminați spațiile de la început/sfârșit înainte de numărare, puteți utiliza metoda de șir .strip():

The len() function counts all whitespace characters. If you want to remove leading/trailing spaces before counting, you can use the .strip() string method:

print(f"Lungimea frază2 fară spații la început și la sfârșit: {lungime_redusă}") ==> ...: 31

Pentru șiruri de caractere, numără fiecare caracter, inclusiv spații, numere și caractere speciale.
Returnează un număr întreg care reprezintă lungimea.
Key Points:
len() works on various container-like objects in Python, including strings, lists, tuples, and dictionaries.
For strings, it counts every character, including spaces, numbers, and special characters.
It returns an integer representing the length.

Python String find() Method

Metoda find() din Python este o metodă de tip șir de caractere utilizată pentru a localiza cel mai mic indice (prima apariție) a unui subșir specific dintr-un șir dat.

Valoare returnată:
Metoda returnează un număr întreg care reprezintă cel mai mic indice din șirul în care se găsește subșirul.
Dacă subșirul nu este găsit în intervalul specificat (sau în întregul șir dacă start și end nu sunt furnizate), metoda returnează -1.

find() method in Python is a string method used to locate the lowest index (first occurrence) of a specific substring within a given string.

Parameters:

Python String index() Method

Metoda index() este similară cu find(), returnând indicele inițial al primei apariții a unui subșir. Dacă subșirul nu este găsit, index() generează o eroare ValueError în loc să returneze -1. index() este sensibilă la majuscule/minuscule.

Parametri:

start (opțional): Indicele inițial al căutării în șir. Dacă este omis, căutarea începe de la începutul șirului (indice 0).
end (opțional): Indicele final al căutării în șir. Dacă este omis, căutarea continuă până la sfârșitul șirului.
Valoare returnată:
Dacă subșirul este găsit, metoda index() returnează cel mai mic indice de unde începe subșirul.
Generează:
Dacă subșirul nu este găsit în intervalul specificat, metoda index() generează o eroare ValueError.

index() method is similar to find(), returning the starting index of the first occurrence of a substring. If the substring is not found, index() raises a ValueError instead of returning -1. index() is case-sensitive.

Parameters:
sub: The substring to search for within the string.
start (optional): The starting index of the search within the string. If omitted, the search begins from the start of the string (index 0).
end (optional): The ending index of the search within the string. If omitted, the search continues to the end of the string.
Return Value:
If the substring is found, the index() method returns the lowest index where the substring begins.
Generate:
If the substring is not found within the specified range, the index() method raises a ValueError.

Python String split() Method

Metoda split(), atunci când este apelată cu sep=None și maxsplit=-1, împarte un șir într-o listă de subșiruri.

Parametrii
sep=None: Acesta este comportamentul implicit. Când sep este None (sau nu este specificat), șirul este împărțit prin orice spațiu alb (spații, tabulatori, linii noi etc.), iar spațiile albe consecutive sunt tratate ca un singur separator. În plus, șirurile goale care ar putea rezulta din spațiile albe la început/sfârșit sau din separatoarele consecutive multiple sunt eliminate automat din lista rezultată.
maxsplit=-1: Acesta este, de asemenea, comportamentul implicit. Când maxsplit este -1 (sau nu este specificat), nu există o limită a numărului de divizări efectuate. Șirul va fi împărțit la fiecare apariție a separatorului.
Valoare returnată:
Metoda split() returnează o listă de șiruri, care sunt subșirurile rezultate din operațiunea de divizare.

split() method, when called with sep=None and maxsplit=-1, splits a string into a list of substrings.

Parameters
sep=None: This is the default behavior. When sep is None (or not specified), the string is split by any whitespace (spaces, tabs, newlines, etc.), and consecutive whitespace characters are treated as a single separator. Additionally, empty strings that might result from leading/trailing whitespace or multiple consecutive separators are automatically removed from the resulting list.
maxsplit=-1: This is also the default behavior. When maxsplit is -1 (or not specified), there is no limit to the number of splits performed. The string will be split at every occurrence of the separator.
Return Value:
The split() method returns a list of strings, which are the substrings resulting from the split operation.
# Împărțirea prin spații albe implicite
text = "  Salut   lume\nPython este   grozav.  "
cuvinte = text.split()
print(cuvinte)         ==> ['Salut', 'lume', 'Python', 'este', 'grozav.']

# Împărțirea după spații albe (comportament implicit).
text = "Python este un limbaj versatil"
rezultat = text.split()
print(rezultat)         ==> ['Python', 'este', 'un', 'limbaj', 'versatil']

# Separarea cu un separator specific
şir_fructe = "măr, pară, cireșă, caisă, smochină, prună, piersică, strugure"
fructe = şir_fructe.split(", ")
print(fructe)           ==> ['măr', 'pară', 'cireșă', 'caisă', 'smochină', 'prună', 'piersică', 'strugure']

Note that consecutive delimiters will insert empty strings into the list. A multi-character string can also be used as a separator. The maxsplit parameter limits the number of splits. For example, maxsplit=3 will result in at most 4 elements in the list.

Substring Check: The "in" operator determines if a sequence of characters (the substring) exists anywhere within another sequence of characters (the main string).
Boolean Result: It always returns a boolean value (True or False).
Case Sensitivity: The check is case-sensitive by default. To ignore case, convert both strings to the same case using .lower() or .upper().

Operatorul not in: Operatorul "not in" este inversul lui "in", returnând True dacă subșirul nu este găsit și False dacă este găsit.

not in Operator: The "not in" operator is the inverse of "in", returning True if the substring is not found and False if it is found.

print("epure" not in text_câine_pisică) ==> True
Comportamentul între tipurile de date
Comportamentul și performanța operatorului in variază în funcție de structura de date pe care o interogați:
Liste și tupluri: Scanează secvențial de la început până la sfârșit (complexitate temporală O(n)).
Șiruri: Verifică dacă există un subșir specific în interiorul șirului mai mare.
Dicționare: Verifică exclusiv cheile potrivite, nu valorile (complexitate temporală medie O(1)).
Seturi: Folosește hashing-ul pentru căutare aproape instantanee (complexitate temporală medie O(1))
Distincții cheie
Operatorul invers: Îl puteți combina în not in pentru a verifica în mod clar dacă un element este complet absent dintr-o colecție.
Cuvânt cheie operator vs. buclă: Nu confundați valoarea în colecție (operatorul de apartenență) cu valoarea for în colecție: Într-o buclă for, in servește doar ca sintaxă pentru a direcționa iterația buclei.
Sub acoperire: Când executați x în y, Python încearcă să apeleze metoda magică a containerului y.__contains__(x). Dacă aceasta nu există, se revine la iterarea manuală a colecției.
Behavior Across Data Types
The behavior and performance of the in operator vary depending on the data structure you are querying:
Lists & Tuples: Scans sequentially from start to finish (O(n) time complexity).
Strings: Checks if a specific substring exists inside the larger string.
Dictionaries: Checks exclusively for matching keys, not values (O(1) average time complexity).
Sets: Uses hashing for near-instant lookup (O(1) average time complexity)
Key Distinctions
The Inverse Operator: You can combine it into not in to cleanly verify if an item is completely absent from a collection.
Operator vs. Loop Keyword: Do not confuse value in collection (the membership operator) with for value in collection: In a for loop, in serves purely as syntax to direct the loop's iteration.
Under the Hood: When you execute x in y, Python attempts to call the container's magic method y.__contains__(x). If that does not exist, it falls back to iterating through the collection manually.
