Număr cu virgulă - Floating number(float)

Reprezintă numere reale, inclusiv cele cu părți fracționare. Acestea pot fi scrise în formă zecimală standard sau în notație științifică folosind e sau E pentru a indica o putere a lui 10.

Numerele cu virgulă mobilă standard din Python sunt de obicei numere cu precizie dublă, oferind o precizie de până la aproximativ 15 zecimale.

Compararea directă a numerelor cu virgulă mobilă poate duce uneori la rezultate neașteptate din cauza problemelor de precizie a numerelor cu virgulă mobilă.

Represent real numbers, including those with fractional parts. They can be written in standard decimal form or in scientific notation using e or E to indicate a power of 10.

Standard Python floats are typically double-precision numbers, offering accuracy up to about 15 decimal places.


Directly comparing floats can sometimes lead to unexpected results due to floating-point precision issues.

Exemplu: 3.14, -0.5, 2.0, 2,5e2

Numerele cu virgulă literale - Floating literals

Literalii în virgulă mobilă din Python reprezintă numere reale, care pot avea o parte fracționară. Sunt imuabile și sunt de tipul de date float.

Floating-point literals in Python represent real numbers, which are numbers that can have a fractional part. They are immutable and are of the float data type.

print(4.2)
print(type(4.2))
print(4.)
print(type(.4))
print(.2)
print(type(.2))
print(.4e7)
print(type(.4e7))
print(4.25e-4)
print(type(4.25e-4))

Notație zecimală standard - Standard decimal notation

Aceasta este cea mai comună modalitate de a scrie numere în virgulă mobilă, folosind o virgulă pentru a separa partea întreagă de partea fracționară.

This is the most common way to write floating-point numbers, using a decimal point to separate the whole and fractional parts.

x = 3.14159 # Un număr cu o parte zecimală
y = -2.5    # Un număr  negativ
z = .5      # Un număr în care partea întreagă este zero
w = 0.0     # Un număr în care partea întreagă şi zecimală sunt zero

print(type(x), type(y), type(z), type(w)) ==> <class 'float'> <class 'float'> <class 'float'> <class 'float'>

Notație științifică (pentru numere foarte mari sau foarte mici)

Pentru numere foarte mari sau foarte mici, se folosește adesea notația științifică. Aceasta constă dintr-un număr (mantisa) urmat de 'e' sau 'E' și un exponent întreg. Exponentul indică puterea lui 10 cu care se înmulțește mantisa.

Scientific notation (for very large or very small numbers)

For very large or very small numbers, scientific notation is often used. It consists of a number (the mantissa) followed by 'e' or 'E' and an integer exponent. The exponent indicates the power of 10 by which the mantissa is multiplied.

număr_imens = 1,87e45       # Reprezintă 1,87 × 1045

viteza_luminii = 2,998e8    # Reprezintă 2,998 × 108

număr_foarte_mic = 9,732e-6 # Reprezintă 9,732 × 10-6

număr_mare = 1.23e5         # Reprezintă 1.23 * 105 (123000.0)

număr_mic = 4.56E-3         # Reprezintă 4.56 * 10-3 (0.00456)

Python poate reprezentă, de asemenea, valori numerice speciale care nu se comportă ca numere obișnuite. Acestea le puteți accesa folosind constructorul float() încorporat.

Python can also represent special numerical values that do not behave like regular numbers. You access these using the built-in float() constructor.

Valori speciale în virgulă mobilă:
Infinity (inf): Reprezintă un număr mai mare decât numărul maxim reprezentabil cu virgulă mobilă.
float('inf') pentru infinit pozitiv
float('-inf') pentru infinit negativ
Nu este un număr (nan): Reprezintă un rezultat numeric nedefinit, cum ar fi 0/0.
float('nan')
Special floating-point values:
Infinity (inf): Represents a number that is larger than the maximum representable float.
float('inf') for positive infinity
float('-inf') for negative infinity
Not a Number (nan): Represents an undefined numerical result, such as 0/0.
float('nan')
x = float('nan')
print(x)         ==> nan

# math.isnan(): Pentru verificarea valorilor cu un singur număr în virgulă mobilă în biblioteca standard.
import math
x = float('nan')
print(math.isnan(x)) ==> True
Caracteristici:
Punctul zecimal: Prezența unui punct zecimal distinge un literal cu virgulă mobilă de un literal întreg.
Semn: Literalii cu virgulă mobilă pot fi pozitivi sau negativi, indicați printr-un semn + sau - precedent (+ este opțional pentru numerele pozitive).
Magnitudine: Numerele cu virgulă mobilă au o valoare maximă și una minimă, dincolo de care reprezintă inf (infinit) sau -inf (infinit negativ).
Precizie: Numerele cu virgulă mobilă în Python sunt de obicei implementate folosind numere cu virgulă mobilă cu dublă precizie (64 de biți), oferind un anumit nivel de precizie. Cu toate acestea, este important să fiți conștienți de potențialele inexactități ale virgulei mobile atunci când aveți de-a face cu calcule precise.
Characteristics:
Decimal Point: The presence of a decimal point distinguishes a float literal from an integer literal.
Sign: Floating-point literals can be positive or negative, indicated by a preceding + or - sign (the + is optional for positive numbers).
Magnitude: Floats have a maximum and minimum value, beyond which they represent inf (infinity) or -inf (negative infinity).
Precision: Floating-point numbers in Python are typically implemented using double-precision (64-bit) floating-point numbers, offering a certain level of precision. However, it's important to be aware of potential floating-point inaccuracies when dealing with precise calculations.

Arithmetic operations - Operații aritmetice

print(10 / 5)  # Împărțirea obișnuită are ca rezultat întotdeauna un număr cu zecimale
print(1 + 2.5) # Adăugarea unui număr zecimal la un număr întreg are ca rezultat un număr cu zecimale

Underscores for readability (Introduced in Python 3.6)
Sublinieri pentru lizibilitate (Introduced in Python 3.6)) 

populație = 7_800_000_000.0             # Sublinieri pentru claritate în numere mari

număr_foarte_specific = 1_234.567_89e10 # Folosit în notație științifică
print(număr_foarte_specific)
Comportament important:
Reprezentare inexactă: Numerele cu virgulă mobilă standard în Python au dublă precizie, ceea ce înseamnă că sunt stocate în format binar. Acest lucru poate duce la mici erori de rotunjire pentru unele numere zecimale, cum ar fi 0,1. Drept urmare, math cu virgulă mobilă nu este întotdeauna perfect precisă.
Alternativă pentru precizie: Pentru aplicații financiare sau de altă natură care necesită reprezentări zecimale exacte, utilizați modulul Decimal din biblioteca standard pentru a evita inexactitățile în virgulă mobilă.
Important behavior:
Inexact representation: Standard floats in Python are double-precision, which means they are stored in binary. This can lead to small rounding errors for some decimal numbers, like 0.1. As a result, floating-point math is not always perfectly precise.

Alternative for precision: For financial or other applications requiring exact decimal representations, use the Decimal module from the standard library to avoid floating-point inaccuracies.
print(0.1 + 0.2) 
==> 0.30000000000000004 - Probleme de precizie în virgulă mobilă

Acest lucru poate duce la rezultate neașteptate, în special atunci când se compară numere cu virgulă mobilă pentru egalitate.
Metodă de comparare mai bună:
În loc să se utilizeze ==, este mai sigur să se verifice dacă numerele cu virgulă mobilă sunt "suficient de apropiate" folosind math.isclose().

This can cause unexpected results, especially when comparing floats for equality.

Better comparison method:
Instead of using ==, it's safer to check if floats are "close enough" using math.isclose().

import math

rezultat = 0.1 + 0.2
print(rezultat == 0.3)             # Fals
print(math.isclose(rezultat, 0.3)) # Adevărat

Pentru aplicații financiare sau științifice care necesită reprezentare zecimală exactă și rotunjire precisă, luați în considerare utilizarea modulului decimal.

For financial or scientific applications that require exact decimal representation and precise rounding, consider using the decimal module.

Caracteristici:
Literalii în virgulă mobilă sunt de tipul de date float din Python.
Tipul float din Python utilizează de obicei numere în virgulă mobilă cu precizie dublă (64 de biți), oferind o gamă largă și o precizie, dar nu o acuratețe perfectă pentru toate numerele zecimale din cauza reprezentării binare.
De asemenea, puteți converti alte tipuri în numere cu virgulă mobilă folosind funcția float() încorporată, de exemplu, float(5) ar rezulta în 5.0.
Characteristics:
Floating-point literals are of the float data type in Python.
Python's float type typically uses double-precision (64-bit) floating-point numbers, offering a wide range and precision, but not perfect accuracy for all decimal numbers due to the binary representation.
You can also convert other types to floats using the built-in float() function, for example, float(5) would result in 5.0.

Metodele numerelor cu virgulă - Float methods

Tipul float încorporat în Python oferă mai multe metode pentru manipularea și inspectarea numerelor în virgulă mobilă. Iată câteva dintre metodele cheie:

Python's built-in float type provides several methods for manipulating and inspecting floating-point numbers. Here are some of the key methods.

float.as_integer_ratio()

Această metodă returnează o pereche de numere întregi (numărător, numitor) reprezentând numărul în virgulă mobilă ca o fracție exactă. Numitorul este întotdeauna o putere pozitivă a lui 2.

This method returns a pair of integers (numerator, denominator) representing the floating-point number as an exact fraction. The denominator is always a positive power of 2.

număr1 = 0.75                                                        
numărător1, numitor1 = număr1.as_integer_ratio()                     
print(f"Numărul {număr1} ca raport întreg: {numărător1}/{numitor1}") 
==> Numărul 0.75 ca raport întreg: 3/4

număr2 = 0.1
numărător2, numitor2 = număr2.as_integer_ratio()
print(f"Numărul {număr2} ca raport: {numărător2}/{numitor2}") 
==> Numărul 0.1 ca raport: 3602879701896397/36028797018963968

număr3 = 3.14
numărător3, numitor3 = număr3.as_integer_ratio()
print(f"Numărul {număr3} ca raport: {numărător3}/{numitor3}") 
==> Numărul 3.14 ca raport: 7070651414971679/2251799813685248

float.is_integer()

Această metodă returnează True dacă numărul cu float este un număr finit cu valoare integrală (adică nu are parte fracțională) și False în caz contrar.

This method returns True if the float is a finite number with an integral value (meaning it has no fractional part), and False otherwise.

x = 3.0
print(x.is_integer()) ==> True

y = 3.5
print(y.is_integer()) ==> False

În principal pentru compatibilitatea cu numerele în virgulă mobilă, această metodă returnează întotdeauna True pentru obiectele int.

Primarily for compatibility with floating-point numbers, this method always returns True for int objects.

Scop:
Verifică dacă un număr în virgulă mobilă are o parte fracțională zero, adică poate fi reprezentat cu precizie ca un număr întreg.
Valoare returnată:
Returnează True dacă numărul în virgulă mobilă nu are parte fracțională (de exemplu, 10.0, 0.0, -3.0).
Returnează False dacă numărul în virgulă mobilă are o parte fracțională diferită de zero (de exemplu, 10.5, 3.14).
Notă importantă: Această metodă nu există pentru obiectele int. Dacă încercați să apelați is_integer() pe un int (de exemplu, 5.is_integer()), va genera o eroare AttributeError deoarece obiectele int sunt în mod inerent numere întregi și nu necesită această verificare.
Purpose:
It checks if a floating-point number has a fractional part of zero, meaning it can be precisely represented as an integer.
Return Value:
It returns True if the float has no fractional part (e.g., 10.0, 0.0, -3.0).
It returns False if the float has a non-zero fractional part (e.g., 10.5, 3.14).

Important Note: This method does not exist for int objects. If you try to call is_integer() on an int (e.g., 5.is_integer()), it will raise an AttributeError because int objects are inherently integers and do not require this check.
număr1 = 10.0
număr2 = 10.5
număr3 = 5

print(f"{număr1}.is_integer(): {număr1.is_integer()}") ==> 10.0.is_integer(): True
print(f"{număr2}.is_integer(): {număr2.is_integer()}") ==> 10.5.is_integer(): False

try:
    print(f"{număr3}.is_integer(): {număr3.is_integer()}")
except AttributeError as e:
    print(f"Error for {număr3}: {e}")  ==> Error for 5: 'int' object has no attribute 'is_integer'

Python nu acceptă direct literali hexazecimali în virgulă mobilă în același mod în care acceptă literali zecimali în virgulă mobilă (de exemplu, 3.14) sau literali întregi hexazecimali (de exemplu, 0xFF).
Cu toate acestea, Python oferă o modalitate de a lucra cu reprezentări hexazecimale ale numerelor în virgulă mobilă prin metoda clasei float.fromhex() și metoda instanței float.hex().

Python does not directly support hexadecimal floating-point literals in the same way it supports decimal floating-point literals (e.g., 3.14) or hexadecimal integer literals (e.g., 0xFF).
However, Python provides a way to work with hexadecimal representations of floating-point numbers through the float.fromhex() class method and the float.hex() instance method.

float.fromhex()

Această metodă returnează o reprezentare a numărului în virgulă mobilă sub formă de șir hexazecimal. Acest lucru poate fi util pentru înțelegerea reprezentării interne a numerelor cu virgulă mobilă.

Python acceptă crearea de literali hexazecimali în virgulă mobilă, deși acest lucru este mai puțin comun. Aceștia sunt scriși cu prefixul 0x sau 0X, cifre hexazecimale pentru mantisă, un separator p sau P și un exponent întreg zecimal. Exponentul este interpretat ca o putere a lui 2, nu a lui 10.

This method returns a representation of the floating-point number as a hexadecimal string. This can be useful for understanding the internal representation of floats.

Python supports creating hexadecimal floating-point literals, though this is less common. They are written with a 0x or 0X prefix, hexadecimal digits for the mantissa, a p or P separator, and a decimal integer exponent. The exponent is interpreted as a power of 2, not 10.

Rol într-un număr cu virgulă mobilă.
Mantisă: Reprezintă cifrele semnificative ale numărului. Numărul de biți alocați mantisei determină precizia numărului.
Exponent: Reprezintă puterea la care este ridicată baza (de obicei 2) pentru a obține magnitudinea corectă.
Bit de semn: Un singur bit la început indică dacă numărul este pozitiv sau negativ.
Role in a floating-point number.
Mantissa: Represents the significant digits of the number. The number of bits allocated to the mantissa determines the number's precision.
Exponent: Represents the power to which the base (usually 2) is raised to get the correct magnitude.
Sign Bit: A single bit at the beginning indicates whether the number is positive or negative.

valoare = semn * mantissa * bazaexponent

Mantisa este fie partea zecimală a unui logaritm, fie cifrele semnificative ale unui număr în notație științifică sau virgulă mobilă. De exemplu, în logaritmul 2.749, mantisa este 0.749. În notația științifică 2.5 * 103, mantisa este 2.5.

The mantissa is either the decimal part of a logarithm or the significant figures of a number in scientific or floating point notation. For example, in the logarithm 2.749, the mantissa is 0.749. In scientific notation 2.5 * 103, the mantissa is 2.5.

  
using_method = float.fromhex('0x1.2p3')    # 0x1.2p3 este (1 + 2/16) * 23, sau 1.125 * 8 = 9.0
print(f"0x1.2p3 ca număr zecimal: {using_method}") ==> 0x1.2p3 ca număr zecimal: 9.0

valoare1 = float.fromhex('0x1.8p-12')
print(f"0x1.8p-12 ca număr zecimal: {valoare1}")   ==> 0x1.8p-12 ca număr zecimal: 0.0003662109375

valoare2 = float.fromhex('0x2.05p4')
print(f"0x2.05p4 ca număr zecimal: {valoare2}")    ==> 0x2.05p4 ca număr zecimal: 32.3125

valoare3 = float.fromhex('-0x1p10')
print(f"-0x1p10 ca număr zecimal: {valoare3}")     ==> -0x1p10 ca număr zecimal: -1024.0

În esență, deși nu poți scrie direct 0x1.8p-12 ca literal în codul Python și să îl interpretezi ca un număr cu zecimle, poți obține aceeași funcționalitate folosind float.fromhex() pentru a analiza reprezentarea hexazecimală a șirului de caractere.

In essence, while you cannot directly write 0x1.8p-12 as a literal in Python code and have it interpreted as a float, you can achieve the same functionality by using float.fromhex() to parse the hexadecimal string representation.

float.hex()

Această metodă convertește un număr standard Python cu virgulă în reprezentarea sa hexazecimală sub formă de șir de caractere.

This method converts a standard Python float into its hexadecimal string representation.

număr_zecimal1 = 0.375
reprezentare_hex1 = număr_zecimal1.hex()
print(f"0.375 în hexazecimal: {reprezentare_hex1}")  ==> 0.375 în hexazecimal: 0x1.8000000000000p-2

număr_zecimal2 = 1024.0
reprezentare_hex2 = număr_zecimal2.hex()
print(f"1024.0 în hexazecimal: {reprezentare_hex2}") ==> 1024.0 în hexazecimal: 0x1.0000000000000p+10

Metode ale operatorilor (Metode dunder) - Operator methods (Dunder methods)

Pe lângă aceste metode specifice, elementele cu float acceptă și diverse "metode magice" (metode dunder precum __add__, __sub__, __abs__, __mul__, __truediv__, __floordiv__, __mod__, __pow__) care definesc modul în care acestea interacționează cu operatorii și funcțiile încorporate, cum ar fi abs(). De exemplu, abs(x) apelează intern x.__abs__().

In addition to these specific methods, floats also support various "magic methods" (dunder methods like __add__, __sub__, __abs__, __mul__, __truediv__, __floordiv__, __mod__, __pow__) which define how they interact with operators and built-in functions like abs(). For instance, abs(x) internally calls x.__abs__().

Funcția float() încorporată - The built-in float() Function

Sintaxă: float(valoare)

Se folosește pentru a converti un număr sau un șir de caractere care conține o reprezentare numerică într-un număr cu virgulă mobilă. Numerele în virgulă mobilă sunt folosite pentru a reprezenta numere reale, inclusiv pe cele cu părți fracționare (zecimale).

Is used to convert a number or a string containing a numeric representation into a floating-point number. Floating-point numbers are used to represent real numbers, including those with fractional parts (decimals).

Parametri:
valoare: Valoarea care urmează să fie convertită. Aceasta poate fi:
Un număr întreg (de exemplu, float(5) returnează 5.0).
Un alt număr cu virgulă mobilă (de exemplu, float(3.14) returnează 3.14).
Un șir care conține o reprezentare numerică (de exemplu, float("10.5") returnează 10.5).
Șirurile pot include spații albe la început/sfârșit, care vor fi ignorate.
Șirurile pot reprezenta numere pozitive sau negative, folosind + sau -.
Șirurile pot reprezenta valori speciale în virgulă mobilă, cum ar fi „NaN” (Nu este un număr), "Infinit" sau "inf" (fără sensibilitate la majuscule/minuscule) pentru infinit pozitiv sau negativ.
Gestionarea intrărilor nevalide:
Dacă șirul furnizat nu poate fi convertit într-un număr cu virgulă mobilă valid (de exemplu, "salut"), va fi generată o eroare ValueError.
Valoare returnată:
Funcția float() returnează o reprezentare numerică în virgulă mobilă a valorii de intrare. Dacă nu este furnizat niciun argument, returnează 0.0.
Parameters:
value: The value to be converted. This can be:
An integer (e.g., float(5) returns 5.0).
Another float (e.g., float(3.14) returns 3.14).
A string containing a numerical representation (e.g., float("10.5") returns 10.5).
Strings can include leading/trailing whitespace, which will be ignored.
Strings can represent positive or negative numbers, using + or -.
Strings can represent special floating-point values like "NaN" (Not a Number), "Infinity", or "inf" (case-insensitive) for positive or negative infinity.
Handling Invalid Input:
If the provided string cannot be converted into a valid floating-point number (e.g., "hello"), a ValueError will be raised.
Return Value:
The float() function returns a floating-point number representation of the input value. If no argument is provided, it returns 0.0.
# Conversia unui număr întreg într-un număr cu virgulă mobilă
rezultat1 = float(10)
print(rezultat1) ==> 10.0

# Conversia unui șir de caractere într-un număr cu virgulă mobilă
rezultat2 = float("123.45") 
print(rezultat2) ==> 123.45

# Conversia unui șir de caractere care reprezintă un număr întreg într-un număr cu virgulă mobilă
rezultat3 = float("-7")
print(rezultat3) ==> -7.0


# Valori speciale în virgulă mobilă
rezultat4 = float("inf"), float("-inf") 
print(rezultat4) ==> (inf, -inf)

rezultat5 = float("-Infinity")
print(rezultat5) ==> -inf

rezultat6 = float("NaN"), float("nan")
print(rezultat6) ==> (nan, nan)

# spații_albe
șir_spații_albe = " -99.5 "
număr_zecimal = float(șir_spații_albe)
print(f"{număr_zecimal} din număr cu spații albe") ==> -99.5 din număr cu spații albe

șir_notație_științifică = "2.5e-3"
număr_zecimal = float(șir_notație_științifică)
print(f'{număr_zecimal} rezultat din notația științifică "{șir_notație_științifică}"') ==> 0.0025 rezultat din notația științifică "2.5e-3"

Conversia unui șir de caractere gol sau valoare non-numeric.- Potențialele excepții ValueError

Converting an empty string or non-numeric value. - Potential ValueError exceptions

try:
    float("")
except ValueError as e:
    print(f"Error: {e}")  ==> Error: could not convert string to float: ''

try:
    float("salut")
except ValueError as e:
    print(f"Eroare: {e}") ==> Eroare: could not convert string to float: 'salut'
Cazuri comune de utilizare:
Conversie de tip: Conversia datelor din alte tipuri (cum ar fi numere întregi sau șiruri de caractere) în numere cu virgulă mobilă pentru operații numerice care necesită precizie zecimală.
Gestionarea datelor introduse de utilizator: Conversia datelor introduse de utilizator, adesea primite ca șiruri de caractere, în numere cu virgulă mobile pentru calcule.
Reprezentarea datelor științifice: Lucrul cu numere care pot necesita notație științifică sau precizie ridicată.
Common Use Cases:
Type Conversion: Converting data from other types (like integers or strings) to floats for numerical operations requiring decimal precision.

Handling User Input: Converting user input, often received as strings, into numerical floats for calculations.
Representing Scientific Data: Working with numbers that may require scientific notation or high precision.
