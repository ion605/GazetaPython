Reprezintă numere întregi (pozitive, negative sau zero) fără nicio parte fracționară.
Represent whole numbers (positive, negative, or zero) without any fractional part. 

x = 100
y = -50
z = 0
print(type(x)) ==> <class 'int'>

Numere întregi literale - Integer literals

Literalii întregi în Python sunt reprezentări directe ale numerelor întregi în codul sursă. Aceste numere pot fi pozitive, negative sau zero și nu conțin părți fracționare sau virgulă. Python oferă mai multe modalități de a reprezenta literalii întregi:
Literali zecimali (baza 10): Aceasta este cea mai comună și simplă modalitate de a reprezenta numere întregi. Se scriu folosind cifre de la 0 la 9.

Integer literals in Python are the direct representations of whole numbers within the source code. These numbers can be positive, negative, or zero, and they do not contain any fractional parts or decimal points. Python provides several ways to represent integer literals:
Decimal Literals (Base 10): These are the most common and straightforward way to represent integers. They are written using digits 0-9.

x = 100
y = -50
z = 0
print(type(x))

Literali binari (baza 2): Aceștia sunt reprezentați printr-un prefix 0b sau 0B urmat de cifre binare (0 și 1).
Binary Literals (Base 2): These are represented by a 0b or 0B prefix followed by binary digits (0s and 1s). 

număr_binar = 0b1010 # Reprezintă numărul întreg 10
print(număr_binar)

Literali octali (baza 8): Aceștia sunt reprezentați printr-un prefix 0o sau 0O urmat de cifre octale (0-7).
Octal Literals (Base 8): These are represented by a 0o or 0O prefix followed by octal digits (0-7). 

număr_octal = 0o17 # Reprezintă numărul întreg 15
print(număr_octal)

Literale hexazecimale (baza 16): Acestea sunt reprezentate printr-un prefix 0x sau 0X urmat de cifre hexazecimale (0-9 și A-F, fără a ține cont de majuscule/minuscule).
Hexadecimal Literals (Base 16): These are represented by a 0x or 0X prefix followed by hexadecimal digits (0-9 and A-F, case-insensitive). 

număr_hexadecimal = 0x1A # Reprezintă cifra întregă 26
print(număr_hexadecimal)
Caracteristici cheie ale numerelor întregi literale:
Precizie nelimitată: În Python 3, numerele întregi au o precizie arbitrară, ceea ce înseamnă că dimensiunea lor este limitată doar de memoria disponibilă. Acest lucru diferă de alte limbaje în care dimensiunea numerelor întregi este fixă.
Lizibilitate cu sublinieri: Pentru numere mari, sublinierile pot fi folosite ca separatoare vizuale pentru a îmbunătăți lizibilitatea. Aceste sublinieri sunt ignorate de interpretor.
Characteristics of Integer Literals:
Unlimited Precision: In Python 3, integers have arbitrary precision, meaning their size is limited only by available memory. This differs from some other languages where integer size is fixed.
Readability with Underscores: For large numbers, underscores can be used as visual separators to improve readability. These underscores are ignored by the interpreter.
număr_mare = 1_000_000_000_000  # Sublinierile pot îmbunătăți lizibilitatea
print(număr_mare)

# Sublinierile funcționează și cu alte baze
valoare_binară = 0b_1111_0011    # Reprezintă cifra întregă 243
valoare_hexadecimală = 0x_a0_c0  # Reprezintă cifra întregă 41152
print(valoare_binară)
print(valoare_hexadecimală)

# Pentru a crea un număr întreg negativ, pur și simplu adăugați înaintea literalului semnul minus (-)
număr_întreg_negativ = -12340
print(număr_întreg_negativ)

Zerouri la început: Zerourile la început nu sunt permise pentru numerele întregi diferite de zero, deoarece ar putea fi interpretate greșit ca format literal octal moștenit din Python 2. De exemplu, 010 este un literal invalid în Python 3, dar 0o10 este un literal octal valid.

Leading zeros: Leading zeros are not allowed on non-zero decimal numbers, as they could be misinterpreted as the legacy octal literal format from Python 2. For instance, 010 is an invalid literal in Python 3, but 0o10 is a valid octal literal.

Metodele numerelor întregi - Integer methods

.as_integer_ratio()

Este utilizată pentru a reprezenta un număr în virgulă mobilă ca raport între două numere întregi. Această metodă este disponibilă atât pentru tipurile integer, cât și pentru cele float, precum și pentru obiectele Decimal și Fracţiune din modulul fracţii.

Is used to represent a floating-point number as a ratio of two integers. This method is available for both integer and float types, as well as Decimal objects and Fraction objects from the fractions module.

int.as_integer_ratio()

Pentru numere întregi, această metodă returnează întotdeauna numărul întreg ca numărător și 1 ca numitor.
For integers, this method always returns the integer itself as the numerator and 1 as the denominator.

număr = 15
numărător, numitor = număr.as_integer_ratio()
print(f"{număr} ca raport întreg: {numărător}/{numitor}") ==> 15 ca raport întreg: 15/1

# accesează metoda literal
# parantezele sunt necesare deoarece caracterul punct (.) definește și numerele cu virgulă mobilă
print((număr).as_integer_ratio()) ==> (15, 1)

număr = 42
print(număr.as_integer_ratio()) ==> (42, 1)

.bit_length()

Returnează numărul de biți necesari pentru a reprezenta numărul întreg în binar, excluzând semnul și zerourile inițiale.
Returns the number of bits required to represent the integer in binary, excluding the sign and leading zeros. 

număr = 10 # (binar 1010)
print(număr.bit_length()) ==> 4

.bit_count()

Returnează numărul de unități din reprezentarea binară a valorii absolute a numărului întreg.
Returns the number of ones in the binary representation of the absolute value of the integer. 

număr = 10 # (binarul 1010 are două cifre de 1)
print(număr.bit_count()) ==> 2

număr2 = 214  # (binar: 0b11010110)
câți_de_unu = număr2.bit_count()
print(câți_de_unu) ==> 5

if câți_de_unu % 2 == 0:
    print("Numarul cifrelor 1 este par")
else:
    print("Numarul cifrelor 1 este impar")

from_bytes(bytes, byteorder, *, signed=False)

Returnează un număr întreg reprezentat de o matrice dată de octeți. byteorder specifică ordinea octeților, iar signed indică dacă octeții trebuie interpretați ca un număr cu semn în complement la doi.

Returns an integer represented by a given array of bytes. byteorder specifies the order of bytes, and signed indicates whether to interpret the bytes as a signed two's complement number.

date_octeți = b'\x01\x02'
valoare_întreagă = int.from_bytes(date_octeți, byteorder='big')
print(valoare_întreagă) ==> 258

to_bytes(length, byteorder, *, signed=False)

Returnează o matrice de octeți reprezentând numărul întreg. length este numărul de octeți de utilizat, byteorder specifică ordinea octeților, iar signed indică dacă se utilizează complementul la doi pentru numerele negative.

Returns an array of bytes representing the integer. length is the number of bytes to use, byteorder specifies the order of bytes, and signed indicates whether to use two's complement for negative numbers.

număr = 258
date_octeți = număr.to_bytes(2, byteorder='big')
print(date_octeți) ==> b'\x01\x02'

Verificare dacă un număr este întreg - Checking if a number is an integer

Deoarece is_integer() funcționează doar pe obiecte float, este posibil să aveți nevoie de o abordare mai generală atunci când lucrați cu diferite tipuri de date.
Since is_integer() only works on float objects, you may need a more general approach when dealing with different data types.

isinstance()

Aceasta este metoda standard și cea mai robustă de a verifica tipul unui obiect.
This is the standard and most robust way to check an object's type. 

număr_întreg = 10
număr_float = 10.0
număr_zecimal = 10.5

print(isinstance(număr_întreg, int))  ==> Adevărat
print(isinstance(număr_float, int))   ==> Fals
print(isinstance(număr_zecimal, int)) ==> Fals

# De asemenea, puteți verifica mai multe tipuri
print(isinstance(număr_întreg, (int, float))) ==> Adevărat

Notă: Verificarea isinstance() va returna False pentru 10.0 dacă verificați doar pentru int, deoarece 10.0 este un număr cu virgulă, chiar dacă are o valoare întreagă.
Note: The isinstance() check will return False for 10.0 if you only check for int, as 10.0 is a float even though it has an integer value.

modulo operator (%) - operatorul modulo (%)

def este_număr_întreg(număr):
    return număr % 1 == 0

print(este_număr_întreg(10))     ==> Adevărat
print(este_număr_întreg(10.0))   ==> Adevărat
print(este_număr_întreg(10.5))   ==> Fals

A comprehensive function - O funcție completă

Pentru o funcție care gestionează atât tipurile int, cât și cele float, puteți combina metodele isinstance() și is_integer().
For a function that handles both int and float types, you can combine the isinstance() and is_integer() methods. 

def este_valoare_întreagă(număr):
    if isinstance(număr, int):
        return True
    if isinstance(număr, float):
        return număr.is_integer()
    return False
număr1 = 10
număr2 = 10.0
număr3 = 10.5
număr4 = "10"
print(f"Numărul {număr1} este întreg: ", este_valoare_întreagă(număr1))   ==> Adevărat
print(f"Numărul {număr2} este întreg: ", este_valoare_întreagă(număr2))   ==> Adevărat
print(f"Numărul {număr3} este întreg: ", este_valoare_întreagă(număr3))   ==> Fals
print(f'Numărul "{număr4}" este întreg:' , este_valoare_întreagă(număr4)) ==> Fals

Funcția int() încorporată - The Built-in int() Function

Funcția int() din Python este o funcție încorporată utilizată pentru a converti o valoare într-un număr întreg. Poate lua un număr sau un șir de caractere ca argument și returnează echivalentul întreg.
The int() function in Python is a built-in function used to convert a value into an integer. It can take a number or a string as an argument and returns the integer equivalent.

Sintaxă: int(value, base=10)

Parametri:
value: Valoarea care va fi convertită într-un număr întreg. Aceasta poate fi un număr (float) sau un șir de caractere care reprezintă un număr întreg.
base (opțional): Un număr întreg care reprezintă baza numerică a valorii dacă este un șir de caractere. Baza implicită este 10 (zecimală). Bazele valide sunt 0 și 2-36.
Funcționalitate:
Conversia numerelor în numere întregi:
Când un număr cu virgulă mobilă este transmis către int(), acesta trunchiază partea zecimală, rotunjind efectiv la cel mai apropiat număr întreg.
Exemplu: int(3.14) returnează 3, iar int(-3.14) returnează -3.
Conversia șirurilor în numere întregi:
int() poate converti o reprezentare șir a unui număr întreg într-un tip int real.
Exemplu: int("123") returnează 123.
Dacă șirul reprezintă un număr într-o bază diferită (de exemplu, binară, octală, hexazecimală), argumentul de bază poate fi specificat.
Exemplu: int("101", 2) returnează 5 (binar în zecimal).
Important: Conversia directă a unui șir care reprezintă un număr cu virgulă mobilă (de exemplu, "3.14") va genera o eroare ValueError. Pentru a converti astfel de șiruri, acestea trebuie mai întâi convertite într-un număr cu virgulă mobilă folosind float(), apoi într-un număr întreg folosind int().
Gestionarea fără argumente:
Dacă nu sunt furnizate argumente pentru int(), aceasta returnează 0.
Parameters:
value: The value to be converted to an integer. This can be a number (float) or a string representing an integer.
base (optional): An integer representing the number base of the value if it is a string. The default base is 10 (decimal). Valid bases are 0 and 2-36.
Functionality:
Converting Numbers to Integers:
When a float is passed to int(), it truncates the decimal part, effectively rounding down to the nearest whole number.
Example: int(3.14) returns 3, and int(-3.14) returns -3.
Converting Strings to Integers:
int() can convert a string representation of an integer into an actual int type.
Example: int("123") returns 123.
If the string represents a number in a different base (e.g., binary, octal, hexadecimal), the base argument can be specified.
Example: int("101", 2) returns 5 (binary to decimal).
Important: Directly converting a string representing a floating-point number (e.g., "3.14") will raise a ValueError. To convert such strings, they must first be converted to a float using float(), and then to an integer using int().
Handling No Arguments:
If no arguments are provided to int(), it returns 0.

int() # fără argumente

Cazuri de utilizare:
Asigurarea că o valoare este de tip întreg pentru operații matematice sau comparații.
Conversia datelor de intrare ale utilizatorului (adesea primite ca șiruri de caractere) în numere întregi pentru procesare.
Conversia numerelor reprezentate în diferite baze (de exemplu, binară, octală, hexazecimală) în echivalentele lor întregi zecimale.
Lucrul cu obiecte personalizate care implementează metoda __int__ pentru logica personalizată de conversie a numerelor întregi.
Use Cases:
Ensuring a value is of the integer type for mathematical operations or comparisons.
Converting user input (often received as strings) into integers for processing.
Converting numbers represented in different bases (e.g., binary, octal, hexadecimal) to their decimal integer equivalents.
Working with custom objects that implement the __int__ method for custom integer conversion logic.

Conversia numerelor cu virgulă în numere întregi - Converting floats to integers

În funcție de modul în care doriți să gestionați partea zecimală, Python oferă patru metode principale pentru a realiza acest lucru.

Depending on how you want to handle the decimal portion, Python provides four primary methods to accomplish this.

Rezumat al metodelor de conversie
MetodăComportamentExemplu de intrareExemplu de ieșire
int(x)Elimină tot ce urmează după virgulă (trunchiază).3,9 / -3,93 / -3
round(x)Rotunjește la cel mai apropiat număr întreg.3,6 / 3,44 / 3
math.floor(x)Rotunjește în jos la următorul număr întreg inferior.3,9 / -3,13 / -4
math.ceil(x)Rotunjește prin adaos la următorul număr întreg superior.3,1 / -3,94 / -3

Când transmiteți un număr cu virgulă mobilă către int(), acesta trunchiază partea zecimală și returnează doar numărul întreg. Acest comportament este un "minim spre zero" și nu rotunjește numărul.

When you pass a floating-point number to int(), it truncates the decimal part and returns only the whole number. This behavior is a "floor towards zero" and does not round the number.

# Utilizarea funcției int() (Trunchiere)
print(int(2.99))  ==> 2
print(int(-2.75)) ==> -2

# Utilizarea funcției round() (Rotunjire standard)
print(round(5.6))  ==> 6
print(round(5.4))  ==> 5
print(round(4.5))  ==> 6

# Utilizarea funcțiilor math.floor() și math.ceil() (Floor și Ceiling)
import math

print(math.floor(5.9))   ==> 5
print(math.floor(-5.1))  ==> -6

print(math.ceil(5.1))    ==> 6
print(math.ceil(-5.9))   ==> -5

Conversia șirurilor numerice în numere întregi - Converting numeric strings to integers

print(int("123"))       ==> 123
print(int("   -45   ")) ==> -45

Pentru a gestiona eroarea ValueError care apare la încercarea de a converti un șir de caractere "literal invalid" într-un număr întreg folosind int(), în Python se poate utiliza un bloc try-except.

Handle the ValueError that occurs when attempting to convert a string like "invalid literal" to an integer using int(), a try-except block can be employed in Python.

try:
    # Încercare de conversie a șirului "3.14" într-un număr întreg
    valoare_întregă = int("3.14")
    print(f"Conversie reușită: {valoare_întregă}")
except ValueError:
    # Gestionează ValueError care apare atunci când conversia eșuează
    print("Eroare: Nu se poate converti '3.14' într-un număr întreg. Este un număr cu virgulă.")

număr_șir = "3.14"
try:
    # Încercare de conversie a șirului într-un număr întreg
    număr_întreg = int(număr_șir)
    print(f"Conversia a reușit. Numărul întreg este: {număr_întreg}")

except ValueError:
    # Acest bloc se execută dacă apare o eroare ValueError
    print(f"Eroare: '{număr_șir}' nu este un număr întreg valid.")
    print("Șirul conține o virgulă și nu poate fi convertit direct.")

except Exception as e:
    # Aceasta este o excepție generală pentru orice alte excepții
    print(f"A apărut o eroare neașteptată: {e}")
Explicație:
blocul try: Codul din interiorul acestui bloc este executat primul. Aici plasați codul care ar putea cauza o eroare.
blocul except ValueError: Dacă codul din blocul try eșuează cu o eroare ValueError (așa cum se întâmplă cu "3.14"), programul trece imediat la acest bloc. Execută codul aici în loc să se blocheze.
blocul except Exception: Acesta este un manipulator mai general care va detecta orice alte tipuri de erori, asigurându-se că programul dvs. poate gestiona probleme neprevăzute.
Explanation:
try block: The code inside this block is executed first. This is where you put the code that might cause an error.
except ValueError block: If the code in the try block fails with a ValueError (as it does with "3.14"), the program immediately jumps to this block. It executes the code here instead of crashing.
except Exception block: This is a more general handler that will catch any other types of errors, ensuring your program can handle unforeseen issues.

Convertirea unui șir de caractere cu zecimale - Convert a string with a decimal

# mai întâi convertiți-l într-un număr cu float, apoi într-un număr întreg
int(float("3.14")) ==> 3

Utilizați un bloc try...except pentru a gestiona potențialele erori dacă șirul nu este un număr (de exemplu, "abc")

Use a try...except block to handle potential errors if the string is not a number at all (e.g., "abc")

# Contolează eroriile
șir_număr = "3.14"

try:
    # Mai întâi, convertiți șirul într-un număr cu virgulă mobilă
    șir_număr_float = float(șir_număr)

    # Apoi, convertiți numărul cu virgulă mobilă într-un număr întreg (aceasta trunchiază zecimalele)
    șir_număr_întreg = int(șir_număr_float)

    print(f"Partea întreagă a lui '{șir_număr}' este: {șir_număr_întreg}")

except ValueError:
    print(f"Eroare: '{șir_număr}' nu este un număr valid și nu poate fi convertit.")

Conversia numerelor din alte baze - Converting numbers from other bases

Puteți converti șiruri de caractere care reprezintă numere binare, octale sau hexazecimale în echivalentul lor întreg zecimal (baza 10) utilizând parametrul opțional de bază.

  • bază=2: pentru binar
  • bază=8: pentru octal
  • bază=16: pentru hexazecimale

You can convert strings representing binary, octal, or hexadecimal numbers into their decimal (base-10) integer equivalent by using the optional base parameter.

  • base=2: for binary
  • base=8: for octal
  • base=16: for hexadecimal
# Conversia unui șir binar într-un număr întreg
print(int("101", 2)) ==> 5

# Conversia unui șir hexazecimal într-un număr întreg
print(int("A", 16)) ==> 10

# De asemenea, puteți utiliza prefixe standard precum '0x' sau '0b'
print(int("0xa", 16)) ==> 10
