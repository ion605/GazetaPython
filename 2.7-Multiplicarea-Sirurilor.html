Multiplicarea șirurilor, cunoscută și sub denumirea de repetiție a șirurilor, se realizează folosind operatorul de multiplicare (*). Această operație permite crearea unui nou șir prin repetarea unui șir existent de un număr de ori.

Repetiția, cunoscută și sub denumirea de replicare, implică crearea unei noi secvențe prin repetarea unei secvențe existente de un număr de ori.

String multiplication, also known as string repetition, is achieved using the multiplication operator (*). This operation allows for the creation of a new string by repeating an existing string a specified number of times.

Repetition, also known as replication, involves creating a new sequence by repeating an existing sequence a specified number of times.

Caracteristici
Operanzi: Un operand trebuie să fie un șir de caractere, iar celălalt trebuie să fie un număr întreg. Ordinea acestor operanzi nu contează.
Rezultat: Rezultatul este un nou obiect șir de caractere în care șirul_original este concatenat cu el însuși de valoarea_întreagă de ori.
Repetiții zero: Dacă valoarea_întreagă este 0, se returnează un șir gol ('').
Repetiții negative: Dacă valoarea_întreagă este un număr negativ, se returnează un șir gol ('').
Repetiții cu număr cu virgulă: Încercarea de a înmulți un șir cu un număr cu virgulă va crea TypeError.
Multiplicarea a două șiruri de caractere (de exemplu, "2" * "3" va genera o eroare TypeError). Dacă aveți de-a face cu numere formatate ca text, trebuie mai întâi să le convertiți folosind funcția int() sau float().
Eficiență: Înmulțirea șirurilor este, în general, cea mai eficientă și lizibilă metodă de a repeta un șir în Python, comparativ cu utilizarea buclelor sau a metodei str.join() în același scop.
Characteristics:
Operands: One operand must be a string, and the other must be an integer. The order of these operands does not matter.
Result: The result is a new string object where the original_string is concatenated with itself integer_value times.
Zero Repetitions: If the integer_value is 0, an empty string ('') is returned.
Negative Repetitions: If the integer_value is a negative number, an empty string ('') is returned.
Float Repetitions: Attempting to multiply a string by a float will result in a TypeError.
Multiply two strings together (e.g., "2" * "3" will throw a TypeError). If you are dealing with numbers formatted as text, you must convert them first using the int() or float() function.
Efficiency: String multiplication is generally the most efficient and readable method for repeating a string in Python compared to using loops or str.join() for the same purpose.

def creare_imprimare_tabel(datele, antete=None):
    """
        Creează și afișează un tabel formatat dintr-o listă de liste sau o listă de dicționare.

        Argumente:
        datele (listă): O listă de liste (pentru rânduri) sau o listă de dicționare (pentru rânduri cu coloane denumite).
        antete (listă, opțional): O listă de șiruri de caractere de utilizat ca antete de coloană.
        Dacă None și datele sunt o listă de dicționare, cheile vor fi utilizate ca antete.
    """

    if not datele:
        print("Nu există date de afișat.")
        return

    # Determinarea antetelor și a formatului datelor

    # Pentru o listă de dicţionare
    if isinstance(datele[0], dict):
        if antete is None:
            antete = list(datele[0].keys())
        rânduri = [[rând[antet] for antet in antete] for rând in datele]
    # Pentru o listă de liste
    else:
        if antete is None:
            antete = [f"Coloană {i+1}" for i in range(len(datele[0]))]
        rânduri = datele

    # Calculează lățimile maxime ale coloanelor
    lățime_coloane = [len(str(antet)) for antet in antete]
    for rând in rânduri:
        for i, articol in enumerate(rând):
            lățime_coloane[i] = max(lățime_coloane[i], len(str(articol)))

    # Imprimare antete
    antet_linie = " | ".join([str(antete[i]).ljust(lățime_coloane[i]) for i in range(len(antete))])
    print(antet_linie)
    print("-" * len(antet_linie))

    # Imprimare rânduri de date
    for rând in rânduri:
        rând_linie = " | ".join([str(rând[i]).ljust(lățime_coloane[i]) for i in range(len(rând))])
        print(rând_linie)

def tabele_multiple(sursa, antete=None):
    """
        Creează și afișează un tabel formatat din date(sursa).

        Această funcție poate gestiona datele ca o listă de liste sau o listă de dicționare.
        Calculează automat lățimea coloanelor pentru a asigura alinierea corectă.

        Argumente:
        date(sura-listă): O listă de liste, unde fiecare listă interioară reprezintă un rând,
        sau o listă de dicționare, unde fiecare dicționar reprezintă un rând.
        antete (listă, opțional): O listă de șiruri de caractere care vor fi utilizate ca anteturi de coloană.
        Dacă datele(sursa) este o listă de dicționare, cheile vor fi utilizate ca anteturi dacă acest argument nu este furnizat.
    """
    if not sursa:
        print("Nu există date de afișat.")
        return

    # Determinarea structurii datelor(sursa) și a anteturilor
    if isinstance(sursa[0], dict):
        if antete is None:
            antete = list(sursa[0].keys())
        rânduri_pentru_tabel = [[rând.get(antet, "") for antet in antete] for rând in sursa]
    elif isinstance(sursa[0], list):
        if antete is None:
            antete = [f"Coloană {i+1}" for i in range(len(sursa[0]))]
        rânduri_pentru_tabel = sursa
    else:
        print("Format de date neacceptat. Vă rugăm să utilizați o listă de liste sau o listă de dicționare.")
        return

    # Calculează lățimea maximă pentru fiecare coloană
    lățimea_coloanelor = [len(antet) for antet in antete]
    for rând in rânduri_pentru_tabel:
        for i, element in enumerate(rând):
            lățimea_coloanelor[i] = max(lățimea_coloanelor[i], len(str(element)))

    # Imprimați tabelul
    try:
        # Imprimați antetele
        rând_de_antet = " | ".join(f"{antet:<{lățimea_coloanelor[i]}}" for i, antet in enumerate(antete))
        print(rând_de_antet)
        # Tipărire linie de separare
        separator = "-|-".join("-" * lățime for lățime in lățimea_coloanelor)
        print(separator)
        # Tipăriți rânduri de date
        for rând in rânduri_pentru_tabel:
            textul_rândului = " | ".join(f"{str(element):<{lățimea_coloanelor[i]}}" for i, element in enumerate(rând))
            print(textul_rândului)
    except Exception as e:
        print(f"A apărut o eroare la imprimarea tabelului: {e}", file=sys.stderr)

A for loop iterates over the items of any sequence (such as a list, string, or tuple) and executes a code block once for each item. You should use a for loop when you know the number of repetitions in advance.

bucla while - while loop

O buclă while execută în mod repetat un bloc de cod atâta timp cât o anumită condiție este adevărată. Această structură de control este utilă în special atunci când numărul de iterații nu este cunoscut în prealabil și depinde de evaluarea condiției în timpul execuției.

A while loop repeatedly executes a block of code as long as a given condition is true. This control structure is particularly useful when the number of iterations is not known beforehand and depends on the condition's evaluation during execution. 

Sintaxă:
    
while condition:
    # Bloc de cod care va fi executat în mod repetat
    # (Instrucțiuni indentate)
Explicație:
condiție while: Cuvântul cheie "while" inițiază bucla, urmat de o condiție (o expresie booleană). Această condiție este evaluată la începutul fiecărei iterații.
Două-puncte (:) la sfârșitul condiției unei instrucțiuni while marchează sfârșitul antetului buclei și semnalează începutul corpului acesteia.
Bloc de cod indentat: Instrucțiunile indentate sub instrucțiunea while formează corpul buclei. Aceste instrucțiuni sunt executate în mod repetat atâta timp cât condiția este evaluată ca True.
Cum are loc repetiția:
Verificare inițială: Condiția este evaluată. Dacă este True blocul de cod din interiorul buclei este executat.
Verificări ulterioare: După fiecare execuție a blocului de cod, condiția este evaluată din nou.
Continuare: Dacă condiția este încă True, blocul de cod este executat din nou. Acest ciclu continuă.
Terminare: Când condiția este evaluată ca falsă (False), bucla se termină, iar fluxul programului continuă cu instrucțiunea imediat următoare blocului indentat al buclei.
Explanation:
while condition: The while keyword initiates the loop, followed by a condition (a boolean expression). This condition is evaluated at the beginning of each iteration.
The colon (:) at the end of a while condition represents the end of the loop header and signals the start of the loop body
Indented Code Block: The statements indented below the while statement form the loop's body. These statements are executed repeatedly as long as the condition evaluates to True.
How Repetition Occurs:
Initial Check: The condition is evaluated. If it's True, the code block inside the loop is executed.
Subsequent Checks: After each execution of the code block, the condition is evaluated again.
Continuation: If the condition is still True, the code block is executed again. This cycle continues.
Termination: When the condition evaluates to False, the loop terminates, and the program flow continues with the statement immediately following the loop's indented block.
numără = 0
while numără < 3: # Două puncte marchează sfârșitul antetului
    print(f"Numărul este: {numără}") # Bloc de cod indentat (corpul buclei)
    numără += 1  # Incrementează numărul până când condiția este falsă
print("Bucla sa terminat.")
==> Numărul este: 0
    Numărul este: 1
    Numărul este: 2
    Bucla sa terminat.

În acest exemplu, bucla continuă atâta timp cât "numără" este mai mic decât 3. În interiorul buclei, "numără" este incrementat la fiecare iterație, ceea ce duce în cele din urmă la faptul că, condiția "numără" < 3 devine falsă (False) și încheie bucla.

In this example, the loop continues as long as count is less than 3. Inside the loop, count is incremented in each iteration, eventually leading to the condition count < 3 becoming False and terminating the loop.

Crearea unei bucle while cu o structură "do-while".
Spre deosebire de alte limbaje, Python nu are o buclă do-while nativă. Cu toate acestea, puteți emula una folosind while True și o instrucțiune break pentru a ieși din buclă odată ce o condiție este îndeplinită.

Creating a while loop with a "do-while" structure.
Unlike some other languages, Python does not have a native do-while loop. However, you can emulate one by using while True and a break statement to exit the loop once a condition is met.

while True:
    intrare_utilizator = input("Introduceți 'q': ")
    if intrare_utilizator.lower() == 'q':
        break
print(f"Felicitari, ați introdus corect: '{intrare_utilizator}' este parola pentru ieșire.")
print("Bucla s-a terminat.")

    Felicitari, ați introdus corect: 'q' este parola pentru ieșire.
    Bucla s-a terminat.

Funcția itertools.repeat() - itertools.repeat() Function

Funcția itertools.repeat() din Python este utilizată pentru a crea un iterator care returnează un obiect specificat în mod repetat. Această funcție face parte din modulul itertools, care oferă o colecție de instrumente rapide și eficiente din punct de vedere al memoriei pentru crearea și lucrul cu iteratori.

The itertools.repeat() function in Python is used to create an iterator that returns a specified object repeatedly. This function is part of the itertools module, which provides a collection of fast, memory-efficient tools for creating and working with iterators.

itertools.repeat(object, times=None)

Caracteristici:
Repetarea unui singur obiect: repeat() ia un obiect ca prim argument și returnează un iterator care produce acest obiect.
Repetiție nedefinită: Dacă argumentul times nu este furnizat, repeat() va produce obiectul la infinit.
Repetiție limitată: Dacă argumentul times este specificat, repeat() va produce obiectul exact de același număr de ori.
Eficiență a memoriei: repeat() este leneșă, ceea ce înseamnă că stochează o singură referință la obiectul care se repetă, ceea ce o face eficientă din punct de vedere al memoriei în comparație cu crearea unei liste cu același obiect repetat de mai multe ori.
Key Features:
Repetition of a single object: repeat() takes an object as its first argument and returns an iterator that yields this object.
Indefinite repetition: If the times argument is not provided, repeat() will yield the object infinitely.
Limited repetition: If the times argument is specified, repeat() will yield the object exactly that many times.
Memory efficiency: repeat() is lazy, meaning it only stores a single reference to the object being repeated, making it memory-efficient compared to creating a list with the same object repeated many times.
from itertools import repeat

# Repetă un cuvânt de 3 ori
for cuvânt in repeat("Salut", times=3):
    print(cuvânt, end=", ")
==> Salut, Salut, Salut,

List comprehension

Pentru iterarea unei liste de șiruri de caractere, o înțelegere a listei este adesea considerată mai "Pythonic" și mai ușor de citit decât map() cu lambda.

For iterating over a list of strings, a list comprehension is often considered more "Pythonic" and readable than map() with lambda.

șiruri_de_caractere = ["salut", "lume", "python"]
număr_repetiții = 3

șiruri_repetate_comp = [șir * număr_repetiții for șir in șiruri_de_caractere]
print(șiruri_repetate_comp)
==> ['salutsalutsalut', 'lumelumelume', 'pythonpythonpython']
Puncte cheie:
Atât concatenarea, cât și repetiția creează noi obiecte secvențiale; acestea nu modifică secvențele originale la locul lor.
Pentru concatenare, ambii operanzi trebuie să fie de același tip de secvență (de exemplu, șir + șir). Încercarea de a concatena direct diferite tipuri de secvențe va duce la o eroare de tip TypeError.
Pentru repetiție, un operand trebuie să fie o secvență, iar celălalt trebuie să fie un număr întreg. Un număr întreg negativ va duce la o secvență goală.
Key Points:
Both concatenation and repetition create new sequence objects; they do not modify the original sequences in place.
For concatenation, both operands must be of the same sequence type (e.g., string + string). Attempting to concatenate different sequence types directly will result in a TypeError.
For repetition, one operand must be a sequence and the other must be an integer. A non-positive integer will result in an empty sequence.
Comparație cu alte metode.
Deși utilizarea funcției map() este o abordare validă și "funcțională", în special cu lambda pentru operații scurte, nu este întotdeauna cea mai lizibilă sau eficientă metodă pentru repetarea șirurilor de caractere.
Înmulțirea șirurilor de caractere (*): Pentru repetarea unui singur șir de un număr stabilit de ori, operatorul * este cea mai simplă și mai directă metodă.
Comparison to other methods.
While using map() is a valid and "functional" approach, especially with lambda for short operations, it is not always the most readable or efficient method for string repetition.
String multiplication (*): For repeating a single string a set number of times, the * operator is the simplest and most direct method.
