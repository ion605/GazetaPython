Funcția id() în Python - The id() function in Python

Python id() Function

Funcția id() din Python este o funcție încorporată care returnează "identitatea" unui obiect. Această identitate este un număr întreg care este garantat a fi unic și constant pentru obiectul respectiv pe durata de viață a acestuia.

Caracteristici cheie ale funcției id()
Identitate unică: Fiecare obiect din memorie are o identitate, iar id() returnează acest identificator unic.
Constantă pe durata de viață: id()-ul unui obiect rămâne același atâta timp cât obiectul există în memorie.
Adresă de memorie (CPython): În implementarea CPython (cea mai comună implementare Python), valoarea id() corespunde de obicei adresei de memorie a obiectului.
Privind durata de viață: Este posibil ca două obiecte distincte cu durate de viață care nu se suprapun să aibă aceeași valoare id(), deoarece adresele de memorie pot fi realocate odată ce un obiect nu mai este utilizat.
Verificarea identității: id() determină dacă două variabile se referă la exact același obiect din memorie, mai degrabă decât să aibă doar aceeași valoare.
Ca o optimizare, Python stochează automat în cache numerele întregi din intervalul -5 până la 256 la pornire. Orice variabilă inițializată în acest interval indică exact același obiect partajat din memorie.

The id() function in Python is a built-in function that returns the "identity" of an object. This identity is an integer that is guaranteed to be unique and constant for that specific object during its lifetime.

Key characteristics of id()
Unique Identity: Each object in memory has a distinct identity, and id() returns this unique identifier.
Constant During Lifetime: The id() of an object remains the same as long as the object exists in memory.
Memory Address (CPython): In the CPython implementation (the most common Python implementation), the id() value typically corresponds to the object's memory address.
Lifetime Considerations: It is possible for two distinct objects with non-overlapping lifetimes to have the same id() value, as memory addresses can be reallocated once an object is no longer in use.
Checking Object Identity: id() is useful for determining if two variables refer to the exact same object in memory, rather than just having the same value.
As an optimization, Python automatically caches integers from -5 to 256 at startup. Any variable initialized within this range points to the exact same shared object in memory.

Cu toate acestea, id(numere_1) și id(numere_2) vor fi diferite, deoarece listele sunt obiecte mutabile și, chiar dacă conțin aceleași elemente, sunt obiecte distincte în memorie.

In this example, id(a) and id(b) will likely be the same because Python often optimizes small, immutable objects like integers by having multiple variables refer to the same object. However, id(numere_1) and id(numere_2) will be different because lists are mutable objects, and even if they contain the same elements, they are distinct objects in memory.

Aliasuri ale unei liste - Aliases of a List

În Python, aliasul unei liste are loc atunci când două sau mai multe variabile se referă la același obiect listă din memorie. Aceasta înseamnă că, în loc să creați o copie separată a listei, creați un alt nume (alias) care indică lista identică.

Cum se întâmplă aliasingul: Aliasingul apare de obicei atunci când atribuiți o variabilă de listă alteia. Operatorul de atribuire (=) nu creează copii ale obiectelor în Python. În schimb, creează legături între variabilă și obiectul implicat în atribuire.

In Python, aliasing of a list occurs when two or more variables refer to the same list object in memory. This means that instead of creating a separate copy of the list, you are creating another name (alias) that points to the identical list.

How Aliasing Happens: Aliasing typically arises when you assign one list variable to another. The assignment operator (=) does not create copies of objects in Python. Instead create bindings between the variable and the object involved in the assignment.

numere = [1, 2, 3]

print(id(listă_alias) == id(numere)) ==> True
print(listă_alias is numere) ==> True

În acest scenariu, lista numere și listă_alias indică ambele către același obiect listă din memorie.

Consecințele aliasingului: Deoarece ambele variabile se referă la același obiect, orice modificare efectuată prin intermediul unui alias va fi reflectată la accesarea listei prin intermediul celuilalt alias. Acest lucru este deosebit de important în cazul obiectelor mutabile, cum ar fi listele.

In this scenario, original_list and aliased_list both point to the same list object in memory.

Consequences of Aliasing: Because both variables refer to the same object, any modification made through one alias will be reflected when accessing the list through the other alias. This is particularly important with mutable objects like lists.

Orice se face asupra listei de alias se reflectă în lista care la creat. Atunci de ce avem nevoie de o listă alias?

Conceptul de "aliasing al listelor" se referă la o situație în care mai multe variabile indică spre același listă din memorie. Nu este o caracteristică pe care "trebuie" să o creați explicit, ci este o consecință a modului în care Python gestionează referințele la obiecte și atribuirile cum ar fi listele.

Iată de ce este crucial să înțelegeți și să gestionați aliasingul:

Stare partajată și efecte secundare:
Când atribuiți o variabilă listă alteia (de exemplu, lista_b = lista_a), ambele variabile indică aceeași listă din memorie. Orice modificare făcută prin lista_a va fi reflectată și atunci când este accesată prin lista_b și invers. Această stare partajată poate duce la efecte secundare neașteptate dacă nu sunteți conștient de ea, în special atunci când transmiteți liste către funcții sau le modificați în diferite părți ale codului.
Eficiență:
Aliasing-ul poate fi eficient în ceea ce privește utilizarea memoriei, deoarece evită crearea unor copii duplicat ale unor structuri de date mari atunci când sunt suficiente referințe multiple către aceleași date.
Proiectare intenționată:
În unele cazuri, aliasingul intenționat este un instrument puternic pentru proiectarea structurilor de date sau a algoritmilor. De exemplu, într-o reprezentare a tablei de joc, puteți crea aliasuri pentru anumite grupuri de celule (ca rânduri, coloane sau diagonale) pentru a verifica cu ușurință condițiile de câștig fără a duplica datele.

Când "trebuie" luat în considerare aliasingul (sau evitat).

Lizibilitate a indiciilor de tip:
Deși nu se referă direct la aliasul de liste, aliasul de tip (typing.TypeAlias sau pur și simplu atribuind un indiciu de tip unei variabile) este utilizat pentru a crea indicii de tip mai lizibile și ușor de gestionat pentru structuri de liste complexe (de exemplu, MyDataList = list[dict[str, int]]). Este vorba despre îmbunătățirea clarității codului, nu despre referințe la obiecte partajate.
Prevenirea modificărilor neintenționate:
A modifica o listă fără a afecta alte variabile care ar putea face referire la original, trebuie să creați explicit o copie a listei (de exemplu, folosind lista_b = lista_a[:], lista_b = list(lista_a) sau copy.deepcopy() pentru liste imbricate). Aceasta se referă la evitarea aliasingului atunci când starea partajată este nedorită.
Optimizarea utilizării memoriei:
Când aveți liste foarte mari și nevoie de mai multe referințe la aceleași date, aliasingul poate fi o alegere conștientă pentru a economisi memorie.

În esență, nu "trebuie" să creați aliasuri pentru liste; acestea se întâmplă automat atunci când atribuiți o variabilă de listă alteia. Înțelegând comportamentul și implicațiile sale asupra mutabilității și stării partajate este fundamentală pentru scrierea unui cod Python corect și previzibil.

Anything is done to alias list is reflected to list which created it. Then why do we need alias list.

The concept of "aliasing lists" refers to a situation where multiple variables refer to the same list object in memory. This is not a feature you "need" to explicitly create, but rather a consequence of how Python handles object references and assignments with mutable data types like lists.

Here's why understanding and managing aliasing is crucial:

Shared State and Side Effects:
When you assign one list variable to another (e.g., list_b = list_a), both variables point to the same list in memory. Any modification made through list_a will also be reflected when accessed through list_b, and vice-versa. This shared state can lead to unexpected side effects if you're not aware of it, especially when passing lists to functions or modifying them within different parts of your code.
Efficiency:
Aliasing can be efficient in terms of memory usage, as it avoids creating duplicate copies of large data structures when multiple references to the same data are sufficient.
Intentional Design:
In some cases, intentional aliasing is a powerful tool for designing data structures or algorithms. For example, in a game board representation, you might alias certain groups of cells (like rows, columns, or diagonals) to easily check for winning conditions without duplicating data.

When you might "need" to consider aliasing (or avoid it).

Type Hinting Readability:
While not directly about list aliasing, type aliases (using typing.TypeAlias or simply assigning a type hint to a variable) are used to create more readable and manageable type hints for complex list structures (e.g., MyDataList = list[dict[str, int]]). This is about improving code clarity, not about shared object references.
Preventing Unintended Modifications:
If you want to modify a list without affecting other variables that might be referencing the original, you need to explicitly create a copy of the list (e.g., using list_b = list_a[:], list_b = list(list_a), or copy.deepcopy() for nested lists). This is about avoiding aliasing when shared state is undesirable.
Optimizing Memory Usage:
When dealing with very large lists and you only need multiple references to the same data, aliasing can be a conscious choice to save memory.

In essence, you don't "need" to create aliases for lists; they happen automatically when you assign one list variable to another. However, understanding this behavior and its implications for mutability and shared state is fundamental to writing correct and predictable Python code.

Copie superficială a listei - Shallow copy list

O copie superficială a unei liste în Python creează un nou obiect listă, dar nu copiază recursiv elementele din listă. În schimb, copiază referințele la elementele originale.

Aceasta înseamnă:
Pentru elementele imuabile (ca numere întregi, șiruri de caractere sau tupluri), modificările aduse elementelor listei originale nu vor afecta copia superficială și invers, deoarece aceste elemente sunt copiate după valoare.
Pentru elementele mutabile (cum ar fi listele imbricate sau dicționarele), atât lista originală, cât și copia superficială vor conține referințe la aceleași obiecte mutabile. Prin urmare, modificarea unui element mutabil dintr-o listă va afecta și cealaltă listă, deoarece acestea indică același obiect subiacent din memorie.

A shallow copy of a list in Python creates a new list object, but it does not recursively copy the elements within the list. Instead, it copies the references to the original elements.

This means:
For immutable elements (like integers, strings, or tuples), changes to the original list's elements will not affect the shallow copy, and vice-versa, because these elements are copied by value.
For mutable elements (like nested lists or dictionaries), both the original list and the shallow copy will contain references to the same mutable objects. Therefore, modifying a mutable element within one list will also affect the other list, as they are pointing to the same underlying object in memory.

Metoda copy() - copy() Method

În Python, copy() se referă, de obicei, la metoda disponibilă pentru anumite structuri de date mutabile – precum listele și mulțimile – care creează o copie superficială a obiectului.

In Python, copy() typically refers to the method available on certain mutable data structures, like lists and sets, that creates a shallow copy of the object.

După cum s-a demonstrat, copy() creează un obiect nou, modificările aduse elementelor de nivel superior ale copiei nu afectează obiectul original. Dacă obiectul original conține obiecte imbricate mutabile (o altă listă), copy() copiază doar referințele către acele obiecte imbricate. Prin urmare, modificările aduse obiectelor imbricate – fie prin intermediul originalului, fie prin cel al copiei – se vor reflecta în ambele.

As demonstrated, copy() creates a new object, so changes to the top-level elements of the copy do not affect the original. However, if the original object contains mutable nested objects (like another list), copy() only copies the references to those nested objects. Therefore, changes to the nested objects through either the original or the copy will be reflected in both.

Funcția copy.copy() - copy.copy() Function

copy — Shallow and deep copy operations

copy.copy() din modulul built-in copy al lui Python creează o copie superficială a unui obiect. Funcția construiește un nou obiect de tip colecție și îl populează cu referințe către obiectele componente (sub-obiectele) din colecția originală, în loc să multiplice efectiv acele obiecte componente.

  • Sintaxă: copy.copy(x)
  • Scop: Creează un nou obiect exterior, dar partajează referințele interne pentru elementele imbricate.
  • Alternativă: Pentru colecții simple, precum listele, se comportă identic cu apelarea list.copy().

Comportamentul structurilor plate versus cele imbricate: Impactul unei copii superficiale depinde în întregime de faptul dacă structura de date conține elemente mutabile imbricate (cum ar fi o listă în interiorul altei liste).

  • Structuri plane (elemente independente):
  • Dacă un obiect conține doar elemente imutabile (precum numere sau șiruri de caractere), modificarea structurii de nivel superior a copiei nu va afecta obiectul original.
  • Structuri imbricate (referințe partajate):
  • Dacă un obiect conține structuri mutabile imbricate, atât obiectul original, cât și cel copiat vor face referire la același obiect intern în memorie. Modificarea unui element din interiorul acelui container intern va afecta ambele liste.

The copy.copy() function in Python's built-in copy module creates a shallow copy of an object. This means it constructs a new collection object and populates it with references to the child objects found in the original, rather than duplicating those child objects themselves.

  • Syntax: copy.copy(x)
  • Purpose: Creates a new outer object but shares internal references for nested elements.
  • Alternative: For simple collections like lists, it behaves identically to calling list.copy()

Behavior with Flat vs. Nested Structures: The impact of a shallow copy depends entirely on whether your data structure contains nested mutable elements (like a list inside another list).

  • Flat Structures (Independent Elements):
  • If an object only contains immutable items (like numbers or strings), modifying the top-level structure of the copy will not affect the original.
  • Nested Structures (Shared References):
  • If an object contains nested mutable structures, both the original and the copied object will point to the same inner object in memory. Modifying an item inside that inner container will affect both lists.

Când creezi o copie superficială a unui obiect, doar obiectul părinte este clonat ca entitate distinctă, în timp ce descendenții săi rămân aceiași obiecte, partajate între copii prin referințe duplicate. Cu alte cuvinte, o copie superficială are o adâncime de doar un nivel.

Când să folosești copy.copy()

Pentru o copie rapidă și eficientă din punctul de vedere al memoriei, iar elementele sunt complet imutabile (șirurile de caractere, numerele întregi sau tuplurile), or când dorești în mod intenționat ca schimbările interioare să se sincronizeze.

Pentru a controla modul în care obiectele din clase personalizate gestionează copiile superficiale, poți implementa metoda __copy__() direct în definiția clasei.

When you make a shallow copy of an object, only the parent object is cloned as a distinct entity, while its descendants remain the same objects, shared between copies through duplicated references. In other words, a shallow copy is only one level deep.

When to use copy.copy()

Use copy.copy() when you want a fast, memory-efficient copy and your elements are purely immutable (like strings, integers, or tuples), or when you intentionally want inner changes to sync.

Customizing Shallow Copies

If you want to control how custom class objects handle shallow copies, you can implement the special __copy__() dunder method directly within your class definition.

Copii detaliate ale unei liste - Deep Copies of a List

copy — Shallow and deep copy operations

O copie profundă a unei liste în Python creează un duplicat complet independent al listei originale, inclusiv toate elementele imbricate și obiectele mutabile. Aceasta înseamnă că orice modificări aduse listei copiate profund, chiar și subelementelor sale imbricate, nu vor afecta lista originală. Pentru a crea o copie profundă în Python, se utilizează funcția deepcopy() din modulul de copiere încorporat.

A deep copy of a list in Python creates a completely independent duplicate of the original list, including all nested elements and mutable objects. This means that any changes made to the deep-copied list, even to its nested sub-elements, will not affect the original list. To create a deep copy in Python, the deepcopy() function from the built-in copy module is used.

import copy

listă_mixtă = ["salut", 123, True, [6, 7]]
listă_copiată_în_detaliu = copy.deepcopy(listă_mixtă)

print(f"ID-ul listei care generează copia profundă: {id(listă_mixtă)}")
==> ID-ul listei care generează copia profundă: 2529997480064
print(f"ID-ul copie profundă: {id(listă_copiată_în_detaliu)}")
==> ID-ul copie profundă: 2529997059392

# Obiectele imutabile nu pot fi schimbate in-place (pe loc)
print(id(listă_mixtă[0]) == id(listă_copiată_în_detaliu[0])) ==> True
print(id(listă_mixtă[3]) == id(listă_copiată_în_detaliu[3])) ==> False

print(f"Copie profundă: {listă_copiată_în_detaliu}")
==> Copie profundă: ['salut', 123, True, [6, 7]]
print(f"Cele două liste conţin aceleaşi elemente: {listă_copiată_în_detaliu == listă_mixtă}")
==> Cele două liste conţin aceleaşi elemente: True
print(f"Copia este lista originală: {listă_copiată_în_detaliu is listă_mixtă}")
==> Copia este lista originală: False

# Modifică un element imbricat imuabile
listă_copiată_în_detaliu[0] = "ne vedem mai târziu"
# Modifică un element imbricat mutabil
listă_copiată_în_detaliu[-1].append(8)
listă_copiată_în_detaliu[3][0] = 1

print(f"Copia superficială după modificarea listei [6, 7]: {listă_copiată_în_detaliu}")
==> Copia superficială după modificarea listei [6, 7]: ['ne vedem mai târziu', 123, True, [1, 7, 8]]
print(f"Lista originală după modificarea copiei: {listă_mixtă}")
==> Lista originală după modificarea copiei: ['salut', 123, True, [6, 7]]
print(f"După modificare cele două liste conţin aceleaşi elemente: {listă_copiată_în_detaliu == listă_mixtă}")
==> După modificare cele două liste conţin aceleaşi elemente: False

Modificarea funcției listă_copiată_în_detaliu nu modifică funcția listă_mixtă, deoarece deepcopy() asigură o duplicare recursivă a tuturor obiectelor, inclusiv a listelor imbricate, rezultând o independență deplină între original și copie.

Modifying deep_copied_list does not alter original_list, because deepcopy() ensures a recursive duplication of all objects, including nested lists, resulting in full independence between the original and the copy.

Copierea superficială vs. copierea profundă - Shallow vs Deep Copying

Alegerea dintre ele depinde de necesitatea ca obiectele originale și cele copiate să fie complet independente sau nu, atunci când se lucrează cu structuri mutabile imbricate.

Copie superficială:
O copie superficială creează un nou obiect compus, dar îl populează cu referințe către obiectele găsite în cel original.
Înseamnă că, deși nivelul superior (exe, o listă) este un obiect nou, orice obiecte imbricate mutabile din cadrul acestuia nu sunt copiate. Atât originalul, cât și copia superficială se vor referi la aceleași obiecte imbricate.
Modificările aduse unui obiect imbricat mutabil din copia superficială se vor reflecta și în obiectul original, deoarece ambele indică aceleași date subiacente.
Copiile superficiale sunt mai rapide și utilizează mai puțină memorie, deoarece copiază doar referințe.
Se realizează folosind copy.copy() sau felierea pentru liste (listă = listă_originală[:]).
Copie profundă:
deep copy creează un obiect compus complet nou și inserează recursiv copii ale tuturor obiectelor găsite în original, inclusiv toate obiectele mutabile imbricate.
Aceasta asigură că originalul și copia profundă sunt complet independente. Modificările aduse oricărei părți a copiei profunde, inclusiv structurilor imbricate, nu vor afecta obiectul original.
Copiile profunde consumă mai multă memorie și pot fi mai lente decât copiile superficiale, în special pentru structurile complexe sau profund imbricate, datorită procesului de copiere recursivă.
Realizat folosind copy.deepcopy().
Cazuri de utilizare:
Alegeți copierea superficială (shallow copy) atunci când lucrați cu obiecte imutabile sau când doriți ca modificările aduse obiectelor mutabile imbricate să se reflecte atât în ​​original, cât și în copie.
Alegeți copierea profundă (deep copy) atunci când aveți nevoie de o izolare completă între original și copie, în special în cazul structurilor de date complexe care conțin elemente mutabile imbricate.

The choice between them depends on whether the original and copied objects need to be completely independent or not, especially when dealing with nested mutable structures.

Shallow Copy
A shallow copy creates a new compound object but populates it with references to the objects found in the original.
This means that while the top-level container (e.g., a list) is a new object, any mutable nested objects within it are not copied. Instead, both the original and the shallow copy will refer to the same nested objects.
Changes made to a mutable nested object in the shallow copy will also be reflected in the original object because they both point to the same underlying data.
Shallow copies are generally faster and use less memory than deep copies, as they only copy references.
Achieved using copy.copy() or slicing for lists (new_list = original_list[:]).
Deep Copy:
deep copy creates a completely new compound object and recursively inserts copies of all objects found in the original, including all nested mutable objects.
This ensures that the original and the deep copy are entirely independent. Changes made to any part of the deep copy, including nested structures, will not affect the original object.
Deep copies are more memory-intensive and can be slower than shallow copies, especially for complex or deeply nested structures, due to the recursive copying process.
Achieved using copy.deepcopy().
Use Cases:
Choose shallow copy when working with immutable objects or when you intend for changes in nested mutable objects to be reflected in both the original and the copy.
Choose deep copy when you need complete isolation between the original and the copy, especially when dealing with complex data structures containing mutable nested elements.

Concatenarea listelor - Concatenating Lists

Operatorul +
Operatorul + este cea mai simplă și mai frecvent utilizată metodă pentru concatenarea listelor. Acesta creează o listă nouă care conține toate elementele din listele originale în ordinea în care apar. Ordinea elementelor din lista rezultată va urma ordinea listelor din concatenare.
The + operator
The + operator is the most straightforward and commonly used method for concatenating lists. It creates a new list containing all elements from the original lists in the order they appear. The order of elements in the resulting list will follow the order of the lists in the concatenation.
numere = [1, 2, 3]
litere = ["a", "b", "c"]
listă_combinată = numere + litere
print(f"Listă combinată: {listă_combinată}")
==> Listă combinată: [1, 2, 3, 'a', 'b', 'c']
+= Operator de modificare pe loc
Operatorul += din Python este un operator de atribuire pe-loc (sau augmentată) care adaugă o valoare unei variabile și atribuie rezultatul aceleiași variabile. Acesta servește drept formă concisă pentru x = x + y.
Operatorul += modifică direct lista originală, în loc să aloce una nouă în memorie.
+= In-place Operator
The += operator in Python is an in-place / augmented assignment operator that adds a value to a variable and assigns the result back to that same variable. It serves as a concise shorthand for x = x + y
+= In-place Operator: Modifies the original list directly rather than allocating a new one in memory
listă_numere = [1, 2, 3]

# Afișează adresa de memorie originală
print(f"ID-ul înainte de modificare: {id(listă_numere)}")
==> ID-ul înainte de modificare: 2025887542144

# Modifică lista in-place (similar cu .extend())
listă_numere += [4, 5]
print(f"Lista originală modificată pe loc: {listă_numere}")
==> Lista originală modificată pe loc: [1, 2, 3, 4, 5]
# Afișează aceeași adresă de memorie
print(f"ID-ul după de modificare: {id(listă_numere)}") 
==> ID-ul după de modificare: 2025887542144

# Obiect mutabil (Ambele variabile se modifică)
lista_a = [1, 2]
lista_b = lista_a   # Ambele indică spre aceeași listă
lista_a += [3]      # Modifică obiectul subiacent
print(lista_b)      ==> [1, 2, 3] (și list_b este actualizată!)
Avantaje
Memorie și viteză: Modifică structuri mutabile de mari dimensiuni (precum listele) in-place (pe loc), fără a aloca un nou bloc de memorie pentru un obiect nou.
Sintaxă clară: Scurtătură concisă și ușor de citit pentru operații de acumulare, evitând necesitatea de a scrie de două ori numele variabilei în cadrul atribuirii.
Evaluare unică: Evaluează expresia țintă o singură dată, ceea ce este mai sigur și mai rapid decât cea standard.
Dezavantaje
Efecte secundare legate de referințele partajate:
Modifică toate variabile care indică spre același obiect mutabil, generând efecte secundare neintenționate.
Nu este o operație veritabilă in-place pentru tipurile imutabile: Se comportă exact ca o atribuire standard (x = x + y) când este utilizată cu numere întregi, șiruri sau tupluri, creând un obiect complet nou în fundal.
Particularități privind mutarea tuplurilor: Poate genera o eroare de tip (TypeError) însoțită de o modificare parțială dacă o listă mutabilă este inclusă (imbricată) într-un tuplu imutabil în timpul unei operații +=.
Advantages
Memory and Speed: Modifies large mutable structures (like lists) in place without allocating a fresh block of memory for a new object.
Clean Syntax: Acts as a short, easy-to-read shortcut for accumulation compared to writing out long assignment names twice.
Single Evaluation: Evaluates the target expression only one time, which is safer and faster than standard.
Disadvantages
Shared Reference Side Effects:
Alters all other variables pointing to the exact same mutable object, leading to unintended side effects.
Not True In-Place for Immutable Types: Behaves just like standard assignment (x = x + y) when used on integers, strings, or tuples, creating a brand-new object behind the scenes.
Tuple Mutation Exception Quirks: Can raise a TypeError combined with a partial modification if a mutable list is nested inside an immutable tuple during a += operation.
Operatorul * (despachetare)
Această metodă implică despachetarea elementelor mai multor liste într-o listă nouă. Este o modalitate concisă de a combina liste, în special atunci când se lucrează cu mai multe liste.
Operatorul cu un singur asterisc (*) adesea numit operator de despachetare sau splat extrage elemente individuale dintr-o colecție iterabilă, precum o listă. Acesta elimină necesitatea utilizării unor bucle sau a operațiilor de feliere (slicing) pe bază de indici.
The * (unpacking) operator
This method involves unpacking the elements of multiple lists into a new list. It's a concise way to combine lists, especially when dealing with multiple lists.
The single asterisk * operator (often called the unpacking or splat operator) extracts individual elements out of an iterable collection like a list. It eliminates the need for loops or index slicing.
lista1 = [1, 2, 3]
lista2 = [4, 5, 6]
lista3 = [7, 8]
listă_combinată = [*lista1, *lista2, *lista3]
print(listă_combinată) ==> [1, 2, 3, 4, 5, 6, 7, 8]

# Combină o listă cu diferite tipuri iterabile
listă = [1, 2]
tuplu = (3, 4)
interval = range(5, 7)

# Despachetarea unor tipuri diferite într-o singură listă plată
listă_combinată = [*listă, *tuplu, *interval]
print(listă_combinată) ==> [1, 2, 3, 4, 5, 6]

Python List extend() Method

Data Structures

metoda extend()
Această metodă modifică o listă existentă prin adăugarea tuturor elementelor dintr-un alt iterabil (cum ar fi o altă listă) la sfârșitul acesteia. extend() nu creează o listă nouă, ci modifică lista originală la locul ei.
Greșeală frecventă: Scrierea a = a.extend(b) va suprascrie variabila cu None, (a și b sunt liste).
Necesită un obiect iterabil: transmiterea unui număr întreg sau cu virgulă generează o eroare TypeError.
extend() method
This method modifies an existing list by appending all elements from another iterable (like another list) to its end. extend() does not create a new list but modifies the original list in-place.
Common Mistake: Writing a = a.extend(b) will overwrite the variable with None, (a and b are lists).
Requires an Iterable: Passing an integer or float results in a TypeError.
# Extinderea cu o altă listă
numere = [1, 2, 3]
litere = ["a", "b", "c"]
numere.extend(litere)
print(numere) ==> [1, 2, 3, 'a', 'b', 'c']

# Extinderea cu alte iterabile
numere = [1, 2, 3]
# Tuplu
numere.extend((4, 5)) 
# Șir (despachetează fiecare caracter)
numere.extend('AB')   

print(numere) ==> [1, 2, 3, 4, 5, 'A', 'B']

Repeating an Entire List
Multiplication Operator (*): This is the simplest and most efficient way to create a new list by repeating the original list a specified number of times.
numere = [1, 2, 3]
listă_repetată = numere * 3
print(listă_repetată) ==> [1, 2, 3, 1, 2, 3, 1, 2, 3]
Repetarea fiecărui element dintr-o listă
Înțelegerea (Comprehension) listei: Aceasta oferă o modalitate concisă și eficientă de a crea o listă nouă în care fiecare element din lista originală este repetat de un număr specificat de ori.
Repeating Each Element within a List
List Comprehension: This provides a concise and efficient way to create a new list where each element from the original list is repeated a specified number of times.
numere = [4, 5, 6]
număr_repetări = 3
listă_de_elemente_repetate = [număr for număr in numere for _ in range(număr_repetări)]
print(listă_de_elemente_repetate)  ==> [4, 4, 4, 5, 5, 5, 6, 6, 6]
Repetarea și modificarea obiectelor mutabile
Aveți grijă când utilizați operatorul * asupra unor liste care conțin obiecte mutabile, cum ar fi liste imbricate.
Repeating and modifing mutable objects
Be careful when using the * operator on lists containing mutable objects like nested lists.
matrice = [[15] * 2] * 3 
print(f"Matricea originală: {matrice}")
==> Matricea originală: [[15, 15], [15, 15], [15, 15]]
# Primul element modificat în fiecare grupă
matrice[0][0] = 99
print(f"Matricea după modificare: {matrice}")
==> Matricea după modificare: [[99, 15], [99, 15], [99, 15]]

# list comprehension pentru a inițializa liste interne distincte
matrice = [[15] * 2 for _ in range(3)] 
print(f"Matricea originală: {matrice}")
==> Matricea originală: [[15, 15], [15, 15], [15, 15]]
# Primul element modificat în prima grupă
matrice[0][0] = 99
print(f"Matricea după modificare {matrice}")
==> Matricea după modificare [[99, 15], [15, 15], [15, 15]]
Bucle imbricate (bucle for explicite)
O abordare mai detaliată, dar la fel de eficientă, implică utilizarea buclelor for pentru a adăuga fiecare element de mai multe ori la o listă nouă.
În Python, o buclă imbricată presupune plasarea unei bucle în interiorul corpului altei bucle. Atunci când se procesează liste repetitive folosind "bucle for explicite", bucla interioară se execută complet la fiecare iterație a buclei exterioare.
Nested Loops (Explicit for loops)
A more verbose, but equally effective, approach involves using nested for loops to append each element multiple times to a new list.
In Python, a nested loop means placing one loop inside the body of another loop. When handling repeating lists with "explicit for loops", the inner loop will execute completely for every single iteration of the outer loop
# Definește trei liste separate
sporturi = ["Tenis", "Fotbal"]
zile = ["Luni", "Marţi"]
când = ["dimineaţă", "după amiază"]

# Bucla exterioară controlează de câte ori se repetă secvența din bucla interioară.
for sport in sporturi:
# Bucla interioară se execută complet, de la început până la sfârșit, 
#pentru fiecare element din bucla exterioară.
    for zi in zile:
        if sport.startswith("T"):
            print(f"Sportul: {sport}, Ziua: {zi} - timpul: {când[0]}")
        else:
            print(f"Sportul: {sport}, Ziua: {zi} - timpul: {când[1]}")

==> Sportul: Tenis, Ziua: Luni - timpul: dimineaţă
==> Sportul: Tenis, Ziua: Marţi - timpul: dimineaţă
==> Sportul: Fotbal, Ziua: Luni - timpul: după amiază
==> Sportul: Fotbal, Ziua: Marţi - timpul: după amiază

listă_nivel_unu = [7, 8]
număr_repetări = 2
listă_de_elemente_repetate = []
for element in listă_nivel_unu:
    for _ in range(număr_repetări):
        listă_de_elemente_repetate.append(element)
print(listă_de_elemente_repetate) ==> [7, 7, 8, 8]

În Python, utilizarea caracterului de subliniere simplă (_) într-o buclă de tipul "for _ in" ... reprezintă o convenție standard de denumire pentru a desemna o variabilă de tip "placeholder" sau una a cărei valoare nu este utilizată (variabilă "de unică folosință"). Aceasta semnalează oricui citește codul (precum și instrumentelor de analiză a codului) că variabila buclei este necesară din punct de vedere sintactic, dar valoarea sa efectivă nu va fi folosită în corpul buclei. Din punct de vedere tehnic, "_" este un nume de variabilă absolut valid și obișnuit în Python. Cu toate acestea, dezvoltatorii îl aleg exclusiv pentru a indica faptul că valoarea variabilei nu prezintă interes.

In Python, the single underscore (_) in a "for _ in" ... loop is a standard naming convention used to indicate a throwaway or placeholder variable. It signals to anyone reading the code (and to code analysis tools) that the loop variable is required by Python's syntax but its actual value will not be used inside the loop body. Technically, "_" is a completely valid, normal variable name in Python. However, developers choose it exclusively as a "don't care" marker.

itertools.repeat() built-in Python function

itertools — Functions creating iterators for efficient looping

Pentru scenarii de repetiție mai complexe sau atunci când se lucrează cu iteratoare, aceste funcții din modulul itertools pot fi utile. Creează un iterator care returnează exact același obiect, în mod repetat, la infinit sau de un număr fix de ori.

Oferă o eficiență și o viteză remarcabile în ceea ce privește utilizarea memoriei și procesarea datelor, întrucât transmite fluxuri de referințe către un singur obiect, în loc să construiască o listă complet nouă în memorie.

For more complex repetition scenarios or when working with iterators, these functions from the itertools module can be useful. It creates an iterator yielding the exact same object, repeatedly infinitely or for a fixed number of times.

It offers remarkable efficiency and speed in memory usage and data processing, as it streams references to a single object rather than constructing an entirely new list in memory.

import itertools

# Creează o listă formată din repetarea unei singure valori.
listă_repetată = list(itertools.repeat(7, 4))
print(listă_repetată)  ==> [7, 7, 7, 7]


# Repetă un cuvânt de 3 ori
cuvinte = list(itertools.repeat("Python", 3))
print(cuvinte) ==> ['Python', 'Python', 'Python']

# zip() pentru a adăuga o constantă
numere_pare = [12, 14, 16]
# Asociază fiecare număr unic cu aceeași stare constantă.
tupluri = list(zip(numere_pare, itertools.repeat("par")))
print(tupluri) ==>[(12, 'par'), (14, 'par'), (16, 'par')]

itertools.chain.from_iterable

Este o metodă eficientă utilizată în Python pentru a aplatiza un singur iterabil imbricat (o listă de liste sau un generator de secvențe) într-un singur iterator plat.

Is a memory-efficient method in Python used to flatten a single nested iterable (like a list of lists or a generator yielding sequences) into a single flat iterator

import itertools
a_b = ['a', 'b']
rptă = 2
listă = list(
itertools.chain.from_iterable(itertools.repeat(elm, rptă) for elm in a_b))
print(listă) ==> ['a', 'a', 'b', 'b']

# Un singur obiect iterabil care conține liste imbricate
listă_imbricată = [[1, 2], [3, 4], [5, 6]]
# Aplatizare
iterator_plat = itertools.chain.from_iterable(listă_imbricată)
print(iterator_plat) ==> <itertools.chain object at 0x00000186E17454E0>
# Convertește într-o listă pentru a vedea rezultatul
print(list(iterator_plat)) ==> [1, 2, 3, 4, 5, 6]
