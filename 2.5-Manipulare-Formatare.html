strip(): elimină spațiile albe (sau caracterele specificate) de la început și de la sfârșit dintr-un șir de caractere.

Parametri:
chars (opțional): Un șir care specifică setul de caractere care trebuie eliminate de la începutul și sfârșitul șirului. Dacă chars este omis, strip() elimină toate spațiile albe de la început și de la sfârșit (spații, tabulatori, linii noi).
Comportament:
Fără chars: Elimină toate spațiile albe de la început și de la sfârșit.
Cu chars: Elimină orice caracter prezent în șirul chars de la începutul și de la sfârșit al șirului țintă. Ordinea caracterelor din chars nu contează; este tratat ca un set de caractere care trebuie eliminate. Eliminarea continuă până când se întâlnește un caracter care nu este găsit în chars.
Returnează:
Un șir nou din care au fost eliminate caracterele specificate. Șirul original rămâne neschimbat.

strip(): removes leading and trailing whitespace (or specified characters) from a string.

Parameters:
chars (optional): A string specifying the set of characters to be removed from the beginning and end of the string. If chars is omitted, strip() removes all leading and trailing whitespace characters (spaces, tabs, newlines).
Behavior:
Without chars: Removes all leading and trailing whitespace characters.
With chars: Removes any character present in the chars string from the beginning and end of the target string. The order of characters in chars does not matter; it's treated as a set of characters to be removed. The stripping continues until a character not found in chars is encountered.
Returns:
A new string with the specified characters removed. The original string remains unchanged.

strip() Combinații
Metoda strip() din Python poate fi combinată eficient cu alte metode șir de caractere pentru a efectua manipulări și curățări de text mai complexe. Acest lucru se realizează adesea prin înlănțuirea apelurilor de metode, deoarece fiecare metodă șir de caractere returnează de obicei un nou obiect șir de caractere, permițând apelarea unei alte metode pe baza acelui rezultat.
strip() Combinations
strip() method in Python can be effectively combined with other string methods to perform more complex text manipulation and cleaning. This is often achieved by chaining method calls, as each string method typically returns a new string object, allowing another method to be called on that result.
strip().lower() sau strip().upper() pentru standardizare:
Această secvență este utilă pentru curățarea spațiilor albe de la început/sfârșit și apoi convertirea șirului de caractere într-o majuscule/minuscule consistentă pentru comparații sau stocare.
strip().lower() or strip().upper() for case standardization:
This sequence is useful for cleaning leading/trailing whitespace and then converting the string to a consistent case for comparisons or storage.
intrare_utilizator = " Salut, lume!"
curățat_și_minuscule = intrare_utilizator.strip().lower()
print(curățat_și_minuscule)  ==> salut, lume!
strip().replace() pentru înlocuirea caracterelor interne după eliminare:
Mai întâi, eliminați caracterele nedorite de la capete, apoi înlocuiți caracterele sau subșirurile specifice din șir.
strip().replace() for removing internal characters after stripping:
First, remove unwanted characters from the ends, then replace specific characters or substrings within the string.
şir_bani = " $1,234.56 "
şir_curățat = şir_bani.strip().replace(",", "")
print(şir_curățat) ==> $1234.56

Aceasta este utilizată în mod obișnuit pentru a curăța o linie de text prin eliminarea spațiilor albe de la început/sfârșit înainte de a o împărți în componente individuale.
strip().split() for parsing text into a list of words or elements:
This is commonly used to clean up a line of text by removing leading/trailing whitespace before splitting it into individual components.

Sintaxă: şir.lstrip(characters)

lstrip()
Elimină spațiile albe de la început.
parametrul caractere:
Opțional.
Un șir de caractere care conține setul de caractere care trebuie eliminate.
Dacă este omis sau nu există, lstrip() elimină toate spațiile albe de la începutul șirului (spații, tabs, linii noi, întoarceri etc.).
Comportament: Elimină iterativ caracterele de la începutul șirului, atâta timp cât acestea se găsesc în setul de caractere. Se oprește când întâlnește un caracter care nu este prezent în setul de caractere.
lstrip()
Removes leading whitespace characters.
characters parameter:
Optional.
A string containing the set of characters to be removed.
If omitted or None, lstrip() removes all leading whitespace characters (spaces, tabs, newlines, carriage returns, etc.)
Behavior: It iteratively removes characters from the beginning of the string as long as they are found within the characters set. It stops when it encounters a character not present in the characters set.
șir = "  Salut, lume Python!  "
print(șir.lstrip())                       ==> Salut, lume Python!  

șirul_meu = "  salut lume  "
șirul_meu = șirul_meu.lstrip()
print(șirul_meu)                          ==> salut lume

alt_șir = "<---Python--->"
eliminare_începutul = alt_șir.lstrip('<-')
print(eliminare_începutul)                 ==> Python--->

Sintaxă: şir.rstrip(caractere)

rstrip()
Elimină caracterele finale dintr-un șir de caractere.
parametrul caractere:
Opțional.
Un șir de caractere care conține setul de caractere care trebuie eliminate.
Dacă este omis sau nu există, rstrip() elimină toate spațiile albe de la final.
Comportament: Similar cu lstrip(), dar operează de la capătul din dreapta al șirului, eliminând caracterele atâta timp cât acestea se găsesc în setul de caractere.
rstrip()
Removes trailing characters from a string.
characters parameter:
Optional.
A string containing the set of characters to be removed.
If omitted or None, rstrip() removes all trailing whitespace characters.
Similar to lstrip(), but it operates from the right end of the string, removing characters as long as they are found within the characters set.
șir = "  Salut, lume Python!  "
print(șir.rstrip())                      ==> Salut, lume Python!

șirul_meu = "  salut lume  "
șirul_meu = șirul_meu.rstrip()
print(șirul_meu)                         ==> salut lume

alt_șir = "<---Python--->"
eliminare_sfârşit = alt_șir.rstrip('->')
print(eliminare_sfârşit)                 ==> <---Python
Puncte cheie:
Atât lstrip(), cât și rstrip() returnează un șir nou; nu modifică șirul original la locul lui.
Argumentul caractere specifică un set de caractere, nu un prefix sau un sufix specific. Orice caracter din acel set găsit la capătul respectiv va fi eliminat.
Pentru eliminarea atât a caracterelor de la început, cât și a celor de la sfârșit, se poate utiliza metoda strip().
Key Points:
Both lstrip() and rstrip() return a new string; they do not modify the original string in place.
The characters argument specifies a set of characters, not a specific prefix or suffix. Any character from that set found at the respective end will be removed.
For removing both leading and trailing characters, the strip() method can be used.

.removeprefix(prefix, /), .removesuffix(suffix, /)

removeprefix(prefix)
Python 3.9 a introdus metodele removeprefix() și removessuffix() pentru a elimina în mod convenabil un prefix sau sufix specific dintr-un șir de caractere.
Această metodă returnează un nou șir de caractere cu prefixul specificat eliminat dacă șirul începe cu acel prefix. Dacă șirul nu începe cu prefixul, șirul original este returnat neschimbat.
removeprefix(prefix)
Python 3.9 introduced the removeprefix() and removesuffix() string methods for conveniently removing a specific prefix or suffix from a string.
This method returns a new string with the specified prefix removed if the string starts with that prefix. If the string does not start with the prefix, the original string is returned unchanged.
cale = "/home/utilizator/documente/fișier.txt"
cale_curățată = cale.removeprefix("/home/utilizator/")

șir_no_prefix = "salut lume"
rezultat = șir_no_prefix.removeprefix("salut")
print(rezultat)         ==> lume
removesuffix(suffix)
Această metodă returnează un nou șir de caractere cu sufixul specificat eliminat dacă șirul se termină cu acel sufix. Dacă șirul nu se termină cu sufixul, șirul original este returnat neschimbat.
removesuffix(suffix)
This method returns a new string with the specified suffix removed if the string ends with that suffix. If the string does not end with the suffix, the original string is returned unchanged. 
nume_fișier = "raport.pdf"
nume_doar = nume_fișier.removesuffix(".pdf")

șir_versiune = "produs-v1.2.3"

șir_no_suffix = "măr"
rezultat = șir_no_suffix.removesuffix("plăcintă")
print(rezultat)                                   ==> măr
Puncte cheie:
Ambele metode returnează un șir nou; nu modifică șirul original la locul lui.
Sunt sensibile la majuscule/minuscule.
Dacă prefixul sau sufixul nu este găsit, șirul original este returnat fără erori.
Aceste metode oferă o alternativă mai explicită și mai ușor de citit la utilizarea secvențierii șirurilor sau a expresiilor regulate pentru eliminarea simplă a prefixelor/sufixelor.
Key Points:
Both methods return a new string; they do not modify the original string in place.
They are case-sensitive.
If the prefix or suffix is not found, the original string is returned without error.
These methods offer a more explicit and readable alternative to using string slicing or regular expressions for simple prefix/suffix removal.

Python String replace() Method

# Înlocuiește mai multe cuvinte folosind un dicționar și o funcție de apel invers
def înlocuiți_mai_multe_cuvinte(text, înlocuitori):
    model = re.compile(r"\b(" + "|".join(re.escape(cuvânt) for cuvânt in înlocuitori.keys()) + r")\b")
    def înlocuitor(potrivire):
        return înlocuitori[potrivire.group(0)]
    return model.sub(înlocuitor, text)

print(urare_nouă)  ==> Vă salut pe toți, acesta este un test.

.center(width[, fillchar])

Sintaxă: şir.center(width[, fillchar])

Python String center() Method

Parametri:
lățime: Un număr întreg care reprezintă lungimea totală dorită a noului șir. Șirul original va fi centrat în această lungime. Acest parametru este obligatoriu.
fillchar: (Opțional) Un singur caracter de utilizat pentru umplere. Dacă este omis, se vor folosi caractere spație ASCII pentru umplere.
Cum funcționează:
Metoda center() calculează cantitatea de padding necesară pentru a atinge lățimea specificată.
Apoi distribuie acest padding cât mai uniform posibil pe ambele părți, stânga și dreapta, ale șirului original.
Dacă lățimea este mai mică sau egală cu lungimea șirului original, șirul original este returnat neschimbat.
Valoare returnată:
Metoda returnează un nou șir care este șirul original centrat în lățimea specificată, cu umplerea aplicată așa cum este descris. Șirul original rămâne neschimbat.
Parameters:
width: An integer representing the total desired length of the new string. The original string will be centered within this length. This parameter is mandatory.
fillchar: (Optional) A single character to use for padding. If omitted, ASCII space characters will be used for padding.
How it works:
The center() method calculates the amount of padding needed to reach the specified width.
It then distributes this padding as evenly as possible on both the left and right sides of the original string.
If the width is less than or equal to the length of the original string, the original string is returned unchanged.
Return Value:
The method returns a new string that is the original string centered within the specified width, with padding applied as described. The original string remains unchanged.
şir = "Salut"

# Centrare cu umplere implicită pentru spațiu
spații_de_șir_centrate = şir.center(15)
print(f"Centrat cu spații: '{spații_de_șir_centrate}'")    ==> Centrat cu spații: '     Salut     '

# Centrare cu un caracter de umplere personalizat
șir_centrat_asterisks = şir.center(15, '*')
print(f"Centrat cu asteriscuri: '{șir_centrat_asterisks}'") ==> Centrat cu asteriscuri: '*****Salut*****'

# Dacă lățimea este mai mică sau egală cu lungimea șirului, se returnează șirul original
șir_de_lățime_scurtă = şir.center(3)
print(f"Lățime scurtă: '{șir_de_lățime_scurtă}'")            ==> Lățime scurtă: 'Salut'

.ljust(width[, fillchar]), .rjust(width[, fillchar])

Sintaxă: şir.ljust(width[, fillchar])

Python String ljust() Method

metoda ljust() pentru șiruri de caractere:
Parametri:
width: Parametru obligatoriu, specifică lățimea totală dorită a șirului rezultat. Dacă lungimea șirului original este mai mică decât lățimea, se adaugă caractere de umplere pentru a ajunge la această lățime. Dacă lungimea șirului original este mai mare sau egală cu lățimea, șirul original este returnat neschimbat.
fillchar: Parametru opțional, specifică caracterul care va fi utilizat pentru umplere. Dacă este omis, fillchar-ul implicit este un spațiu (' '). Fillchar-ul trebuie să fie un singur caracter; furnizarea a mai multor caractere va duce la o eroare TypeError.
Valoare returnată:
Metoda ljust() returnează un șir nou care este aliniat la stânga în cadrul lățimii specificate, cu partea dreaptă umplută cu fillchar, dacă este necesar.
string method ljust(width, fillchar):
Parameters:
width: This required parameter specifies the total desired width of the resulting string. If the original string's length is less than width, padding characters are added to reach this width. If the original string's length is greater than or equal to width, the original string is returned unchanged.
fillchar: This optional parameter specifies the character to use for padding. If omitted, the default fillchar is a space character (' '). The fillchar must be a single character; providing more than one character will result in a TypeError.
Return Value:
The ljust() method returns a new string that is left-justified within the specified width, with the right side padded by the fillchar if necessary.
cuvânt = "salut"

# Ajustare la stânga cu umplere implicită a spațiului
resultat1 = cuvânt.ljust(10)
print(f"'{resultat1}'")          ==> 'salut     '

# Ajustare la stânga cu caracter de umplere personalizat
resultat2 = cuvânt.ljust(8, '*')
print(f"'{resultat2}'")          ==> 'salut***'

# Șir original returnat dacă lățimea este mai mică sau egală cu lungimea șirului
resultat3 = cuvânt.ljust(4)
print(f"'{resultat3}'")          ==> 'salut'

Este utilizată pentru formatarea șirurilor de caractere, similară cu şir.format(), dar ia ca argument un singur obiect de mapare (cum ar fi un dicționar). Această metodă înlocuiește substituenții dintr-un șir de caractere cu valorile corespunzătoare din maparea furnizată.
formatează un șir de caractere prin înlocuirea substituenților numiți cu valori direct dintr-un dicționar sau din orice obiect de mapare.
Parametri:
șir de caractere: Șirul de caractere cu substituenți (de exemplu, {nume}).
mapare: Un obiect de mapare (de exemplu, un dicționar) care conține perechi cheie-valoare. Cheile din această mapare corespund numelor utilizate în substituenții din șir, iar valorile sunt cele care vor înlocui acești substituenți.
Valoare returnată:
Metoda format_map() returnează un șir nou, formatat, în care substituenții sunt înlocuiți cu valorile corespunzătoare din mapare. Nu modifică șirul original.
.format_map(mapping)
Is used for string formatting, similar to string.format(), but it specifically takes a single mapping object (like a dictionary) as its argument. This method replaces placeholders within a string with corresponding values from the provided mapping.
formats a string by substituting named placeholders with values directly from a dictionary or any mapping object.
Parameters:
string: The string with placeholders (e.g., {name}).
mapping: A mapping object (e.g., a dictionary) containing key-value pairs. The keys in this mapping correspond to the names used in the placeholders within the string, and the values are what will replace those placeholders.
Return Value:
The format_map() method returns a new, formatted string with the placeholders replaced by their corresponding values from the mapping. It does not modify the original string. 
date_persoană = {"nume": "Aneta", "vârstă": 30}
șir_formatat = "Nume: {nume}, Vârsta {vârstă}".format_map(date_persoană)
print(șir_formatat)   ==> Nume: Aneta, Vârsta 30
Diferența cheie față de şir.format():
Deși şir.format() poate accepta și argumente de tip cuvânt cheie care sunt despachetate dintr-un dicționar folosind operatorul ** (de exemplu, şir.format(**dicționarul_meu)), şir.format_map() preia direct obiectul de mapare. Acest lucru poate fi util în special atunci când se lucrează cu subclase de dicționar personalizate care ar putea avea un comportament special, cum ar fi gestionarea cheilor lipsă printr-o metodă __missing__.
Key Difference from string.format():
While str.format() can also accept keyword arguments that are unpacked from a dictionary using the ** operator (e.g., string.format(**my_dict)), str.format_map() directly takes the mapping object. This can be particularly useful when working with custom dictionary subclasses that might have special behavior, such as handling missing keys through a __missing__ method.
şir.format(**mapping)
Evită crearea unui dicționar temporar: Când utilizați **mapping, Python despachetează mai întâi perechile cheie-valoare într-un dicționar nou înainte de a-l transmite metodei format(). format_map() utilizează direct obiectul de mapare, ceea ce poate fi puțin mai eficient pentru dicționarele foarte mari.
Acceptă clase speciale de mapare: format_map() funcționează direct cu tipuri de mapare personalizate, cum ar fi subclasele dict care implementează un comportament special. Un caz de utilizare comun este gestionarea cheilor lipsă fără a genera o eroare KeyError prin definirea unei metode __missing__().
str.format(**mapping)
Avoids creating a temporary dictionary: When you use **mapping, Python first unpacks the key-value pairs into a new dictionary before passing it to the format() method. format_map() uses the mapping object directly, which can be slightly more efficient for very large dictionaries.
Supports special mapping classes: format_map() works directly with custom mapping types, like dict subclasses that implement special behavior. A common use case is handling missing keys without raising a KeyError by defining a __missing__() method.
# formatare de bază
persoană = {"nume": "Ion", "vârstă": 77}
salut = "Bună ziua, numele meu este {nume} și am {vârstă} ani."
șir_formatat = salut.format_map(persoană)

# formatare cu o clasă de mapare personalizată
# cazurile în care o cheie substituentă lipsește din date.
class PersonalizareDict(dict):
    def __missing__(self, cheie):
        return f"Lipsă - {cheie}"
    
obiect_electronic = PersonalizareDict({"produs": "prăjitor de pâine"})
detalii_comandă = "Comandă: {produs}, Preț: {preț}."

# Cheia "preț" lipsește din obiect_electronic, dar nu este generată nicio eroare KeyError.
șir_formatat2 = detalii_comandă.format_map(obiect_electronic)
print(șir_formatat2)  ==> Comandă: prăjitor de pâine, Preț: Lipsă - preț.

# chei imbricate
# format_map() poate gestiona și chei imbricate prin referirea lor în interiorul acoladelor.
programator = {"detalii": {"nume": "Florescu", "vârstă": 55}}
șir_informații = "Nume: {detalii[nume]}, Vârsta: {detalii[vârstă]}."

șir_formatat3 = șir_informații.format_map(programator)
print(șir_formatat3)  ==> Nume: Florescu, Vârsta: 55.

Python's F-String for String Interpolation and Formatting

f-strings
Introduse în Python 3.6 literalii de șiruri formate, sau șiruri f, oferă o modalitate concisă și ușor de citit de a încorpora expresii în interiorul literalilor de șir în Python. Aceștia sunt identificați printr-un prefix f sau F înainte de ghilimelele de deschidere ale șirului.
O metodă modernă și ușor de citit care utilizează prefixul f. Expresiile din interiorul acoladelor ({}) sunt evaluate la momentul execuției.
În Python, nu poți concatena direct un șir de caractere și un număr folosind operatorul +, deoarece acest lucru va genera o eroare TypeError. Mai întâi trebuie să convertiți explicit numărul într-un șir de caractere folosind o metodă precum str(), f-strings sau metoda .format().
Pentru potriviri de modele mai avansate și căutări fără sensibilitate la majuscule/minuscule, modulul "re" din Python oferă capabilități puternice de expresii regulate.
f-strings
Formatted string literals, or f-strings, introduced in Python 3.6 provide a concise and readable way to embed expressions inside string literals in Python. They are identified by an f or F prefix before the opening quotation mark of the string.
A modern and highly readable method using a f prefix. Expressions inside curly braces ({}) are evaluated at runtime.
In Python, you cannot directly concatenate a string and a number using the + operator, as this will raise a TypeError. You must first explicitly convert the number to a string using a method like str(), f-strings, or the .format() method.
or more advanced pattern matching and case-insensitive searches, Python's "re" module provides powerful regular expression capabilities.

format() function

Funcția format()
Funcția format() încorporată în Python oferă o modalitate versatilă de a formata valorile în reprezentări de tip șir de caractere. Aceasta primește două argumente principale: valoare și un format_spec opțional.
format() function
The built-in format() function in Python provides a versatile way to format values into string representations. It takes two main arguments: value and an optional format_spec.

Formatare de bază - Basic Formatting

# Conversia unui număr întreg în reprezentarea sa binară
valoare_binară = format(10, 'b')
print(f"Binar: {valoare_binară} / {type(valoare_binară)}")  ==> Binar: 1010 / <class 'str'>

# Conversia unui număr la două zecimale
valoare_fixă1 = format(3.14159, '.2f')
valoare_fixă2 = format(25, '.2f')
print(f"Doua zecimale: {valoare_fixă1} / {type(valoare_fixă1)}")  ==> Doua zecimale: 3.14 / <class 'str'>
print(f"Doua zecimale: {valoare_fixă2} / {type(valoare_fixă2)}")  ==> Doua zecimale: 25.00 / <class 'str'>

Formatarea numerelor cu separatori - Number Formatting with Separators

# Adăugați o virgulă ca separator de mii
virgulă_separate = format(1234567, ',d')   
print(f"Mii separate: {virgulă_separate}") ==> Mii separate: 1,234,567

# Folosiți o subliniere ca separator de mii
sub_separat = format(9876543, '_d')
print(f"Suliniere separată: {sub_separat}") ==> Suliniere separată: 9_876_543

Aliniere și umplere - Alignment and Padding

# Aliniere la dreapta a unui șir cu o lățime de 10 caractere

Explicația format_spec:
Șirul format_spec (de exemplu, 'b', '.2f', ',d', '>10') oferă instrucțiuni detaliate despre cum se formatează valoarea. Acesta poate include:
Aliniere: <, >, ^ (stânga, dreapta, centru)
Semn: +, -, ` ` (plus, minus, spațiu)
Umplere: Un caracter de utilizat pentru umplere (de exemplu, *)
Lățime: Lățimea minimă a câmpului
Precizie: Pentru numerele cu virgulă mobilă, numărul de zecimale (de exemplu, .2f)
Tip: Tipul de conversie (de exemplu, d pentru zecimal, b pentru binar, f pentru virgulă fixă, c pentru caracter)
Combinând acești specificatori, puteți obține o gamă largă de rezultate de formatare cu funcția format().
Explanation of format_spec:
The format_spec string (e.g., 'b', '.2f', ',d', '>10') provides detailed instructions on how to format the value. It can include:
Alignment: <, >, ^ (left, right, center)
Sign: +, -, ` ` (plus, minus, space)
Padding: A character to use for padding (e.g., *)
Width: The minimum field width
Precision: For floating-point numbers, the number of decimal places (e.g., .2f)
Type: The type of conversion (e.g., d for decimal, b for binary, f for fixed-point, c for character)
By combining these specifiers, you can achieve a wide range of formatting results with the format() function.
Utilizarea format() cu clase personalizate.
Pentru o clasă personalizată, puteți implementa o metodă __format__ pentru a defini comportamentul acesteia în formatare.
Using format() with custom classes.
For a custom class, you can implement a __format__ method to define its formatting behavior.
import datetime

class AnulLunaZiua:
    def __init__(self, anul, luna, ziua):
        self.data = datetime.date(anul, luna, ziua)

    def __format__(self, format_spec):
        return self.data.strftime(format_spec)

azi = AnulLunaZiua(2026, 06, 30)
data_formatata = format(azi, '%B %d, %Y')
print(data_formatata)  ==> June 30, 2026
Când se utilizează format()
Deși metoda şir.format() și șirurile f sunt în general mai comune pentru formatarea de bază a șirurilor, funcția format() încorporată este utilă în următoarele situații:
Crearea unei clase personalizate: Puteți defini metoda __format__ pentru formatarea personalizată, care va fi utilizată automat atât de format(), cât și de șirurile f.
Specificatori de format dinamici: format_spec poate fi o variabilă, care vă permite să setați dinamic formatarea la momentul execuției.
Formatare specializată: Când trebuie să aplicați un format unei singure valori fără a o încorpora într-un șablon de șir mai mare.
When to use format()
While the str.format() method and f-strings are generally more common for basic string formatting, the built-in format() function is useful in these situations:
Creating a custom class: You can define the __format__ method for custom formatting, which will be used automatically by both format() and f-strings.
Dynamic format specifiers: The format_spec can be a variable, which allows you to dynamically set the formatting at runtime.
Specialized formatting: When you need to apply a format to a single value without embedding it into a larger string template.

Format Specification Mini-Language

Puteți transmite parametri personalizați în spații substituibile după două puncte (:) pentru a controla strict umplerea, alinierea și tipurile. Aceste reguli se aplică atât funcției str.format(), cât și funcției independente format().

Format Code Behavior Example Result
.Nf Formats floats to N decimal places format(3.14159, ".2f") '3.14'
, Adds commas as thousands separators format(1000000, ",") '1,000,000'
% Multiplies by 100 and appends percentage sign format(0.25, "%") '25.000000%'
b / x Converts numbers to Binary or Hexadecimal format(10, "b") '1010'
^N Centers value within N character spaces "{}".format("Hi").center(6) or "{:^6}".format("Hi") ' Hi '
>N Right-aligns text within N spaces format("Test", ">8") ' Test'
