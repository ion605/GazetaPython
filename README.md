## 🇬🇧 English: Git & GitHub Learning Resource

Welcome to the official repository for **[Gazeta Python](https://gazetapython.com)**. 

This project serves a dual purpose:
1. It hosts a completely free, fast, and lightweight index of Python tutorials (Built-in Types, Data Structures, Binary Types, and more).
2. It acts as a real-world, live example to help you learn **Git, GitHub, and modern web deployment**.

### 🛠️ The Tech Stack
Instead of using heavy, traditional content management systems like WordPress, this entire platform is built using standard, efficient engineering workflows:
* **HTML & CSS:** Clean, static web pages with no database lag.
* **Git & GitHub:** Version control to track code changes and host the remote repository.
* **Netlify:** Continuous deployment that instantly updates the live site whenever changes are pushed to GitHub.

### 🎓 Learning Git Through This Project
If you are new to programming, understanding version control is just as important as learning Python:
* **`git status`** - Checks which HTML files have been modified or newly created.
* **`git add <file_name>`** - Stages your updated files, preparing them to be saved.
* **`git commit -m "Message"`** - Creates a permanent save point in your project's history.
* **`git push origin main`** - Sends your committed changes straight to this GitHub repository, triggering an automatic live update via Netlify.

## 🇷🇴 Română: Resursă de Învățare Git și GitHub

Bun venit în depozitul (repository) oficial pentru **[Gazeta Python](https://gazetapython.com)**. 

Acest proiect are un scop dublu:
1. Găzduiește un index complet gratuit, rapid și simplu de tutoriale Python (Tipuri încorporate, Structuri de date, Tipuri binare și multe altele).
2. Funcționează ca un exemplu real și live pentru a vă ajuta să învățați **Git, GitHub și tehnologii moderne de publicare web**.

### 🛠️ Tehnologia din spatele proiectului
În loc să folosim sisteme tradiționale și îngreunate de gestionare a conținutului (cum ar fi WordPress), întreaga platformă este construită folosind fluxuri de lucru standard din ingineria software:
* **HTML & CSS:** Pagini web statice, curate, fără întârzieri cauzate de baze de date.
* **Git & GitHub:** Controlul versiunilor pentru a urmări istoricul și găzduirea depozitului de cod.
* **Netlify:** Publicare continuă (continuous deployment) care actualizează instantaneu site-ul live de fiecare dată când codul este trimis pe GitHub.

### 🎓 Cum să înveți Git prin intermediul acestui proiect
Dacă sunteți la început de drum în programare, înțelegerea controlului versiunilor este la fel de importantă ca învățarea limbajului Python:
* **`git status`** - Verifică ce fișiere HTML au fost modificate sau nou create.
* **`git add <nume_fișier>`** - Pregătește modificările (staging) pentru a fi salvate.
* **`git commit -m "Mesaj"`** - Creează un punct de salvare permanent în istoricul proiectului.
* **`git push origin main`** - Trimite modificările direct pe GitHub, declanșând actualizarea automată pe Netlify în doar câteva secunde.
