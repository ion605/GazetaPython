Includerea caracterelor între ghilimele simple, duble sau triple - Enclosing characters in single, double, or triple quotes

Puteți crea un șir de caractere în Python prin includerea caracterelor între ghilimele simple, duble sau triple.

You can create a string in Python by enclosing characters in single, double, or triple quotes.

# Ghilimele simple
şir_simplu = 'Salut, lume!'
print(şir_simplu)

# Ghilimele duble
şir_dublu = "Salut, lume!"
print(şir_dublu)

# Folosește ghilimele duble pentru șiruri de caractere care conțin ghilimele simple în interior
print("E o zi 'frumoasă'")

# Ghilimele duble triple pentru șiruri de caractere pe linii multiple
şir_duble_triple = """
Acesta este un
șir de caractere dispus pe mai multe
rânduri folosind ghilimele duble triple."""
print(şir_duble_triple)

# Ghilimele simple triple pentru șiruri de caractere pe linii multiple
şir_simple_triple = '''
Acesta este un
șir de caractere pe mai multe linii
folosind ghilimele simple triple.'''
print(şir_simple_triple)
Caracteristici cheie ale șirurilor de caractere
Imuabil: Odată ce un șir de caractere este creat, acesta nu poate fi modificat. Orice operațiune care pare să modifice un șir de caractere, cum ar fi înlocuirea unui caracter, creează și returnează de fapt un șir complet nou.
Secvență: Caracterele dintr-un șir sunt stocate într-o secvență specifică, ordonată. Acest lucru vă permite să accesați caracterele individuale după poziția lor (index).
Iterabil: Deoarece șirurile de caractere sunt secvențe, puteți itera peste caracterele lor folosind diferite metode.
Unicode: Șirurile de caractere Python gestionează caractere Unicode, care acceptă text din toate limbile lumii, precum și emoji-uri.
Key characteristics of strings
Immutable: Once a string is created, it cannot be changed. Any operation that appears to modify a string, like replacing a character, actually creates and returns a completely new string.
Sequence: Characters in a string are stored in a specific, ordered sequence. This allows you to access individual characters by their position (index).
Iterable: Since strings are sequences, you can iterate over their characters using different methods.
Unicode: Python strings handle Unicode characters, which support text from all the world's languages as well as emojis.

Constructor str() - str() Constructor

Puteți converti alte tipuri de date în șiruri de caractere folosind funcția str() încorporată.

You can convert other data types into strings using the built-in str() function.

număr = 123
număr_ca_șir = str(123)   
print(număr_ca_șir)       ==> 123
print(type(număr_ca_șir)) ==> <class 'str'>

listă = [1, 2, 3]
șir_listă = str(listă)
Puncte cheie:
Consistență: Deși atât ghilimelele simple, cât și cele duble sunt valide, este o practică bună să mențineți consecvența în codul dvs.
Caractere de evadare: Dacă trebuie să includeți un caracter ghilimea care se potrivește cu tipul de ghilimea utilizată pentru a defini șirul (de exemplu, o ghilimea dublă într-un șir între ghilimele duble), puteți utiliza o bară oblică inversată (\) pentru a-l evada.
Imutabilitate: Șirurile Python sunt imuabile, ceea ce înseamnă că odată create, conținutul lor nu poate fi modificat direct. Orice operațiune care pare să modifice un șir creează de fapt un șir nou.
Key Points:
Consistency: While both single and double quotes are valid, it's good practice to maintain consistency within your code.
Escaping Characters: If you need to include a quote character that matches the quote type used to define the string (e.g., a double quote within a double-quoted string), you can use a backslash (\) to escape it.
Immutability: Python strings are immutable, meaning once created, their content cannot be changed directly. Any operation that appears to modify a string actually creates a new string.

Metoda str() - str() Method

Metoda __str__ din Python este o metodă specială de tip "dunder" (subliniere dublă) care definește modul în care un obiect al unei clase ar trebui reprezentat ca un șir de caractere atunci când este convertit pentru a fi lizibil de către om.

The __str__ method in Python is a special "dunder" (double underscore) method that defines how an object of a class should be represented as a string when converted for human readability.

Scop:
Reprezentare lizibilă de către om: Scopul său principal este de a oferi o reprezentare ușor de utilizat a unui obiect sub formă de șir de caractere, potrivită pentru afișare către utilizatori, înregistrare în jurnal sau imprimare.
Apelată de print() și str(): Când utilizați funcția print() cu un obiect sau apelați explicit str(object), Python invocă automat metoda __str__ a obiectului (dacă este definită).
Implementare:
Metoda __str__ primește un argument, self, care se referă la instanța clasei.
Trebuie să returneze un șir de caractere.
Purpose:
Human-readable representation: Its primary goal is to provide a user-friendly string representation of an object, suitable for displaying to users, logging, or printing.
Called by print() and str(): When you use the print() function with an object, or explicitly call str(object), Python automatically invokes the object's __str__ method (if defined).
Implementation:
The __str__ method takes one argument, self, which refers to the instance of the class.
It must return a string.
class Carte:
    def __init__(self, titlul, autorul, anul):
        self.titlul = titlul
        self.autorul = autorul
        self.anul = anul

    def __str__(self):
        return f"'{self.titlul}' de {self.autorul} ({self.anul})"

cartea = Carte("Baltagul", "Mihail Sadoveanu", 1930)

print(cartea)      ==> 'Baltagul' de Mihail Sadoveanu (1930)
print(str(cartea)) ==> 'Baltagul' de Mihail Sadoveanu (1930)
Comparație cu __repr__:
În timp ce __str__ se concentrează pe ieșiri lizibile de către om, metoda __repr__ își propune să ofere o reprezentare oficială a unui șir de caractere care ar putea fi utilizată în mod ideal pentru a recrea obiectul. Dacă __str__ nu este definită într-o clasă, __repr__ va fi utilizată ca alternativă atunci când se apelează print() sau str().
Comparison with __repr__:
While __str__ focuses on human-readable output, the __repr__ method aims to provide an official string representation that could ideally be used to recreate the object. If __str__ is not defined in a class, __repr__ will be used as a fallback when print() or str() is called.

Metoda repr() - repr() Method

Funcția încorporată repr() din Python returnează o reprezentare "prietenoasă pentru dezvoltatori" sau "oficială" a unui obiect sub formă de șir de caractere. Această reprezentare este concepută să fie lipsită de ambiguitate și, în mod ideal, ar putea fi utilizată pentru a recrea obiectul folosind funcția eval(), dacă este posibil.

The repr() built-in function in Python returns a "developer-friendly" or "official" string representation of an object. This representation is intended to be unambiguous and, ideally, could be used to recreate the object using the eval() function if possible.

Caracteristici cheie ale repr():
Reprezentare lipsită de ambiguitate: Scopul său este de a oferi o reprezentare clară și precisă a stării unui obiect, inclusiv tipul și valorile sale.
Corectare și înregistrare în jurnal: repr() este deosebit de utilă pentru corectare și înregistrare în jurnal, deoarece oferă o vedere detaliată a structurii interne a unui obiect.
Recreere de obiecte (unde este posibil): Pentru multe tipuri încorporate și clase personalizate bine concepute, șirul de caractere returnat de repr() poate fi transmis către eval() pentru a reconstrui un obiect echivalent.
În contrast cu str(): În timp ce str() oferă o reprezentare lizibilă de către om, repr() se concentrează pe o reprezentare precisă din punct de vedere tehnic și adesea mai detaliată pentru dezvoltatori.
Implementarea metodei __repr__ în clasele personalizate:
Pentru a defini comportamentul repr() pentru propriile clase, trebuie să implementați metoda specială __repr__ în cadrul clasei. Această metodă ar trebui să returneze un șir de caractere care reprezintă obiectul.
Key Characteristics of repr():
Unambiguous Representation: It aims to provide a clear and precise representation of an object's state, including its type and values.
Debugging and Logging: repr() is particularly useful for debugging and logging, as it offers a detailed view of an object's internal structure.
Object Recreation (where possible): For many built-in types and well-designed custom classes, the string returned by repr() can be passed to eval() to reconstruct an equivalent object.
Contrast with str(): While str() provides a human-readable representation, repr() focuses on a technically accurate and often more verbose representation for developers.
Implementing __repr__ in Custom Classes:
To define the repr() behavior for your own classes, you need to implement the __repr__ special method within the class. This method should return a string that represents the object.
class Punct:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __repr__(self):
        return f"Punctul cardinal(x={self.x}, y={self.y})"

p = Punct("LONGITUDINE", "LATITUDINE")
print(repr(p)) ==> Punctul cardinal(x=LONGITUDINE, y=LATITUDINE)

În exemplul de mai sus, repr(p) returnează un șir de caractere care indică în mod clar tipul obiectului și valorile atributelor sale și ar putea fi teoretic utilizat pentru a recrea un obiect Point cu aceleași coordonate.

In the example above, repr(p) returns a string that clearly indicates the object's type and its attribute values, and could theoretically be used to recreate a Point object with the same coordinates.

Cum funcționează
Când apelați repr(obj), Python caută o metodă specială în clasa obiectului numită __repr__().
Dacă __repr__() este definită, atunci este apelată pentru a obține reprezentarea sub formă de șir de caractere.
Dacă __repr__() nu este definită, Python revine la o reprezentare implicită, care de obicei arată tipul obiectului, adresa de memorie și numele clasei.
Pentru o clasă personalizată, este considerată cea mai bună practică să definiți întotdeauna o metodă __repr__() pentru a oferi informații utile de intreținere.
How it works
When you call repr(obj), Python looks for a special method on the object's class called __repr__().
If __repr__() is defined, it is called to get the string representation.
If __repr__() is not defined, Python falls back to a default representation, which typically shows the object's type, memory address, and class name.
For a custom class, it's considered best practice to always define a __repr__() method to provide useful debugging information

Luați în considerare o clasă personalizată Pasăre cu ambele metode __repr__() și __str__().
Consider a custom Pasăre class with both __repr__() and __str__() methods. 

class Pasăre:
    def __init__(self, nume, vârstă):
        self.nume = nume
        self.vârstă = vârstă

    def __repr__(self):
        # Rezultat axat pe dezvoltator care poate recrea obiectul
        return f"Papagal('{self.nume}', {self.vârstă})"

    def __str__(self):
        # Rezultat axat pe utilizator
        return f"{self.nume} are vârsta de {self.vârstă} ani"

# Create an instance of the class
papagal = Pasăre("Zeli", 5)

# Apelează direct repr()
print(f"{repr(papagal)} - apelat cu 'repr'") ==> Papagal('Zeli', 5) - apelat cu 'repr'

# Apelează direct str()
print(f"{str(papagal)} - apelat cu 'str'")   ==> Zeli are vârsta de 5 ani - apelat cu 'str'

# Folosește print(), care apelează implicit str()
print(f"{papagal} - apelat fără 'repr' sau 'str'") ==> Zeli are vârsta de 5 ani - apelat fără 'repr' sau 'str'
repr() vs. str()
repr(): Rezultatul este destinat dezvoltatorilor. Ar trebui să fie lipsit de ambiguitate și detaliat pentru depanare și înregistrare în jurnal.
str(): Rezultatul este destinat utilizatorilor finali. Ar trebui să fie ușor de citit și concis.
repr() vs. str()
repr(): The output is for developers. It should be unambiguous and detailed for debugging and logging.
str(): The output is for end-users. It should be human-readable and concise.
Ce se întâmplă dacă __str__() nu este definit?
Dacă o clasă definește doar __repr__(), atunci str() va folosi în continuare ieșirea __repr__(). Acest lucru face ca definirea __repr__() să fie un prim pas bun pentru orice clasă personalizată, deoarece asigură o reprezentare utilă atât în contexte de dezvoltare, cât și în contexte orientate către utilizator.
What happens if __str__() is not defined?
If a class only defines __repr__(), then str() will fall back to using the __repr__() output. This makes defining __repr__() a good first step for any custom class, as it ensures you get a useful representation in both development and user-facing contexts.
class Pasăre:
    def __init__(self, nume, vârstă):
        self.nume = nume
        self.vârstă = vârstă

    def __repr__(self):
        # Doar __repr__ este definit
        return f"Papagal('{self.nume}', {self.vârstă})"


# Creați o instanță a clasei
papagal = Pasăre("Zeli", 5)

# Ambele apeluri folosesc acum ieșirea __repr__
print(f"{papagal} - apelat fără 'repr' sau 'str'") ==> Papagal('Zeli', 5) - apelat fără 'repr' sau 'str'
print(f"{str(papagal)} - apelat cu 'str'")         ==> Papagal('Zeli', 5) - apelat cu 'str'

str() și repr() funcții încorporate - str() and repr() built-in functions

str() și repr() sunt funcții încorporate utilizate pentru a obține reprezentări sub formă de șiruri ale obiectelor, dar servesc scopuri diferite și vizează diferite grupuri de oameni.

str() and repr() are built-in functions used to obtain string representations of objects, but they serve different purposes and target different audiences.

Funcția str():
Scop: str() este concepută pentru a returna o reprezentare sub formă de șir de caractere "lizibilă de om" sau "imprimabilă cu ușurință" a unui obiect. Această reprezentare este destinată utilizatorilor finali sau afișajului, cum ar fi la imprimarea unui obiect sau la convertirea acestuia într-un șir de caractere pentru ieșire.
Metoda de bază: Când este apelată metoda str(obj), Python apelează intern metoda specială __str__() a obiectului obj.
str() Function:
Purpose: str() is designed to return a "human-readable" or "nicely printable" string representation of an object. This representation is intended for end-users or for display purposes, such as when printing an object or converting it to a string for output.
Underlying Method: When str(obj) is called, Python internally calls the __str__() special method of the object obj.
class ClasăStrig:
    def __init__(self, valoare):
        self.valoare = valoare

    def __str__(self):
        return f"Un obiect StrigClass cu valoare: {self.valoare}"

obct = ClasăStrig(10)
print(str(obct))      ==> Un obiect StrigClass cu valoare: 10
Funcția repr():
Scop: repr() este concepută pentru a returna o reprezentare "oficială" sau "neambiguă" sub formă de șir de caractere a unui obiect, destinată în principal dezvoltatorilor și depanării (corectării, remedierii). În mod ideal, șirul de caractere returnat de repr() ar trebui să fie o expresie Python validă care ar putea fi utilizată pentru a recrea obiectul.
Metodă de bază: Când este apelată repr(obj), Python apelează intern metoda specială __repr__() a obiectului obj.
repr() Function:
Purpose: repr() is designed to return an "official" or "unambiguous" string representation of an object, primarily intended for developers and debugging. Ideally, the string returned by repr() should be a valid Python expression that could be used to recreate the object.
Underlying Method: When repr(obj) is called, Python internally calls the __repr__() special method of the object obj.
class ClasăRepr:
    def __init__(self, valoare):
        self.valoare = valoare

    def __repr__(self):
        return f"ClasăRepr(valoare={self.valoare})"

obct = ClasăRepr(10)
print(repr(obct))    ==> ClasăRepr(valoare=10)
Diferențele rezumat:
Public: str() este pentru utilizatorii finali; repr() este pentru dezvoltatori.
Scop: str() vizează lizibilitatea; repr() vizează reprezentarea lipsită de ambiguitate, adesea reconstruibilă.
Metode subiacente: str() apelează __str__(); repr() apelează __repr__().
Comportament implicit: Dacă __str__() nu este definit pentru o clasă, str() va apela alternativ __repr__().
Când se utilizează fiecare dintre methode:
Folosește str() atunci când trebuie să afișezi un obiect într-un format ușor de utilizat (de exemplu, în jurnale, instrucțiuni de imprimare, elemente UI).
Folosește repr() atunci când ai nevoie de o reprezentare detaliată și lipsită de ambiguitate a unui obiect pentru depanare, inspecție sau pentru a recrea obiectul programatic.
Differences Summarized:
Audience: str() is for end-users; repr() is for developers.
Goal: str() aims for readability; repr() aims for unambiguous representation, often reconstructible.
Underlying Methods: str() calls __str__(); repr() calls __repr__().
Default Behavior: If __str__() is not defined for a class, str() will fall back to calling __repr__().
When to use which:
Use str() when you need to display an object in a user-friendly format (e.g., in logs, print statements, UI elements).
Use repr() when you need a detailed, unambiguous representation of an object for debugging, inspection, or to recreate the object programmatically.

Să creăm o clasă personalizată care implementează atât __str__(), cât și __repr__().
Let's create a custom class that implements both __str__() and __repr__().

class Angajat:
    def __init__(self, nume, funcția):
        self.nume = nume
        self.funcția = funcția

    def __str__(self):
        # Un format lizibil de către utilizatorul final
        return f"Eu sunt {self.nume} şi am {self.funcția} de programator."

    def __repr__(self):
        # Un format lipsit de ambiguitate pentru dezvoltatori
        return f"Angajat('{self.nume}', {self.funcția})"

# Creați o instanță a clasei
ion = Angajat("Ion Barb", "poziția")

Funcția str() și funcția print(), care apelează str(), vor utiliza șirul de caractere lizibil de către om.
The str() function and the print() function, which calls str(), will use the human-readable string.

# Folosind print()
print(ion)         ==> Eu sunt Ion Barb şi am poziția programator.

# Folosind str()   
print(str(ion))    ==> Eu sunt Ion Barb şi am poziția programator.

funcția repr() (dacă tastați numele variabilei) vor utiliza șirul de caractere ușor de utilizat pentru dezvoltatori.
repr() function (if you type the variable name) will use the developer-friendly string.

# Folosind repr()
repr(ion)         ==> "Angajat('Ion Barb', poziția)"
Când se utilizează fiecare:
Folosește str() sau print() pentru ieșiri orientate către utilizator, cum ar fi înregistrarea în jurnal, afișarea mesajelor într-o interfață cu utilizatorul sau scrierea într-un raport.
Folosește repr() pentru depanare, dezvoltare și înregistrare în jurnal, unde ai nevoie de o reprezentare completă și lipsită de ambiguitate a stării unui obiect.
Recomandare: Implementează întotdeauna __repr__() pentru clasele tale personalizate, deoarece oferă o reprezentare implicită utilă pentru depanare. Implementează __str__() numai dacă ai nevoie de o ieșire separată, mai ușor de utilizat, pentru obiectul respectiv.
When to use each:
Use str() or print() for user-facing output, such as logging, displaying messages in a user interface, or writing to a report.
Use repr() for debugging, development, and logging, where you need a complete and unambiguous representation of an object's state.
Recommendation: Always implement __repr__() for your custom classes, as it provides a useful default representation for debugging. Implement __str__() only if you need a separate, more user-friendly output for that object.

Secvențe de evadare în șirurile literale - Escape sequences in string literals

Secvențele escape sunt combinații speciale de caractere utilizate în șirurile de caractere literale pentru a reprezenta caractere dificil sau imposibil de tastat direct, cum ar fi linii noi, tabulatori sau ghilimele. Acestea sunt inițiate de o bară oblică inversată (\) urmată de unul sau mai multe caractere.

Escape sequences are special character combinations used within string literals to represent characters that are difficult or impossible to type directly, such as newlines, tabs, or quotes. They are initiated by a backslash (\) followed by one or more characters.

\n: Reprezintă un caracter de linie nouă (se mută la o linie nouă).
\n: Represents a newline character (moves to a new line).

print("Prima linie\nA doua linie")

==> Prima linie
    A doua linie

\t: Reprezintă un caracter de tabulare, inserând un spațiu orizontal.
\t: Represents a tab character, inserting horizontal space.

print("Nume:\tIon Barb") ==> Nume:	Ion Barb

\': Reprezintă o apostră simplă într-un șir de caractere între gilimele simple.
\': Represents a single quote within a single-quoted string.

print('\'neața! dom\'le') ==> 'neața! dom'le

\": Reprezintă o ghilimea dublă într-un șir de caractere între ghilimele duble.
\": Represents a double quote within a double-quoted string.

print("Mi-a spus, \"mâine să vii la întâlnire\".") ==> Mi-a spus, "mâine să vii la întâlnire".

\\: Reprezintă un caracter oblic inversat literal.
\\: Represents a literal backslash character.

print("C:\\Users\\Username") ==> C:\Users\Username

\b: Represents a backspace character (șterge caracterul precedent).
  
\r: Represents a carriage return character (mută cursorul la începutul liniei).

\f: Represents a form feed character (utilizarea sa directă pentru controlul imprimantei este mai puțin frecventă în mediul informatic modern).

\N{<name>}: Character from Unicode database with given <name>

\v: ASCII Vertical tab (VT) character

\uxxxx: Unicode character with 16-bit hex value xxxx

\Uxxxxxxxx: Unicode character with 32-bit hex value xxxxxxxx
    
\xdd: Represents a character by its hexadecimal value dd.

print("\x41")           ==> A
print("\N{snake}")      ==> 🐍
print(len("\N{snake}")) ==> 1
print(len("🐍"))        ==> 1
print("\N{duck}")       ==> 🦆
print("\N{pig}")        ==> 🐖
Șiruri brute:
Pentru a împiedica Python să interpreteze secvențele de escape dintr-un șir, puteți utiliza un "șir brut" prin prefixarea literalului șirului cu un r sau R. În șirurile brute, barele oblice inversate sunt tratate ca și caractere literale, cu excepția cazului în care acestea escape un caracter de ghilimele care ar termina șirul.
Raw Strings:
To prevent Python from interpreting escape sequences within a string, you can use a "raw string" by prefixing the string literal with an r or R. In raw strings, backslashes are treated as literal characters, except when they escape a quote character that would terminate the string.
cale = r"C:\Utilizatori\Documente\fișier.txt" ==> C:\Utilizatori\Documente\fișier.txt
print(cale)

Nu interpretează \U, \D, or \f ca secvenţe escape
