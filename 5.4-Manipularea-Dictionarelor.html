Eliminare element/e dintr-un dicționar - Remove item/s from a dictionary

Cele mai comune metode de a elimina elemente dintr-un dicționar Python depind de faptul dacă dorești să gestionezi în siguranță cheile inexistente, să recuperezi valoarea eliminată sau să golești întregul dicționar.

The most common ways to remove items from a Python dictionary depend on whether you want to safely handle missing keys, retrieve the removed value, or clear the entire dictionary.

Rezumat al celor mai bune metode
Metodă Sintaxă Returnează o valoare? Gestionează în siguranță cheile lipsă?
dict.pop() my_dict.pop(key, default) Da Da (dacă este furnizat un argument implicit)
Cuvântul-cheie del del my_dict[key] Nu Nu (generează KeyError)

Folosește pop() (recomandat și cel mai sigur) - Use pop() (Recommended & Safest)

clear(): Această metodă elimină toate elementele dintr-un dicționar, rezultând un dicționar gol. Nu acceptă niciun argument și returnează None.

clear(): This method removes all items from a dictionary, resulting in an empty dictionary. It does not take any arguments and returns None.

nume = {"Cristina": 40, "Andrei": 50, "Mihai": 75, "Vasile": 67, "Alexandru": 39, "Elena": 41, "Ioana": 19}

print(nume) ==> {}

pop(key, default_value): Această metodă elimină elementul cu cheia specificată și returnează valoarea corespunzătoare. Dacă cheia nu este găsită, generează o eroare KeyError, cu excepția cazului în care este furnizată o valoare implicită, caz în care returnează valoarea implicită.

pop(key, default_value): This method removes the item with the specified key and returns its corresponding value. If the key is not found, it raises a KeyError unless a default_value is provided, in which case it returns the default_value.

Acest lucru previne eroarea RuntimeError.

Important Note: If the intention is to remove key-value pairs, or if there's a risk of changing the dictionary's size during iteration, it is crucial to iterate over a copy of the dictionary's keys or items, or to build a new dictionary with the desired changes. This prevents the RuntimeError.

Ambele metode pop() și del oferă modalități sigure de a elimina elemente dintr-un dicționar, pop() fiind mai concisă pentru cazurile în care ați putea dori, de asemenea, să recuperați valoarea eliminată sau să gestionați cheile lipsă cu o valoare implicită, în timp ce del cu o verificare oferă control explicit asupra procesului de ștergere.

Both methods pop() and del provide safe ways to remove items from a dictionary, with pop() being more concise for cases where you might also want to retrieve the removed value or handle missing keys with a default, while del with an in check offers explicit control over the deletion process.

Diferență simetrică ^ dicționare - Symmetric difference ^ dictionaries

Diferența simetrică a cheilor de dicționar: Pentru a găsi cheile unice pentru fiecare dicționar (prezente într-unul, dar nu în celălalt), puteți utiliza operatorul ^ în vizualizările keys() ale dicționarelor.

Symmetric Difference of Dictionary Keys: To find the keys that are unique to each dictionary (present in one but not the other), you can use the ^ operator on the keys() views of the dictionaries.

dict1 = {"a": 1, "b": 2, "c": 3}
dict2 = {"c": 4, "d": 5, "e": 6}

# Diferența simetrică a cheilor
chei_unice = dict1.keys() ^ dict2.keys()
print(chei_unice) ==> {'a', 'e', 'd', 'b'}

# reconstruiește un nou dicționar care conține aceste chei unice
dict_nou = {k: (dict1.get(k) if k in dict1 else dict2.get(k)) for k in chei_unice}
print(dict_nou) ==> {'a': 1, 'e': 6, 'd': 5, 'b': 2}

Diferența simetrică a elementelor de dicționar: Pentru a găsi perechile cheie-valoare unice pentru fiecare dicționar (unde atât cheia, cât și valoarea nu sunt prezente în celălalt dicționar), puteți utiliza operatorul ^ în vizualizările items(). Acest lucru necesită ca atât cheile, cât și valorile să fie hashabile.

Symmetric Difference of Dictionary Items: To find the key-value pairs that are unique to each dictionary (where both the key and value are not present in the other dictionary), you can use the ^ operator on the items() views. This requires that both keys and values are hashable.

dict1 = {"a": 15, "b": 2, "a": 77, "c": 3}
dict2 = {"c": 3, "d": 5, "b": 6, "d": 44}  # "b" are valori diferite în cele două dicționare

# Diferența simetrică a elementelor
elemente_unice = dict1.items() ^ dict2.items()
print(elemente_unice) ==> {('a', 77), ('d', 44), ('b', 2), ('b', 6)}

# Conversia în dicționar
dictionar_nou = dict(elemente_unice)
print(dictionar_nou) 
==> {'a': 77, 'd': 44, 'b': 6} sau {'b': 2, 'd': 44, 'a': 77}, ordinea în set este aleatorie!

Schimbarea numelui unei chei într-un dicționar - Change a key name in a dictionary

Pentru a schimba numele unei chei într-un dicționar în Python, o abordare comună implică utilizarea funcției pop() și atribuirea valorii noii chei.

To change a key name in a dictionary in Python, a common approach involves using pop() and assigning the value to the new key.

def renumeste_cheia(dictionar, cheie_veche, cheie_noua):
    """
    Redenumește o cheie dintr-un dicționar.

    Args:
        dictionar (dict): Dicționarul de modificat.
        cheie_veche: Cheia existentă care va fi redenumită.
        cheie_noua: Numele noii chei.
    """
    if cheie_veche in dictionar:
        dictionar[cheie_noua] = dictionar.pop(cheie_veche)
    else:
        print(f"Error: Cheia veche '{cheie_veche}' nu se găsește în dicționar.")
        
lactate = {"sana": 15,"lapte": 20,"iaurt": 25}
renumeste_cheia(lactate, "lapte", "unt")
print(lactate) ==> {'sana': 15, 'iaurt': 25, 'unt': 20}

renumeste_cheia(): Funcție care primește trei argumente

dictionar: Dicționarul a cărui cheie trebuie schimbată.

cheie_veche: Numele curent al cheii.

cheie_noua: Noul nume dorit pentru cheie.

if cheie_veche in dictionar: Această linie verifică dacă cheie_veche există de fapt în dicționar. Aceasta previne o eroare KeyError dacă cheie_veche specificată nu este găsită.

dictionar.pop(cheie_veche): Această metodă elimină cheie_veche și valoarea sa corespunzătoare din dicționar și returnează acea valoare.

dictionar[cheie_noua] = ...: Valoarea returnată este apoi atribuită cheie_noua din dictionar, redenumind efectiv cheia, păstrându-i în același timp valoarea.

else: print(f"Eroare: Cheia veche '{cheie_veche}' nu se găsește în dicționar.")

Dacă cheia veche nu este găsită, se afișează un mesaj de eroare informativ.

rename_key(): Function that takes three arguments

dictionary: The dictionary whose key needs to be changed.

old_key: The current name of the key.

new_key: The desired new name for the key.

if old_key in dictionary: This line checks if the old_key actually exists in the dictionary. This prevents a KeyError if the specified old_key is not found.

dictionary.pop(old_key): This method removes the old_key and its corresponding value from the dictionary and returns that value.

dictionary[new_key] = ...: The returned value is then assigned to the new_key in the dictionary, effectively renaming the key while preserving its value.

else: print(f"Error: Old key '{old_key}' not found in the dictionary."):

If the old_key is not found, an informative error message is printed.

# valoare_implicită
def renumeste_cheia(dictionar, cheie_veche, cheie_noua, valoare_implicita=None):
    """
    Redenumește o cheie dintr-un dicționar.

    Args:
        dicţionar (dict): Dicționarul de modificat.
        cheie_veche: Cheia existentă care va fi redenumită.
        cheie_nouă: Numele noii chei.
        valoare_implicită: Valoarea de atribuit noii chei dacă chei_veche nu există.
        Implicit, valoarea este None.
    """
    if cheie_veche in dictionar:
        dictionar[cheie_noua] = dictionar.pop(cheie_veche) + " Voinea"
    else:
        # Dacă cheia veche nu există, setează noua cheie cu o valoare implicită
        dictionar.setdefault(cheie_noua, valoare_implicita)
    return dictionar
        
persoana = {"nume": "Cristina", "varsta": 50, "oras": "Severin"}
# Schimbă pronumele în nume complet
renumeste_cheia(persoana, "nume", "nume_complet")
print(persoana)
==> {'varsta': 50, 'oras': 'Severin', 'nume_complet': 'Cristina Voinea'}

# Încercare de a schimba o cheie inexistentă, adăugând una nouă cu o valoare implicită
renumeste_cheia(persoana, "locatie", "tara", "Romania")
print(persoana)
==> {'varsta': 50, 'oras': 'Severin', 'nume_complet': 'Cristina Voinea', 'tara': 'Romania'}

Metoda setdefault() din dicționarele Python nu este utilizată direct pentru a schimba numele unei chei. Scopul său este de a returna valoarea unei chei dacă aceasta există sau de a insera cheia cu o valoare implicită specificată dacă aceasta nu există și apoi de a returna acea valoare implicită.

The setdefault() method in Python dictionaries is not directly used to change a key name. Its purpose is to return the value of a key if it exists, or to insert the key with a specified default value if it does not exist, and then return that default value.

Modificarea valorilor dicționarului - Changing Dictionary Values

Modificarea dimensiunii unui dicționar (adăugarea sau eliminarea perechilor cheie-valoare) în timpul iterării directe peste acesta poate duce la o eroare RuntimeError: dictionary changed size during iteration. Cu toate acestea, modificarea valorilor asociate cheilor existente este, în general, sigură și se face frecvent.

Modifying the size of a dictionary (adding or removing key-value pairs) while iterating directly over it can lead to a RuntimeError: dictionary changed size during iteration. However, modifying the values associated with existing keys is generally safe and commonly done.

Cea mai simplă și mai frecventă metodă de a modifica o valoare este prin referirea cheii între paranteze pătrate ([]) și atribuirea unei noi valori. Dacă cheia există deja, valoarea acesteia este suprascrisă.

The easiest and most common way to change a value is by referencing its key inside square brackets ([]) and assigning a new value. If the key already exists, its value is overwritten.

# Atribuire directă (cheie unică)
fructe_cost = {"caise": 2.40, "prune": 2.12, "mere": 1.69, "pere": 1.50, "smochine": 1.70}

# Schimbați valoarea articolului "mere"
fructe_cost["mere"] = round(fructe_cost["mere"] * 1.3, 2)
print(fructe_cost) ==> {'caise': 2.4, 'prune': 2.12, 'mere': 2.2, 'pere': 1.5, 'smochine': 1.7}

# Modificați valoarile mai mici de 2
fructe_cost = {"caise": 2.40, "prune": 2.12, "mere": 1.69, "pere": 1.50, "smochine": 1.70}

# Parcurgem dicționarul și modificăm valorile < 2
for cheie, valoare in fructe_cost.items():
    if valoare < 2:
        # Puneți aici noua valoare dorită
        fructe_cost[cheie] = round(fructe_cost[cheie] * 1.5, 2) 

print(fructe_cost) ==> {'caise': 2.4, 'prune': 2.12, 'mere': 2.54, 'pere': 2.25, 'smochine': 2.55}

# Utilizarea operatorului de actualizare |= (Python 3.9+)
fructe_cost = {"caise": 2.40, "prune": 2.12, "mere": 1.69, "pere": 1.50, "smochine": 1.70}

fructe_cost |= {k: (round(fructe_cost[k] * 1.5, 2) if v < 2 else v) for k, v in fructe_cost.items()}
print(fructe_cost) ==> {'caise': 2.4, 'prune': 2.12, 'mere': 2.54, 'pere': 2.25, 'smochine': 2.55}

    # Modifică valoarea asociată cheii curente

    fructe_cost[fruct] = round(cost * 0.85, 2)
print(fructe_cost) ==> {'caise': 4.08, 'prune': 3.6, 'mere': 2.87, 'pere': 2.55, 'smochine': 2.89}

for fruct, cost in fructe_cost.items():
    if cost == fructe_cost["caise"]:

        fructe_cost[fruct] = 2.65
print(fructe_cost) ==> {'caise': 2.65, 'prune': 3.6, 'mere': 2.87, 'pere': 2.55, 'smochine': 2.89}

fructe_cost = {"caise": 2.40, "prune": 2.12, "mere": 1.69, "pere": 1.50, "smochine": 1.70}

Inversarea cheilor și valorilor într-un dicționar - Swap keys and values in a dictionary

Utilizarea înțelegerii (comprehension) dicționarului: Aceasta este adesea cea mai concisă și pitonică modalitate de a realiza schimbarea.

Using Dictionary Comprehension: This is often the most concise and Pythonic way to achieve the swap.

fructe = {"mere": 50, "pere": 30, "prune": 35, "caise": 25, "smochine": 15}
inversat_chei_valori = {valoare: cheie for cheie, valoare in fructe.items()}

print(inversat_chei_valori) ==> {50: 'mere', 30: 'pere', 35: 'prune', 25: 'caise', 15: 'smochine'}

Utilizarea unei bucle: Această metodă implică iterarea dicționarului original și construirea unuia nou cu perechile schimbate.

Using a Loop: This method involves iterating through the original dictionary and building a new one with the swapped pairs.

fructe = {"mere": 50, "pere": 30, "prune": 35, "caise": 25, "smochine": 15}
inversat_chei_valori = {}
for cheie, valoare in fructe.items():
    inversat_chei_valori[valoare] = cheie

print(inversat_chei_valori) ==> {50: 'mere', 30: 'pere', 35: 'prune', 25: 'caise', 15: 'smochine'}

Definirea unei funcții care primește un dicționar ca intrare și returnează un nou dicționar cu cheile și valorile schimbate. Acest lucru poate fi realizat eficient folosind o înțelegere a dicționarului.

Defining a function that takes a dictionary as input and returns a new dictionary with keys and values ​​swapped. This can be achieved efficiently using a dictionary comprehension.

def inversare_valori_chei(dictionar_original):
    """
    Schimbă cheile și valorile unui dicționar.

    Args:
        dicționar_original: Dicționarul ale cărui chei și valori urmează să fie interschimbate.

    Retururi:
        Un nou dicționar cu chei și valori schimbate.
    """
    dictionar_inversat  = {valoare: cheie for cheie, valoare in dictionar_original.items()}
    return dictionar_inversat

fructe = {"mere": 50, "pere": 30, "prune": 35, "caise": 25, "smochine": 15}
fructe_culoare = {"mere": "verde", "pere": "galben", "caise": "portocaliu", "prune": "indigo", "smochine": "maro"}

Sortare dicționare - Sort dictionaries

Conceptul de "sortare" a unui dicționar în Python se referă de obicei la crearea unei noi reprezentări ordonate a conținutului dicționarului, fie pe baza cheilor sale, fie a valorilor sale. Dicționarul original în sine rămâne neschimbat în structura sa internă.

Nu se recomandă utilizarea sort() direct într-un dicționar Python, deoarece dicționarele sunt în mod inerent colecții neordonate de perechi cheie-valoare în versiunile anterioare Python 3.7. Deși dicționarele din Python 3.7+ mențin ordinea de inserare, acestea nu sunt concepute pentru sortare în același mod ca listele.

The concept of "sorting" a dictionary in Python typically refers to creating a new ordered representation of the dictionary's contents, either based on its keys or its values. The original dictionary itself remains unchanged in its internal structure.

It is not recommended to use sort() directly on a Python dictionary because dictionaries are inherently unordered collections of key-value pairs in versions prior to Python 3.7. While dictionaries in Python 3.7+ maintain insertion order, they are still not designed for sorting in the same way that lists are.

Atunci când se dorește sortarea datelor din dicționar, abordarea recomandată implică următorii pași:
Recuperarea elementelor: Obținerea elementelor ca o listă de tupluri cheie-valoare folosind metoda .items().
Sortarea listei: Utilizați funcția sorted() pe această listă de tupluri. Puteți specifica criteriile de sortare (după cheie sau după valoare) folosind argumentul cheie cu o funcție lambda sau operator.itemgetter().
Construirea unui nou dicționar (opțional): Dacă este necesar un dicționar ordonat, convertiți lista de tupluri ordonate înapoi într-un dicționar folosind constructorul dict(). Aceasta va duce la un nou dicționar în care ordinea elementelor reflectă criteriile de sortare.
When sorting is desired for dictionary data, the recommended approach involves the following steps:
Retrieve items: Obtain the dictionary's items as a list of key-value tuples using the .items() method.

Filtrarea elementelor dintr-un dicționar: filter() - Filtering Items in a Dictionary: filter()

Dicționarele nu sunt direct iterabile. Trebuie să convertiți dicționarul într-un iterabil de perechi cheie-valoare, de obicei folosind dictionary.items(), care returnează un obiect de vizualizare cu tupluri (cheie, valoare).

Creați o funcție (adesea o funcție lambda pentru concizie) care primește un singur tuplu (cheie, valoare) ca intrare și returnează True dacă elementul ar trebui inclus în dicționarul filtrat și False în caz contrar.

Transmiteți funcția de filtrare și iterabilul dictionary.items() către funcția filter(). Aceasta va returna un obiect de filtrare, care este un iterator ce produce doar elementele care îndeplinesc condiția. În final, convertiți obiectul filtru înapoi într-un dicționar folosind constructorul dict().

Dictionaries are not directly iterable. You need to convert the dictionary into an iterable of key-value pairs, typically using dictionary.items(), which returns a view object of (key, value) tuples.

Create a function (often a lambda function for conciseness) that takes a single (key, value) tuple as input and returns True if the item should be included in the filtered dictionary, and False otherwise.

Pass the filtering function and the dictionary.items() iterable to the filter() function. This will return a filter object, which is an iterator yielding only the items that satisfy the condition. Finally, convert the filter object back into a dictionary using the dict() constructor.

fructe_cantitate = {"mere": 50, "pere": 30, "prune": 35, "caise": 25, "smochine": 15}

# Filtrați elementele a căror valoare este mai mare de 30

print(f"Filtrat după valoare mai mare decât 30: {filtrat_valoare}")

# Filtrați elementele în care cheia conține litera r
filtrat_litera = dict(filter(lambda tuplu: "r" in tuplu[0], fructe_cantitate.items()))
print(f"Filtrat dupa cheile care conţin litra 'r' {filtrat_litera}")

ChainMap creează o singură vizualizare actualizabilă din mai multe dicționare existente.

ChainMap creates a single, updateable view out of multiple existing dictionaries.

Creați o instanță ChainMap: Instanțiați un obiect ChainMap, transmițând dicționarele ca argumente în ordinea dorită. Ordinea contează pentru căutarea cheilor; ChainMap caută în dicționare de la stânga la dreapta.

Create a ChainMap instance: Instantiate a ChainMap object, passing the dictionaries as arguments in the desired order. The order matters for key lookup; ChainMap searches the dictionaries from left to right.

Atunci când există chei duplicate în dicționarele înlănțuite, ChainMap acordă prioritate valorii din dicționarul care apare primul în ordinea de creare a obiectului ChainMap. În exemplul de mai sus, fructe_legume['morcovi'] ar returna valoarea 3 din legume1, nu 4 din legume2.

When duplicate keys exist across the chained dictionaries, ChainMap prioritizes the value from the dictionary appearing earliest in the ChainMap's creation order. In the example above, fructe_legume['morcovi'] would return 3 from legume1, not 4 from legume2.

Modifications to the ChainMap (e.g., adding a new key or changing a value) will only affect the first dictionary in the chain. If you modify an existing key, the change will apply to the dictionary where that key was initially found.

The itertools.chain() function in Python can be used to iterate through multiple dictionaries sequentially in a single loop. This is achieved by chaining the iterables returned by the .items() method of each dictionary.

for cheie, valoare in chain(fructe.items(), legume1.items(), legume2.items()):
    print(f"Cheie -> {cheie}, Valoare: {valoare}")

  • Bucla for iterează apoi prin acest iterator combinat, permițându-vă să accesați cheia și valoarea pentru toate intrările din mai multe dicționare în secvență.
