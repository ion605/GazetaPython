bytes in Python is an immutable sequence of 8-bit unsigned integers (values ​​from 0 to 255), used to handle raw binary data.

In Python 3, the fundamental difference between str and bytes boils down to a simple concept: human-readable text versus raw data for the computer.

Here is a detailed breakdown of the two data types, structured to help you understand exactly how and when each one is used.

Ce este str (String)?
Tipul str reprezintă text abstract, conceput pentru a fi citit și înțeles de oameni.

What is str (String)?
The str type represents abstract text, designed to be read and understood by humans.
Basic unit: A sequence of Unicode characters. Each element in the string is a character (a letter, a number, a symbol, or an emoji).
How it is stored: Python handles the encoding in the background, allowing you to use any alphabet from around the world (including diacritics like ș, ț, î, or Cyrillic characters, Japanese characters, etc.).

Ce sunt obiectele de tip "bytes"?
Tipul bytes reprezintă date binare brute, concepute pentru a fi stocate pe hard disk sau transmise prin rețea.
Unitate de bază: O secvență de numere întregi cuprinse între 0 și 255 (reprezentând octeți/bytes).
Mod de afișare: Atunci când afișezi un obiect de tip bytes, Python încearcă să redea caracterele ASCII ori de câte ori este posibil (pentru o mai bună lizibilitate), în timp ce restul octeților sunt afișați sub formă de secvențe hexazecimale (în formatul \x..).

What are bytes?
The bytes type represents raw binary data, designed to be stored on a hard drive or transmitted over a network.
Basic unit: A sequence of integers between 0 and 255 (representing octets/bytes).
How it is displayed: When you display a bytes object, Python attempts to show ASCII characters wherever possible (for readability), while displaying the remaining bytes as hexadecimal sequences (in the format \x..).
Example: b"Mar" has a length of 3 bytes (since standard ASCII characters occupy 1 byte). In contrast, the word "Măr" converted into bytes (UTF-8) will consist of 4 bytes (b'M\xc4\x83r'), because the diacritic character "ă" occupies 2 bytes.

Python bytes() Function

Funcția bytes() din Python returnează o secvență nouă, imutabilă, de numere întregi din intervalul 0, 256. Aceasta este utilizată, în principal, pentru prelucrarea datelor binare, citirea fișierelor binare și gestionarea protocoalelor de rețea.

bytes() function in Python returns a new, immutable sequence of integers in the range 0,256. It is primarily used for handling binary data, reading binary files, and managing network protocols.

Sintaxă bytes([source[, encoding[, errors]]])

  • -source (Opțional): Datele utilizate pentru a inițializa obiectul de tip bytes.
  • -encoding (Opțional): Obligatoriu dacă source este un string. Specifică modul de codificare (exp., 'utf-8', 'ascii').
  • -errors (Opțional): Specifică modul în care sunt gestionate erorile apărute în timpul codificării (exp., 'strict', 'ignore', 'replace').
  • -source (Optional): The data used to initialize the bytes object.
  • -encoding (Optional): Required if the source is a string. Specifies how to encode it (e.g., 'utf-8', 'ascii').
  • -errors (Optional): Specifies how to handle encoding actions if they fail (e.g., 'strict', 'ignore', 'replace').

Metoda clasă bytes.fromhex() - bytes.fromhex() Class Method

Sintaxă bytes.fromhex(string)

Metoda clasă bytes.fromhex() din Python convertește un șir de cifre hexazecimale într-un obiect de tip bytes imuabil.

The bytes.fromhex() class method in Python converts a string of hexadecimal digits into an immutable bytes object.

Reguli fundamentale
Metoda grupează câte două caractere hexazecimale pentru a forma un singur octet (8 biți).
Orice caractere de tip spațiu alb ASCII (spații, tab-uri, caractere de linie nouă) din cadrul șirului sunt omise automat. Acest lucru permite citirea cu ușurință a dump-urilor hexazecimale formatate sau spațiate.
Metoda acceptă exclusiv caractere hexazecimale și spații albe. Transmiterea unui șir care începe cu 0x sau care conține caractere ce nu sunt hexazecimale va genera o eroare de tip ValueError.
Core Rules
The method pairs up every two hexadecimal characters to form one single byte (8 bits).
Any ASCII whitespace characters (spaces, tabs, newlines) within the string are automatically skipped. This allows you to read formatted or spaced hex dumps easily.
No 0x Prefix Allowed: The method expects only hexadecimal characters and whitespace. Passing a string starting with 0x or containing non-hex characters will throw a ValueError.

# Controlul intrărilor hexazecimale cu spații

print(list(bytes.fromhex("30 8c d9"))) ==> [48, 140, 217]

Accesarea unui element dintr-un obiect de tip bytes returnează un întreg (valoarea ASCII/byte), în timp ce felierea returnează un nou obiect de tip bytes.

Indicele trebuie să fie în intervalul range(0, len(data)-1), altfel Python va genera o eroare de tip IndexError.

Accessing an element from a bytes object returns an integer (the ASCII/byte value), while slicing a bytes object returns a new bytes object.

The index must be in range(0, len(data)-1) otherwise Python will throw an IndexError.

Divizarea și combinarea numerelor binare (manipularea biților) - Splitting and Joining Binary Numbers (Bit Manipulation)

Pentru a împărți un număr întreg în segmente binare de lungime fixă ​​sau pentru a le reasambla, poți converti numărul într-un șir binar sau poți utiliza deplasarea pe biți.

To split an integer into fixed-length binary chunks or reassemble them, you can convert the number to a binary string or use bit-shifting.

# Împărțirea unui număr în două jumătăți (de exemplu, de la 16 biți la două valori pe 8 biți)
def split_16bit(num):
    binar = bin(num)[2:].rjust(16, '0')
    return (int(binar[:8], 2), int(binar[8:], 2))


# Exemplu: 4660 în binar este 0b010010 00110100
# 4660 = 0x1234 în hexazecimal
# Exemplu: 4646 în binar este 0b010010 00100110
# 4646 = 0x1226 în hexazecimal 
# Exemplu: 4460 în binar este 0b010001 01101100
# 4460 = 0x116C în hexazecimal

print(split_16bit(0x1234)) ==> (18, 52)
print(split_16bit(0x1226)) ==> (18, 38)
print(split_16bit(0x116C)) ==> (17, 108)

Acest cod împarte un întreg pe 16 biți în doi întregi separați pe 8 biți (octetul superior și octetul inferior), transformând numărul într-un șir binar, împărțind acest șir în două și reconvertind părțile rezultate în numere întregi.

Iată o explicație pas cu pas a modului în care funcționează codul, folosind exemplul 0x1234 (care înseamnă 4660 în sistemul zecimal):

This code splits a 16-bit integer into two separate 8-bit integers (the high byte and the low byte) by converting the number into a binary string, cutting the string in half, and converting those pieces back into integers.

Here is a step-by-step breakdown of how the code works using the example 0x1234 (which is 4660 in decimal):

bin(num)[2:] (Conversia într-un șir binar)
bin(0x1234) convertește numărul într-un șir binar: '0b1001000110100'.
Segmentarea [2:] elimină prefixul '0b', păstrând doar cifrele binare propriu-zise: '1001000110100'.
.rjust(16, '0') (Completarea cu zerouri)
Dacă șirul binar are mai puțin de 16 cifre, acesta este completat cu zerouri în partea stângă, până când ajunge la o lungime de exact 16 caractere.
Rezultat: '0001001000110100'
binar[:8] and binar[8:] (Împărțirea șirului)
binar[:8] extrage primele 8 caractere (octetul superior / jumătatea superioară): '00010010'
binar[8:] extrage restul de 8 caractere (octetul inferior / jumătatea inferioară): '00110100'
int(..., 2) (Conversia înapoi în numere întregi)
int('00010010', 2) convertește primul șir binar înapoi într-un număr întreg (baza 2), care este 18 (sau 0x12 în hexazecimal).
int('00110100', 2) convertește al doilea șir binar înapoi într-un număr întreg (baza 2), care este 52 (sau 0x34 în hexazecimal).

Funcția returnează tuplul final: (18, 52).

bin(num)[2:] (Convert to Binary String)
bin(0x1234) converts the number to the binary string '0b1001000110100'.
The [2:] slice removes the '0b' prefix, leaving just the raw binary digits: '1001000110100'.
.rjust(16, '0') (Pad with Zeros)
If the binary string is shorter than 16 digits, this pads it with leading zeros on the left until it is exactly 16 characters long.
Result: '0001001000110100'
binar[:8] and binar[8:] (Split the String)
binar[:8] grabs the first 8 characters (the high byte / upper half): '00010010'
binar[8:] grabs the remaining 8 characters (the low byte / lower half): '00110100'
int(..., 2) (Convert Back to Integers)
int('00010010', 2) converts the first binary string back to a base-2 integer, which is 18 (or 0x12 in hex).
int('00110100', 2) converts the second binary string back to a base-2 integer, which is 52 (or 0x34 in hex).

The function returns the final tuple: (18, 52).

O metodă mai rapidă și mai eficientă (operatori pe biți)
Deși metoda bazată pe șiruri de caractere funcționează corect, ea este relativ lentă, deoarece transformă constant numerele în text și invers. În programare, această sarcină este, în mod tradițional, realizată mult mai rapid folosind operatori pe biți:
A Faster, More Efficient Way (Bitwise Operators)
While the string method works perfectly fine, it is relatively slow because it constantly translates numbers to text and back. In programming, this task is traditionally done much faster using bitwise operators:
# Împărțirea unui număr în două jumătăți (de exemplu, de la 16 biți la două valori pe 8 biți)
def split_16bit_bitwise(num):
    octet_superior = (num >> 8) & 0xFF  # Deplasare la dreapta cu 8 biți
    octet_inferior = num & 0xFF         # Izolează cei 8 biți superiori
    return (octet_superior, octet_inferior)

# Exemplu: 4660 în binar este 00010010 00110100
# 4660 în hexazecimal este 0x1234
octet_superior, octet_inferior = split_16bit_bitwise(4660)

print(f"Octet superior: {octet_superior} (Hex: {hex(octet_superior)})")
==> Octet superior: 18 (Hex: 0x12)
print(f"Octet inferior: {octet_inferior} (Hex: {hex(octet_inferior)})")
==> Octet inferior: 52 (Hex: 0x34)

# Reasamblarea părților binare prin deplasarea biților
def join_8bit(octet_superior, octet_inferior):
    return (octet_superior << 8) | octet_inferior

print(join_8bit(18, 52)) ==> 4660
print(join_8bit(18, 38)) ==> 4646
print(join_8bit(17, 108)) ==> 4460

Citirea, modificarea și scrierea unui fișier binar - Reading, Modifying, and Writing a Binary File

Atunci când lucrați cu fișiere fizice, asigurați-vă că le deschideți folosind modurile "rb" (citire binară) și "wb" (scriere binară).

When handling physical files, make sure to open them using "rb" (read binary) and "wb" (write binary) modes.

Regula de aur în Python 3
Când scrii o aplicație modernă, folosește strategia numită "Sandvișul Unicode":
La intrare: Convertește imediat datele primite (octeți) în text (str) folosind .decode().
În interiorul programului: Lucrează exclusiv cu str (procesare text, căutări, modificări).
La ieșire: Convertește textul (str) înapoi în bytes folosind .encode() chiar înainte de a trimite datele în exterior.
The Golden Rule in Python 3
When writing a modern application, use the strategy known as the "Unicode Sandwich":
At the input: Immediately convert incoming data (bytes) into text (str) using .decode().
Inside the program: Work exclusively with str (text processing, searching, modifications).
At the output: Convert the text (str) back into bytes using .encode() just before sending the data externally.

# THE INPUT (Top Crust): Bytes in -> Decode immediately

def load_external_data(file_path):
    # Read raw binary data (bytes) from the outside world
    with open(file_path, "rb") as f:
        raw_bytes = f.read()
    
    # IMMEDIATELY decode to text (str) using the correct encoding
    clean_text = raw_bytes.decode("utf-8")
    return clean_text

# THE APPLICATION CORE (The Filling): Work exclusively with 'str'

def process_text_logic(text_content: str) -> str:
    # Inside the program, we treat it purely as text.
    # String manipulation, searching, and case folding work perfectly.
    uppercase_text = text_content.upper()
    
    # We can safely use text-based methods like replacing characters
    processed_text = uppercase_text.replace("SALUTARE", "BUNĂ ZIUA")
    return processed_text

# HE OUTPUT (Bottom Crust): Encode text -> Bytes out

def save_external_data(file_path, text_content: str):
    # Just before leaving the app, turn the text back into bytes
    encoded_bytes = text_content.encode("utf-8")
    
    # Write the raw bytes out to the external destination
    with open(file_path, "wb") as f:
        f.write(encoded_bytes)
