Tipuri boolean - Boolean Types

  • Boolean Type - bool
  • Python Booleans
  • Built-in Functions

Tipul de date boolean (bool) reprezintă una dintre cele două valori de adevăr predefinite: True sau False.

Valorile True și False sunt sensibile la majuscule și trebuie scrise întotdeauna cu majusculă. Valorile booleene sunt deasemenea o subclasă a numerelor întregi (int), în care True se comportă ca 1, iar False se comportă ca 0.

The Boolean data type (bool) represents one of two built-in truth values: True or False.

True or False are case-sensitive and must always be capitalized. Booleans values are also a subclass of integers (int), where True behaves as 1 and False behaves as 0.

print(type(True))   ==><class 'bool'>
print(type(False))  ==><class 'bool'>

print(True == 1)    ==>True
print(False == 0)   ==>True

print(issubclass(bool, int))  ==>True
print(isinstance(True, int))  ==>True
print(isinstance(False, int)) ==>True

print(True + True) ==> 2

În Python, o valoare booleană (reprezentată prin "tipul de date bool") este utilizată pentru a lua decizii și a controla fluxul unui program, prin evaluarea faptului dacă o condiție este adevărată (True) sau falsă (False).

In Python, a Boolean (represented as the "bool data type") is used to make decisions and control the flow of a program by evaluating whether a condition is True or False.

Valori booleene în diverse scenarii - Booleans in the different scenarios:

#Instrucțiuni condiționale (if, elif, else)
#Valorile booleene determină ce bloc de cod se execută în funcție de o condiție.
este_conectat = True

if este_conectat:
    print("Bun venit!") #Se execută deoarece condiția este adevărată.
else:
    print("Te rog conecteazăte.")

# Comparaţie
# Ori de câte ori compari două valori folosind operatori de comparare 
(>, <, ==, !=, >=, <=), Python returnează automat o valoare booleană.
temperatura = 0
îngheață = temperatura <= 0  # Se evaluează ca adevărat
print(îngheață)  ==>True
îngheață = temperatura > 0  # Se evaluează ca fals
print(îngheață)  ==>False

# Comenzi de buclă (while)
# O buclă "while" verifică în mod continuu o condiție booleană
#și se execută atâta timp cât acea condiție rămâne adevărată

timp_expirat = False
while not timp_expirat:
    print("Poți continua.")  ==> Poți continua.
    timp_expirat = True      # Încheie bucla

# O buclă "if" verifică condiții booleane
# Valorile booleene acționează ca "indicatori" (sau "semnalizatoare") 
#pentru a monitoriza o stare sau un status în cadrul unei aplicații.

def proces_plata(suma):
    if suma <= 0:
        return False  # Plata a eșuat
    return True  # Plata a reușit
    
proces_plata(30)  ==> True

Fără a menționa True or False
Python efectuează automat această conversie pentru evaluarea valorii de adevăr în cadrul instrucțiunilor "if" și al buclelor.

username_list = ["administrator", "oaspete"]

# Python evaluează implicit valoarea de adevăr a listei
if username_list:
    print(f"Utilizatori găsiți: {username_list}")
else:
    print("Lista de utilizatori este goală!")
==> Utilizatori găsiți: ['administrator', 'oaspete']

Testarea obiectelor personalizate

class Cont:
    def __init__(self, balanță):
        self.balanță = balanță

    def __bool__(self):
        # Contul este considerat "falsy" dacă balanță este 0 sau negativ
        return self.balanță > 0

cont_activ = Cont(150)
cont_fără_fonduri = Cont(0)

print(bool(cont_activ))          ==> True
print(bool(cont_fără_fonduri))   ==> False

Operatori booleeni - Boolean operators

Python utilizează trei operatori logici booleeni principali: and, or și not. Acești operatori combină instrucțiuni condiționale și evaluează expresiile, rezultând o valoare booleană True sau False.

Python uses three main logical Boolean operators: and, or, and not. These operators combine conditional statements and evaluate expressions down to a Boolean value of True or False.

Operatori booleeni
Operator Regulă Exemplu Rezultat
and True doar dacă ambele părți sunt adevărate. (5 > 3) and (10 < 20) True
or True dacă cel puțin o parte este adevărată (5 < 3) or (10 < 20) True
not Inversează valoarea (True devine False) not (5 > 3) False

Evaluare cu scurtcircuitare - Short-Circuit Evaluation

Python utilizează evaluarea cu scurtcircuitare pentru a optimiza performanța. Acesta încetează verificarea expresiilor imediat ce rezultatul final este garantat.

  • and realizează un scurtcircuit dacă expresia din stânga este False. Deoarece ambele expresii trebuie să fie adevărate, Python ignoră complet expresia din dreapta.
  • or realizează un scurtcircuit dacă expresia din stânga este True. Deoarece este suficient ca una singură să fie adevărată, acesta sare peste evaluarea părții din dreapta.

Din acest motiv, and și or nu returnează întotdeauna o valoare strictă de tip True sau False. În schimb, ele returnează valoarea ultimului operand evaluat.

Python uses short-circuit evaluation to optimize performance. It stops checking expressions as soon as the final result is guaranteed.

  • and short-circuits if the left expression is False. Because both must be true, Python ignores the right expression entirely.
  • or short-circuits if the left expression is True. Because only one needs to be true, it skips evaluating the right side.

Because of this, and and or do not always return a strict True or False value. Instead, they return the value of the last evaluated operand. 

print(0 and 20) ==> 0 (0 este fals, deci "and" îl scurtcircuitează și îl returnează)
print(5 or 10)  ==> 5 (5 este adevărat, deci "or" îl scurtcircuitează și îl returnează)

Operatorul "and"

scor = 65
trecut = True

# Ambele condiții trebuie să fie îndeplinite pentru a obține diploma.
if scor >= 65 and trecut:
    print("Îți poți ridica diploma.")

Operatorul "or"

este_luni = False
zi_de_sărbătoare = True

# Dacă oricare dintre condiții este adevărată, se va fi o zi liberă.
if este_luni or zi_de_sărbătoare:
    print("E timpul să te relaxezi!")
else:
    print("Înapoi la muncă.")
==> E timpul să te relaxezi!

Operatorul "not"

Operatorul "not" se plasează în fața condiției pentru a-i inversa rezultatul.

plouă = False

# Rezultatul este True dacă nu plouă
if not plouă:
    print("Hai la o plimbare.")
else:
    print("Rămâi în casă.")

==> Hai la o plimbare.

Precedența operatorilor (ordinea operațiilor)

Atunci când se combină mai mulți operatori într-o singură instrucțiune, Python îi evaluează într-o ordine specifică:

When mixing multiple operators in a single statement, Python evaluates them in a specific order:

  1. not (highest priority)
  2. and
  3. or (lowest priority)

Folosește paranteze () pentru a specifica explicit ordinea de evaluare și pentru a menține codul lizibil.

Use parentheses () to explicitly dictate evaluation order and keep your code readable.

rezultat_default = True or False and False
# "and" se evaluează primul în mod implicit: 
True or (False and False) ==> True or False 
print(rezultat_default)  ==> True

rezultat_paranteză = (True or False) and False
# Parantezele impun evaluarea mai întâi a operatorului "or": 
(True or False) and False ==> True and False 
print(rezultat_paranteză)   ==> False

Operatori asociați: Comparare și identitate - Related Operators: Comparison & Identity

Expresiile booleene sunt adesea construite folosind operatori de comparare care returnează o valoare booleană:

  • Comparare: == (egal cu), != (diferit de), >, <, >=, <=.
  • Identitate: is verifică dacă două variabile indică exact același obiect din memoria calculatorului.
  • Apartenență: in verifică dacă un anumit element există într-o colecție (cum ar fi o listă sau un șir de caractere).

Boolean expressions are frequently built using comparison operators that output a Boolean value:

  • Comparison: == (equal to), != (not equal to), >, <, >=, <=.
  • Identity: is checks if two variables point to the exact same object in computer memory.
  • Membership: in checks if a specific element exists inside a collection (like a list or string).
print(False == 0) ==> True
print(True == 1)  ==> True

Numerele întregi mici (de la -5 la 256) sau șirurile scurte returnează uneori True atât pentru ==, cât și pentru is.
Small integers (from -5 to 256) or short strings sometimes return True for both == and is. 

x = 100
y = 100
print(x is y) ==> True (Datorită optimizării memoriei interne din Python)
print(id(x))  ==> 140716356837256
print(id(y))  ==> 140716356837256

x = 257
y = 257
print(x is y) ==> False
print(id(x))  ==> 2306467458672
print(id(y))  ==> 2306467457456
print(x == y) ==> True

Din cauza acestei optimizări interne (numită "interning"), nu ar trebui să folosești niciodată "is" pentru a compara valori de tipuri primitive, precum numere întregi sau șiruri de caractere. Folosește întotdeauna "==" pentru valori și rezervă "is" pentru verificări de tipul variabilă is None.

Because of this background optimization (called "interning"), you should never use is to compare primitive data values like integers or strings. Always use == for values and reserve "is" for checks like variable is None.
