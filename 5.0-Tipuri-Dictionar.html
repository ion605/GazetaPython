Dicționar, un tip de date încorporat - Dictionary a built-in data type

În Python, un dicționar este un tip de date încorporat foarte important și util, care stochează date în perechi cheie-valoare. Este o colecție mutabilă, conținutul său poate fi modificat după creare. Dicționarele sunt, ordonate începând cu Python 3.7+ și nu permit chei duplicate.

Caracteristici cheie ale dicționarelor Python:
Perechi cheie-valoare: Datele sunt stocate ca o colecție de perechi cheie:valoare.
Chei unice: Fiecare cheie dintr-un dicționar trebuie să fie unică. Cheile sunt utilizate pentru a accesa valorile corespunzătoare.
Chei imuabile: Cheile dicționarului trebuie să fie de un tip de date imuabil, cum ar fi șiruri de caractere, numere sau tupluri. Listele și alte tipuri mutabile nu pot fi utilizate ca chei.
Valori mutabile: Valorile dicționarului pot fi de orice tip de date, inclusiv alte dicționare, liste sau funcții.
Ordonate (Python 3.7+): Dicționarele mențin ordinea de inserare a elementelor.
Schimbabile: Puteți adăuga, modifica sau șterge perechi cheie-valoare după ce un dicționar este creat.
Sintaxă: Dicționarele sunt definite folosind acolade {} cu perechi cheie-valoare separate prin două puncte (:) și perechi individuale separate prin virgule (,).
Fără indexare:
Spre deosebire de secvențe precum listele sau șirurile de caractere, dicționarele nu acceptă indexarea sau felierea. Datele sunt accesate prin cheia asociată.
Implementat cu tabele hash:
Dicționarele sunt de obicei implementate folosind tabele hash, care permit operațiuni rapide de căutare, inserare și ștergere.

In Python, a dictionary is a very important and useful built-in data type that stores data in key-value pairs. It is a mutable collection, meaning its contents can be changed after creation. Dictionaries are also ordered as of Python 3.7+, and they do not allow duplicate keys.

Key characteristics of Python dictionaries:
Key-Value Pairs: Data is stored as a collection of key: value pairs.
Unique Keys: Each key within a dictionary must be unique. Keys are used to access their corresponding values.
Immutable Keys: Dictionary keys must be of an immutable data type, such as strings, numbers, or tuples. Lists and other mutable types cannot be used as keys.
Mutable Values: Dictionary values can be of any data type, including other dictionaries, lists, or functions.
Ordered (Python 3.7+): Dictionaries maintain the insertion order of items.
Changeable: You can add, modify, or delete key-value pairs after a dictionary is created.
Syntax: Dictionaries are defined using curly braces {} with key-value pairs separated by colons (:) and individual pairs separated by commas (,).
No Indexing:
Unlike sequences like lists or strings, dictionaries do not support integer-based indexing or slicing. Data is accessed by its associated key.
Implemented with Hash Tables:
Dictionaries are typically implemented using hash tables, which enables fast lookup, insertion, and deletion operations.
nume_dicționar = {
"cheie1": "valoare1",
"cheie2": "valoare2",
"cheie3": "valoare3"
}

dictionary_name = {
    "key1": "value1",
    "key2": "value2",
    "key3": "value3"
}

Metodele Dicționarului - The Dictionary's Methods

Tipul încorporat dict din Python nu dispune de metode speciale așa cum au clasele definite de utilizator pentru operații precum adunarea. În schimb, utilizează metode standard precum get(), keys(), values() și items() pentru manipularea datelor și suportă accesul bazat pe operatori, de tipul d[key]. Metodele speciale (cunoscute și sub numele de "dunder methods") servesc la definirea comportamentului obiectelor și nu sunt utilizate direct pentru operațiile specifice dicționarelor încorporate, deși __dict__ este un atribut special folosit intern pentru stocarea atributelor unui obiect.

Python's built-in dict type doesn't have specific special methods in the way a custom class does for operations like addition. Instead, it uses standard methods like get(), keys(), values(), and items() to manipulate data, and also supports operator-based access like d[key]. The special methods (dunder methods), are for defining object behavior and aren't used directly for built-in dictionary operations, though __dict__ is a special attribute used internally to store an object's attributes.

Metode standard pentru a interacționa cu dicționarele
clear() Elimină toate elementele din dicționar.
copy() Returnează o copie a dicționarului
fromkeys() Returnează un dicționar cu cheile și valoarea specificate.
get(key, default=None) Returnează valoarea pentru cheia specificată sau default dacă cheia nu este găsită.
keys() Returnează un obiect de vizualizare a tuturor cheilor din dicționar.
values() Returnează un obiect de vizualizare a tuturor valorilor din dicționar.
items() Returnează un obiect de vizualizare a perechilor cheie-valoare (sub formă de tupluri).
pop(key, default=None) Elimină cheia specificată și returnează valoarea acesteia.
popitem() Elimină și returnează ultima pereche cheie-valoare inserată ca tuplu.
update(other) Actualizează dicționarul cu perechi cheie-valoare dintr-un alt dicționar sau dintr-un iterabil de perechi cheie-valoare.
setdefault(key, default=None) Dacă cheia este în dicționar, aceasta returnează valoarea sa. Altfel, introduce cheia cu valoarea implicită specificată și returnează valoarea implicită.
Metode speciale (metode Dunder)
Aceste metode, cu nume precum __init__ și __len__, fac parte din modelul de date Python și sunt apelate implicit de Python pentru a executa anumite operații.
__init__(self, other) Constructorul, apelat după ce un obiect este creat.
__len__(self) Permite funcției len() să lucreze cu obiecte personalizate.
__dict__ Un atribut intern care conține atributele și metodele de scriere ale unei clase sau instanțe, acționând ca un spațiu de nume.

Deși din punct de vedere tehnic puteți apela direct metode speciale, Python intenționează ca acestea să fie apelate implicit prin funcții sau operatori încorporați. Pentru operațiunile de dicționar încorporate, veți utiliza metodele standard enumerate mai sus.

Standard methods for interacting with dictionaries.
clear() Removes all items from the dictionary.
copy() Returns a copy of the dictionary.
fromkeys() Returns a dictionary with the specified keys and value.
get(key, default=None) Returns the value for the specified key, or default if the key is not found.
keys() Returns a view object of all the keys in the dictionary.
values() Returns a view object of all the values in the dictionary.
items() Returns a view object of key-value pairs (as tuples).
pop(key, default=None) Removes the specified key and returns its value.
popitem() Removes and returns the last inserted key-value pair as a tuple.
update(other) Updates the dictionary with key-value pairs from another dictionary or an iterable of key-value pairs.
setdefault(key, default=None) If the key is in the dictionary, it returns its value. Otherwise, it inserts the key with the specified default value and returns the default value.
Special Methods (Dunder Methods)
These methods, with names like __init__ and __len__, are part of Python's data model and are called implicitly by Python to execute certain operations.
__init__(self, other) The constructor, called after an object is created.
__len__(self) Allows the len() function to work with custom objects.
__dict__ An internal attribute that holds the writable attributes and methods of a class or instance, acting as a namespace.

While you can technically call special methods directly, Python intends for them to be called implicitly through built-in functions or operators. For built-in dictionary operations, you'll use the standard methods listed above.

dir({})
În Python, funcția dir() este un instrument încorporat utilizat pentru introspecția obiectelor, care returnează o listă sortată a atributelor și metodelor valide pentru un anumit obiect sau domeniu de vizibilitate.
dir({})
In Python, the dir() function is a built-in tool used for object introspection that returns a sorted list of valid attributes and methods for a given object or scope.
