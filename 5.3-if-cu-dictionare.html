Condiția if cu dicționare - if condition with Dictionaries

În Python, poți folosi condiții pentru a verifica dacă o cheie există, pentru a filtra date sau pentru a actualiza valori pe baza unor criterii specifice.

In Python, you can use conditions to check if a key exists, filter data, or update values based on specific criteria.

Verificarea existenței cheii - Checking for Key Existence

Cea mai comună și mai specifică metodei Python de a verifica dacă o cheie există într-un dicționar este prin utilizarea operatorului in. Această abordare verifică în mod explicit prezența cheii înainte de a încerca orice operațiune.

The most common and Pythonic way to check if a key exists in a dictionary is by using the in operator. This approach explicitly checks for the key's presence before attempting any operation.

# Află dacă cheia există (Verificare recursivă)
def are_cheie_recursiv(dictionar, cheie):
    # Verifică dacă se află la nivelul curent
    if cheie in dictionar:
        return True
        
    # Caută în profunzime, în eventualele dicționare imbricate
    for valoare in dictionar.values():
        # Verifică dacă valoarea este un alt dicționar
        if isinstance(valoare, dict): 
            if are_cheie_recursiv(valoare, cheie):
                return True
    return False

# Exemplu:
dict_imbricat = {"a": 1, "b": {"c": 2, "d": {"cheie": "indict!"}}}

if are_cheie_recursiv(dict_imbricat, "cheie"):
    print("Cheia există undeva în dicționar!")
    
else:
    print("Cheia nu există în dicționar!")
==> Cheia există undeva în dicționar!

Handling errors in Python using try-except blocks allows you to prevent the program from crashing unexpectedly when an unforeseen situation arises, such as accessing a non-existent key in a dictionary (KeyError).

Verificarea existenței cheii folosind metoda get() - Checking for Key Existence using the get() method

Metoda get() preia valoarea asociată cu o anumită cheie daca există. Dacă cheia nu este găsită, returnează implicit None (sau o valoare implicită specificată). Aceasta poate fi utilizată pentru a deduce existența cheii.

The get() method retrieves the value associated with a specific key, if it exists. If the key is not found, it returns None by default (or a specified default value). This can be used to determine whether the key exists.

persoana = {"nume": "Cristina", "varsta": 50, "localitate": "Severin"}

if persoana.get("varsta") is not None:
    print("Cheia 'varsta' există în dictionar.")
else:
    print("Cheia 'varsta' nu există în dictionar.")
    
if persoana.get("tara") is not None:
    print("Cheia 'tara' există în dictionar.")
else:
    print("Cheia 'tara' nu există în dictionar.") 
==> Cheia 'varsta' există în dictionar.
==> Cheia 'tara' nu există în dictionar.

Verificarea existenței cheie-valoare - Checking for the existence of a key-value pair

Pentru a verifica dacă există o anumită pereche cheie-valoare într-un dicționar Python, puteți utiliza operatorul if cu .items(), .get() or in. Metoda .items() or .get() returnează un obiect de vizualizare care afișează o listă cu perechile de tupluri cheie-valoare ale unui dicționar. Puteți apoi utiliza operatorul in pentru a verifica dacă un anumit tuplu (cheie, valoare) este prezent în această vizualizare.

To check if a specific key-value pair exists in a Python dictionary, you can use if operator with the .items(), .get() or in. The .items() or .get() method returns a view object that displays a list of a dictionary's key-value tuple pairs. You can then use the in operator to check if a specific (key, value) tuple is present in this view.

# Utilizarea operatorului in împreună cu .items()

persoana = {"nume": "Cristina", "varsta": 50, "localitate": "Severin"}

if ("nume", "Cristina") in persoana.items():
    print('Perechea cheie-valore ("nume", "Cristina") există.')
else:
    print('Perechea cheie-valore ("nume", "Cristina") nu există.')
    
if ("varsta", 30) in persoana.items():
    print('Perechea cheie-valore ("varsta", 30) există.')
else:
    print('Perechea cheie-valore ("varsta", 30) nu există.')

==> Perechea cheie-valore ("nume", "Cristina") există.
==> Perechea cheie-valore ("varsta", 30) nu există.

# Utilizarea .get() (Verificarea în siguranță)

persoana = {"nume": "Cristina", "varsta": 50, "localitate": "Severin"}
if persoana.get("nume") == "Cristina":
    print(f'Perechea cheie-valore ("nume", "Cristina") există.')
else:
    print('Perechea cheie-valore ("nume", "Cristina") nu există.')
    
if persoana.get("varsta") == 30:
    print('Perechea cheie-valore ("varsta", 30) există.')
else:
    print('Perechea cheie-valore ("varsta", 30) nu există.')

==> Perechea cheie-valore ("nume", "Cristina") există.
==> Perechea cheie-valore ("varsta", 30) nu există.

# Utilizarea operatorului in (cea mai rapidă metodă pentru logica în mai mulți pași)

persoana = {"nume": "Cristina", "varsta": 50, "localitate": "Severin"}
if "nume" in persoana and persoana["nume"] == "Cristina":
    print(f'Perechea cheie-valore ("nume", "Cristina") există.')
else:
    print('Perechea cheie-valore ("nume", "Cristina") nu există.')
    
if "varsta" in persoana and persoana["varsta"] == 30:
    print('Perechea cheie-valore ("varsta", 30) există.')
else:
    print('Perechea cheie-valore ("varsta", 30) nu există.')

==> Perechea cheie-valore ("nume", "Cristina") există.
==> Perechea cheie-valore ("varsta", 30) nu există.

Dicționare imbricate - Nested dictionaries

Un dicționar imbricat în Python este un dicționar în care valorile asociate unor chei sunt ele însele alte dicționare. Acest lucru permite stocarea ierarhică a datelor.

Instrucțiunile if pot fi utilizate pentru a accesa sau procesa condiționat date dintr-un dicționar imbricat. Aceasta poate implica verificarea existenței cheilor, compararea valorilor sau efectuarea de acțiuni pe baza unor criterii specifice.

A nested dictionary in Python is a dictionary where the values associated with some keys are themselves other dictionaries. This allows for hierarchical data storage.

if statements can be used to conditionally access or process data within a nested dictionary. This can involve checking for the existence of keys, comparing values, or performing actions based on specific criteria.

# dicționar imbricat
student_punctaje = {
    "id_a01": {"numele": "Angela", "varsta": 19, "punctaj": {"Matematica": 90, "Calculator": 85, "Engleza": 75}
    },

student_id_de_verificat = "id_a01"

def verifica_valideaza_varsta(dictionar):
    # Verificăm dacă structura de chei există
    utilizator = dictionar.get("utilizator1")
    if utilizator is None:
        return False, "Lipsește cheia 'utilizator1' sau valoarea este None"
        
    profil = utilizator.get("profil")
    if profil is None:
        return False, "Lipsește cheia 'profil' în cadrul utilizatorului"
        
    if "varsta" not in profil:
        return False, "Lipsește cheia 'varsta' din profil"
        
    varsta = profil.get("varsta")
    if varsta is None:
        return False, "Cheia 'varsta' există, dar valoarea ei este None"

    # Validarea tipului de date și a valorii
    if not isinstance(varsta, int):
        return False, f"Tip de date invalid pentru vârstă! Se aștepta 'int', dar s-a primit '{type(varsta).__name__}'"
        
    if varsta <= 0 or varsta > 140:
        return False, f"Valoare nerealistă pentru vârstă: {varsta} (trebuie să fie între 1 și 140)"

    # Dacă totul este în regulă
    return True, varsta

def verifica_converteste_valideaza(dictionar):
    # Verificarea existenței structurii de chei
    utilizator = dictionar.get("utilizator1")
    if utilizator is None:
        return False, "Lipsește cheia 'utilizator1' sau valoarea este None"
        
    profil = utilizator.get("profil")
    if profil is None:
        return False, "Lipsește cheia 'profil' în cadrul utilizatorului"
        
    if "varsta" not in profil:
        return False, "Lipsește cheia 'vârstă' din profil"
        
    varsta_initial = profil.get("varsta")
    if varsta_initial is None:
        return False, "Cheia 'varsta' există, dar valoarea ei este None"

    # Încercarea de conversie automată în număr întreg (int)
    try:
        # int() va funcționa pentru numere (25), float-uri (25.6 -> 25) și string-uri numerice ("25")
        # Folosim float mai întâi pentru a prinde cazuri precum "25.0" care altfel ar da eroare direct la int()
        varsta = int(float(varsta_initial))
    except (ValueError, TypeError):
        return False, f"Conversie eșuată! Valoarea '{varsta_initial}' (tip: {type(varsta_initial).__name__}) nu poate fi transformată în număr întreg."

    # Validarea valorii numerice obținute
    if varsta <= 0 or varsta > 140:
        return False, f"Valoare nereală pentru vârstă după conversie: {varsta} (trebuie să fie între 1 și 140)"

    # Dacă totul este în regulă, returnăm True și valoarea curățată (int)
    return True, varsta

        # Actualizare valoarea în dicționar
        profil["varsta"] = varsta_corectata
        raport["actualizat"].append(id_utilizator)
        
    # Ștergerea efectivă a utilizatorilor invalizi din dicționarul original
    for id_utilizator in utilizatori_de_sters:
        del dictionar_date[id_utilizator]
        
    return raport

def elimina_invalid(dictionar_date):
    raport = { 
        "actualizat": [], 
        "eliminat": {} 
    }
    date_valide = {}

    for utilizator, date in dictionar_date.items():
        # Verificăm existența profilului
        if "profil" not in date:
            raport["eliminat"][utilizator] = "Lipseste profilul"
            continue
            
        profil = date["profil"]
        
        # Verificăm existența cheii 'varsta'
        if "varsta" not in profil:
            raport["eliminat"][utilizator] = "Lipseste cheia varsta"
            continue
            
        varsta_initial = profil["varsta"]
        
        # Încercăm conversia și validarea vârstei
        try:
            # float(varsta_initial) rezolvă atât "35" cât și 20.9. 
            int() transformă în număr întreg (20.9 -> 20)
            varsta_intreg = int(float(varsta_initial))

            # Limiata superioară nu contează
            if varsta_intreg < 0:
                raport["eliminat"][utilizator] = f"Varsta negativa: {varsta_initial}"
            else:
                # Salvăm utilizatorul validat cu structura corectă
                date_valide[utilizator] = {"profil": {"varsta": varsta_intreg}}
                raport["actualizat"].append(utilizator)
                
        except (ValueError, TypeError):
            raport["eliminat"][utilizator] = f"Valoare invalida pentru varsta: {varsta_initial}"

    return date_valide, raport

date_utilizatori = { 
    "utilizator1": {"profil": {"nume": "Ion Popescu", "varsta": "35"}},       
    "utilizator2": {"profil": {"nume": "Anca Alexandrescu", "varsta": 20.9}},

    "utilizator4": {"profil": {"nume": "Elena", "varsta": -5}},               
    "utilizator5": {"fara_profil": {}},                                       
    "utilizator6": {"profil": {"nume": "Dan Lolea", "varsta": 33}},            
    "utilizator7": {"profil": {"nume": "Ana-Maria!", "varsta": 25}},          
    "utilizator8": {"profil": {"nume": "Ana-Maria", "varsta": 28}},
    "utilizator9": {"profil": {"nume": "Al", "varsta": 40}},                  
    "utilizator10": {"profil": {"nume": "AB" * 26, "varsta": 22}}               
}

def elimina_invalid(dictionar_date, varsta_maxima=120, nume_min_len=3, nume_max_len=50):
    raport = { 
        "actualizat": [], 
        "eliminat": {} 
    }
    date_valide = {}

    for utilizator, date in dictionar_date.items():
        # Verificăm existența profilului
        if "profil" not in date:
            raport["eliminat"][utilizator] = "Lipseste profilul"
            continue
            
        profil = date["profil"]
        
        # Verificăm existența cheilor 'nume' și 'varsta'
        if "nume" not in profil:
            raport["eliminat"][utilizator] = "Lipseste cheia nume"
            continue
        if "varsta" not in profil:
            raport["eliminat"][utilizator] = "Lipseste cheia varsta"
            continue
            
        nume_initial = str(profil["nume"]).strip()  # Folosim .strip() pentru a elimina spațiile inutile de la început/sfârșit
        varsta_initial = profil["varsta"]
        
        # Validare lungime nume
        if len(nume_initial) < nume_min_len:
            raport["eliminat"][utilizator] = f"Nume prea scurt (minimum {nume_min_len} caractere): '{nume_initial}'"
            continue
        if len(nume_initial) > nume_max_len:
            raport["eliminat"][utilizator] = f"Nume prea lung (maximum {nume_max_len} caractere)"
            continue
        
        # Validare format nume (doar litere, spații și cratime)
        if not re.match(r"^[A-Za-zĂÂÎȘȚăâîșț \-]+$", nume_initial):
            raport["eliminat"][utilizator] = f"Nume invalid (trebuie sa contina doar litere, spatii sau cratime): '{nume_initial}'"
            continue
        
        # Încercăm conversia și validarea vârstei
        try:
            varsta_intreg = int(float(varsta_initial))
            
            if varsta_intreg < 0:
                raport["eliminat"][utilizator] = f"Varsta negativa: {varsta_initial}"
            elif varsta_intreg > varsta_maxima:
                raport["eliminat"][utilizator] = f"Varsta depaseste limita maxima de {varsta_maxima} ani: {varsta_initial}"
            else:
                # Salvăm utilizatorul validat
                date_valide[utilizator] = {"profil": {"nume": nume_initial, "varsta": varsta_intreg}}
                raport["actualizat"].append(utilizator)
                
        except (ValueError, TypeError):
            raport["eliminat"][utilizator] = f"Valoare invalida pentru varsta: {varsta_initial}"

    return date_valide, raport
