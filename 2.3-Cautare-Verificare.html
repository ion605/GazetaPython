Python String Methods

Python oferă mai multe metode pentru căutarea în șiruri de caractere. Alegerea metodei depinde de cerințele specifice ale căutării, cum ar fi dacă trebuie să verificați existența, să găsiți indexul unui subșir sau să efectuați potriviri de tipare mai complexe.

Python provides several methods for searching within strings. The choice of method depends on the specific requirements of the search, such as whether you need to check for existence, find the index of a substring, or perform more complex pattern matching.

.endswith(suffix[, start[, end]])

Sintaxă: şir.endswith(suffix[, start[, end]])

Python String endswith() Method

Verifică dacă șirul de caractere se termină cu sufixul specificat.

Parametri:
sufix: Acesta este șirul sau un tuplu de șiruri cu care doriți să verificați dacă șirul original se termină.
start (opțional): Un număr întreg care specifică indicele de început de unde începe căutarea sufixului.
end (opțional): Un număr întreg care specifică indicele de sfârșit înaintea căruia se termină căutarea sufixului.
Valoare returnată:
Metoda endswith() returnează o valoare booleană:
True dacă șirul (sau un subșir specificat) se termină cu sufixul.
False în caz contrar.

Checks if the string ends with the specified suffix.

Parameters:
suffix: This is the string or a tuple of strings that you want to check if the original string ends with.
start (optional): An integer specifying the starting index from where the search for the suffix begins.
end (optional): An integer specifying the ending index before which the search for the suffix ends.
Return Value:
The endswith() method returns a boolean value:
True if the string (or a specified substring) ends with the suffix.
False otherwise.
șir = "Salut, Lume!"
rezultat_1 = șir.endswith("Lume!")
rezultat_2 = șir.endswith("lume!") # Sensibilitate la majuscule/minuscule

print(f"Se termină cu 'Lume!': {rezultat_1}") ==> True
print(f"Se termină cu 'lume!': {rezultat_2}") ==> False

# parametrii de început și de sfârșit
text = "Python Programare"
rezultat1 = text.endswith("gram", 7, 14) # Verifică "Program"
rezultat2 = text.endswith("mare", 7) # Verifică de la indexul 7 până la sfârșit

print(f"Se termină cu 'gram' în subșirul {text[7: 14]}: {rezultat1}")   ==> True
print(f"Se termină cu 'mare' în subșirul de la indexul 7: {rezultat2}") ==> True

# sufixe multiple (tuplu)
nume_fișier = "imagine.png"
rezultat = nume_fișier.endswith((".jpg", ".gif", ".png"))

print(f"Se termină cu oricare dintre extensiile de imagine: {rezultat}") ==> True

.startswith(prefix[, start[, end]])

Sintaxă: şir.startswith(prefix[, start[, end]])

Python String startswith() Method

Verifică dacă șirul începe cu prefixul specificat.

Parametri:
prefix: Acesta este șirul sau un tuplu de șiruri cu care se verifică dacă șirul începe. Dacă este furnizat un tuplu, metoda returnează True dacă șirul începe cu oricare dintre prefixele din tuplu.
start (opțional): Un număr întreg care specifică poziția de început în șir unde ar trebui să înceapă căutarea prefixului. Implicit este 0 (începutul șirului).
end (opțional): Un număr întreg care specifică poziția de sfârșit în șir unde ar trebui să se termine căutarea prefixului. Implicit este lungimea șirului.
Valoare returnată:
Metoda startswith() returnează o valoare booleană:
True dacă șirul (sau porțiunea specificată a șirului) începe cu prefixul dat.
False în caz contrar.

Checks if the string starts with the specified prefix.

Parameters:
prefix: This is the string or a tuple of strings to check if the string starts with. If a tuple is provided, the method returns True if the string starts with any of the prefixes in the tuple.
start (optional): An integer specifying the starting position in the string where the search for the prefix should begin. The default is 0 (the beginning of the string).
end (optional): An integer specifying the ending position in the string where the search for the prefix should end. The default is the length of the string.
Return Value:
The startswith() method returns a boolean value:
True if the string (or the specified slice of the string) starts with the given prefix.
False otherwise.
șir = "Salut, lume Python!"

# Verifică dacă șirul începe cu un singur prefix
print(șir.startswith("Salut")) ==> True
print(șir.startswith("Salve")) ==> False 

# Verificați dacă șirul începe cu oricare dintre mai multe prefixe (folosind un tuplu)
print(șir.startswith(("Salve", "Salut"))) ==> True

# Check with start and end parameters
print(șir.startswith("lume", 7, 12))    # True (verifică lume în lume)
print(șir.startswith("lume", 0, 5))     # False (verifică Salut în Salut)

Python String isalnum() Method

În Python, isalnum() este o metodă încorporată pentru șiruri de caractere, utilizată pentru a determina dacă toate caracterele dintr-un șir de caractere sunt alfanumerice.

Funcționalitate:

Returnează False dacă șirul de caractere conține caractere non-alfanumerice (de exemplu, spații, semne de punctuație, simboluri) sau dacă șirul de caractere este gol.

In Python, isalnum() is a built-in string method used to determine if all characters within a string are alphanumeric.

Functionality:
It returns True if all characters in the string are either letters (a-z, A-Z) or digits (0-9).
It returns False if the string contains any non-alphanumeric characters (e.g., spaces, punctuation, symbols) or if the string is empty.
Parameters:
The isalnum() method does not accept any parameters.
Return Value:
A boolean value: True or False.
print("Python3".isalnum())
print("Salut Lume".isalnum()) # Fals (din cauza spațiului)

.isascii()

Sintaxă: şir.isascii()

Python String isascii() Method

În Python, isascii() este o metodă de tip șir de caractere care verifică dacă toate caracterele dintr-un șir sunt caractere ASCII (American Standard Code for Information Interchange).

Cum funcționează isascii():
Metoda isascii() returnează True dacă toate caracterele din șir au o valoare ASCII între 0 și 127 (inclusiv).
Dacă șirul conține caractere non-ASCII (caractere cu o valoare ASCII mai mare de 127), metoda returnează False.
Un șir gol returnează, de asemenea, True atunci când este apelată isascii() asupra lui.

In Python, isascii() is a string method that checks whether all characters in a string are ASCII(American Standard Code for Information Interchange) characters.

How isascii() works:
isascii() method returns True if all characters in the string have an ASCII value between 0 and 127 (inclusive).
If the string contains any non-ASCII characters (characters with an ASCII value greater than 127), the method returns False.
An empty string also returns True when isascii() is called on it.
# Exemplu de isascii() care returnează True
şir_1 = "Salut, lume!"
print(f"'{şir_1}'.isascii(): {şir_1.isascii()}") ==> True

# Exemplu de isascii() care returnează False din cauza unui caracter non-ASCII
şir_2 = "Bună, lume!"
print(f"'{şir_2}'.isascii(): {şir_2.isascii()}") ==> False

# Exemplu cu un șir gol
şir_3 = ""
print(f"'{şir_3}'.isascii(): {şir_3.isascii()}") ==> True

# Exemplu cu caractere ASCII speciale
şir_4 = "Linia1\nLinia2\tTabbed"
print(f"'{şir_4}'.isascii(): {şir_4.isascii()}") ==> True

Python String isdecimal() Method

.isdecimal() method in Python is a string method used to check if all characters in a given string are decimal characters and if the string contains at least one character. It returns True if these conditions are met, and False otherwise.

Characteristics:
Decimal Characters: It specifically identifies characters that can be used to form numbers in base 10. This typically refers to the digits 0-9 in various numeral systems (e.g., Arabic numerals, Bengali numerals) as defined by Unicode.
Exclusions: It returns False if the string contains any non-decimal characters, including:
Letters (e.g., "abc")
Punctuation (e.g., ".", ",", "!")
Whitespace (e.g., spaces, tabs)
Special characters (e.g., "$", "%")
Superscripts or subscripts (e.g., "²", "½")
Roman numerals or currency numerals.
Empty Strings: An empty string will return False because it does not contain at least one character.
Unicode Support: It works with Unicode strings, recognizing decimal characters from various supported numeral systems.

.isdecimal() din Python este o metodă de tip șir de caractere utilizată pentru a verifica dacă toate caracterele dintr-un șir dat sunt caractere zecimale și dacă șirul conține cel puțin un caracter. Returnează True dacă aceste condiții sunt îndeplinite și False în caz contrar.

Caracteristici:
Caractere zecimale: Identifică în mod specific caracterele care pot fi utilizate pentru a forma numere în baza 10. Aceasta se referă de obicei la cifrele 0-9 din diverse sisteme numerice (de exemplu, cifre arabe, cifre bengaleze), așa cum sunt definite de Unicode.
Excluderi: Returnează False dacă șirul conține caractere nezecimale, inclusiv:
Litere (de exemplu, "abc")
Punctuație (de exemplu, „.", „,", „!")
Spații albe (de exemplu, spații, tabs)
Caractere speciale (de exemplu, "$", "%”)
Superscripturi sau indici (de exemplu, "²", "½")
Cifre romane sau cifre valutare.
Șiruri goale: Un șir gol va returna False deoarece nu conține cel puțin un caracter.
Suport Unicode: Funcționează cu șiruri Unicode, recunoscând caracterele zecimale din diverse sisteme numerice acceptate.

s2 = "123.45"

print(s3.isdecimal()) ==> False

s4 = ""

Python String isidentifier() Method

.isidentifier() din Python este o metodă încorporată pentru șiruri de caractere, utilizată pentru a determina dacă un anumit șir de caractere este un identificator valid, conform regulilor limbajului Python.

Cum funcționează isidentifier():
Metoda returnează True dacă șirul de caractere îndeplinește criteriile pentru un identificator Python valid și False în caz contrar.
Reguli pentru un identificator Python valid:
Caractere: Un identificator valid poate conține doar caractere alfanumerice (a-z, A-Z, 0-9) și sublinieri (_).
Caracter de început: Trebuie să înceapă cu o literă (a-z, A-Z) sau un subliniere (_). Nu poate începe cu un număr.
Cuvinte cheie: Nu poate fi un cuvânt cheie Python (cuvânt rezervat), cum ar fi if, else, for, while, def, class etc.
Caractere speciale: Nu poate conține caractere speciale precum !, @, #, $, % etc.

.isidentifier() method in Python is a built-in string method used to determine if a given string is a valid identifier according to Python's language rules.

How isidentifier() works:
The method returns True if the string meets the criteria for a valid Python identifier, and False otherwise.
Rules for a valid Python identifier:
Characters: A valid identifier can only contain alphanumeric characters (a-z, A-Z, 0-9) and underscores (_).
Starting character: It must start with a letter (a-z, A-Z) or an underscore (_). It cannot begin with a number.
Keywords: It cannot be a Python keyword (reserved word), such as if, else, for, while, def, class, etc.
Special characters: It cannot contain any special characters like !, @, #, $, %, etc.
# Identificatori valizi
print("variabila_mea".isidentifier()) # True
print("Numere123".isidentifier()) # True
print("_privat".isidentifier()) # True

# Identificatori invalizi
print("123nume".isidentifier()) # Fals (începe cu un număr)
print("variabila-mea".isidentifier()) # Fals (conține o cratimă)
print("if".isidentifier()) # True (dar este un cuvânt cheie, deci nu este un identificator de *variabilă* valid)
print("variabila mea".isidentifier()) # Fals (conține un spațiu)

Notă: Deși isidentifier() verifică regulile pentru caractere și caracterele de început, nu verifică dacă șirul este un cuvânt cheie Python. Pentru a verifica cuvintele cheie, de obicei, utilizați funcția keyword.iskeyword() din modulul keyword împreună cu isidentifier().

Note: While isidentifier() checks the character and starting character rules, it does not check if the string is a Python keyword. To check for keywords, you would typically use the keyword.iskeyword() function from the keyword module in conjunction with isidentifier()

Python String islower() Method

Metoda .islower() din Python este o metodă încorporată pentru șiruri de caractere, utilizată pentru a verifica dacă toate caracterele dintr-un șir sunt minuscule. Returnează True dacă toate caracterele scrise din șir sunt minuscule și există cel puțin un caracter scris cu minuscule; în caz contrar, returnează False.

Caracteristici:
Verifică doar caracterele scrise cu minuscule.
Această metodă examinează în mod specific caracterele alfabetice (a-z, A-Z) pentru a le vedea dacă sunt scrise cu minuscule. Ignoră caracterele non-alfabetice, cum ar fi numerele, simbolurile, spațiile și semnele de punctuație.
Returnează False pentru șiruri goale.
Un șir gol nu conține caractere scrise cu minuscule, iar islower() va returna False.
Necesită cel puțin un caracter scris cu minuscule.
Dacă un șir conține doar numere, simboluri sau spații, islower() va returna False.

The .islower() method in Python is a built-in string method used to check if all cased characters within a string are lowercase. It returns True if all cased characters in the string are lowercase and there is at least one cased character; otherwise, it returns False.

Characteristics:
Checks cased characters only.
This method specifically examines alphabetic characters (a-z, A-Z) for their case. It ignores non-alphabetic characters such as numbers, symbols, spaces, and punctuation.
Returns False for empty strings.
An empty string does not contain any cased characters, and islower() will return False.
Requires at least one cased character.
If a string contains only numbers, symbols, or spaces, it will return False.
# True deoarece toate caracterele sunt scrise cu minuscule
print("salut lume!".islower())

# False deoarece 'S' este majusculă
print("Salut lume!".islower())

# True deoarece 'a', 'b', 'c' sunt minuscule, iar numerele/simbolurile sunt ignorate
print("abc123!".islower())

# False deoarece nu există caractere scrise cu minuscule
print("123!@#".islower())

# False deoarece șirul este gol
print("".islower())

Python String isnumeric() Method

Metoda .isnumeric() din Python este o metodă de tip șir de caractere utilizată pentru a determina dacă toate caracterele dintr-un șir sunt numerice. Returnează True dacă toate caracterele din șir sunt numerice și există cel puțin un caracter, iar False în caz contrar.

Caracteristici:
Caractere numerice: Recunoaște cifrele (0-9), precum și caracterele care au o valoare numerică Unicode, cum ar fi fracțiile (de exemplu, '½', '⅓'), exponentele (de exemplu, '²') și indicii.
Valoare returnată booleană: Metoda returnează o valoare booleană: Adevărat sau Fals.
Caractere non-numerice: Dacă șirul conține caractere non-numerice, inclusiv spații albe, litere, semne de punctuație sau simboluri speciale, isnumeric() va returna Fals.

Python String istitle() Method

.istitle() returnează True dacă șirul are cel puțin un caracter scris cu majuscule și respectă regulile de scriere cu majuscule pentru titlu. În caz contrar, returnează False.

Reguli de scriere cu majuscule pentru titlu:
Prima literă a fiecărui cuvânt din șir trebuie să fie majusculă.
Toate celelalte litere din fiecare cuvânt trebuie să fie minuscule.
Caracterele non-alfabetice (cum ar fi numerele, simbolurile și spațiile) sunt ignorate în această evaluare, dar acestea delimitează în continuare cuvintele.

.istitle() nu acceptă niciun parametru. Transmiterea oricărui argument către aceasta va genera o eroare TypeError.

.istitle() returns True if the string has at least one cased character and follows the title case rules. Otherwise, it returns False.

Title Case Rules:
The first letter of each word in the string must be an uppercase letter.
All other letters within each word must be lowercase letters.
Non-alphabetic characters (like numbers, symbols, and spaces) are ignored in this evaluation, but they still delimit words.

.istitle() method does not take any parameters. Passing any argument to it will result in a TypeError.

print("Salut lume".istitle()) # Fals (deoarece 'lume' nu este scris cu majuscule)

print("Python este Distractiv".istitle()) # Fals (deoarece 'este' nu este scris cu majuscule)
print("123 Un Titlu".istitle()) # True (numerele sunt ignorate la verificarea majusculelor)
