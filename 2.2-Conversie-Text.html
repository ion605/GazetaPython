Python oferă mai multe metode încorporate pentru conversia majusculelor/minusculelor șirurilor de caractere, permițând manipularea lor. Aceste metode returnează un nou șir de caractere cu majusculele și minusculele convertite, deoarece șirurile de caractere sunt imuabile în Python.

Notă: Pentru .lower(), .upper(), .title(), .capitalize(), .casefold(), swapcase() şirul de caractere trebuie să înceapă cu un caracter alfabetic.

Python offers several built-in string methods for case conversion, allowing strings' manipulation. These methods return a new string with the converted case, as strings are immutable in Python.

Note: For .lower(), .upper(), .title(), .capitalize(), .casefold(), swapcase() the string must start with an alphabetical character.

.lower(), .upper()

Returnează un șir nou cu toate caracterele convertite în majuscule sau minuscule.
Return a new string with all characters converted to lowercase or uppercase.

# Conversie de minuscule/majuscule
s = "Salut, lume"
print(s.lower())  ==> salut, lume
print(s.upper())  ==> SALUT, LUME

șirul = " Salut, lumea Python!"
print(șirul.lower())  ==> salut, lumea python!
print(șirul.upper())  ==> SALUT, LUMEA PYTHON!
Puncte cheie:
Ambele metode sunt utile pentru standardizarea textului pentru comparații, procesarea datelor sau prezentare. Se aplică direct unui obiect șir de caractere folosind notația punctuală.
Key Points:
Both methods are useful for standardizing text for comparisons, data processing, or presentation. They are applied directly to a string object using dot notation.

.title()

Sintaxă: șir.title()

Este o metodă de tip șir de caractere care returnează un șir nou în care prima literă a fiecărui cuvânt este scrisă cu literă mare, iar restul literelor sunt convertite în litere mici. Nu modifică șirul original.

Parametri:
Metoda title() nu acceptă niciun parametru.
Valoare returnată:
Returnează un șir nou cu formatarea specificată pentru titlu-majusculă.

Metoda title() identifică cuvintele din șir tratând caracterele non-alfabetice (inclusiv spații, cratime și apostrofuri) ca separatoare de cuvinte. Apoi scrie cu majusculă primul caracter alfabetic al fiecărui cuvânt identificat și convertește restul caracterelor din acel cuvânt în litere mici.

Is a string method that returns a new string where the first letter of each word is capitalized and the remaining letters are converted to lowercase. It does not modify the original string.

Parameters:
The title() method does not take any parameters.
Return Value:
It returns a new string with the specified title-case formatting.

The title() method identifies words within the string by treating non-alphabetic characters (including spaces, hyphens, and apostrophes) as word separators. It then capitalizes the first alphabetic character of each identified word and converts the rest of the characters in that word to lowercase.

text_şir = "salut lumea lui Python"
textul_titlu = text_şir.title()
print(textul_titlu)             ==> Salut Lumea Lui Python

# Şir cu majuscule si minuscule
text_şir2 = "aCeSTa Este un TeST"
titlu_text_şir2 = text_şir2.title()
print(titlu_text_şir2)          ==> Acesta Este Un Test

# Șir cu numere și simboluri
text_şir3 = "python 3.11 este grozav!"
titlu_text_şir3 = text_şir3.title()
print(titlu_text_şir3)          ==> Python 3.11 Este Grozav!

# Cuvinte separate prin caractere non-alfabetice
text_şir4 = "acesta-es#te 1*test"
titlu_text_şir4 = text_şir4.title()
print(titlu_text_şir4)          ==> Acesta-Es#Te 1*Test

.capitalize()

Sintaxă: șir.capitalize()

Este o metodă încorporată pentru șiruri de caractere care returnează o copie a șirului de caractere cu primul caracter scris cu literă mare și restul caracterelor convertite în litere mici.

Is a built-in string method that returns a copy of the string with its first character capitalized and the rest of the characters converted to lowercase.

text_capit = "salut lume."
text_cu_majusculă = text_capit.capitalize()
print(text_cu_majusculă) ==> Salut lume.

propoziție_capit = "salut lume! acesta este python."
propoziție_cu_litere_capitalizate = propoziție_capit.capitalize()
print(propoziție_cu_litere_capitalizate) ==> Salut lume! acesta este python.

alt_șir = "PYTHON ESTE DISTRACTIV!"
alt_șir_capitalizat = alt_șir.capitalize()
print(alt_șir_capitalizat) ==> Python este distractiv!
Considerații importante:
Afectează doar primul caracter: Metoda capitalize() scrie cu majusculă doar primul caracter al întregului șir, nu primul caracter al fiecărui cuvânt dintr-o propoziție. Pentru a scrie cu majusculă prima literă a fiecărui cuvânt, ați utiliza metoda title() sau o abordare personalizată care implică divizarea și reunirea șirului.
Returnează un șir nou: Metoda capitalize() nu modifică șirul original. În schimb, returnează un șir nou cu majusculă aplicată.
Gestionează primele caractere non-alfabetice: Dacă primul caracter al șirului nu este o literă (de exemplu, un număr, un simbol sau un spațiu), metoda returnează șirul original fără nicio modificare.
Primul caracter deja scris cu majusculă: Dacă primul caracter este deja scris cu majusculă, metoda returnează totuși un șir nou, dar acesta va fi identic cu șirul original. Restul caracterelor, însă, vor fi convertite în litere mici dacă erau inițial litere mari.
Important Considerations:
Only affects the first character: The capitalize() method only capitalizes the very first character of the entire string, not the first character of each word within a sentence. For capitalizing the first letter of every word, you would use the title() method or a custom approach involving splitting and rejoining the string.
Returns a new string: The capitalize() method does not modify the original string in place. Instead, it returns a new string with the capitalization applied.
Handles non-alphabetic first characters: If the first character of the string is not an alphabet (e.g., a number, symbol, or space), the method returns the original string without any changes.
Already capitalized first character: If the first character is already uppercase, the method still returns a new string, but it will be identical to the original string. The rest of the characters, however, will still be converted to lowercase if they were originally uppercase.

.casefold()

Este o metodă de șir de caractere care returnează o versiune a unui șir de caractere cu majuscule/minuscule. Aceasta înseamnă că, convertește toate caracterele din șir în echivalentul lor cu minuscule, ceea ce reprezintă o formă mai agresivă și mai cuprinzătoare de utilizare a literelor mici în comparație cu metoda standard lower().

Caracteristici:
Comparații fără sensibilitate la majuscule/minuscule: Scopul său principal este de a facilita comparații fiabile de șiruri de caractere fără sensibilitate la majuscule/minuscule, în special atunci când se lucrează cu diverse caractere Unicode și diferite limbi.
Respectă Unicode: Gestionează o gamă mai largă de caractere dincolo de ASCII de bază, inclusiv cele cu reguli unice de utilizare a literelor mici în diferite limbi.
Utilizare agresivă a literelor mici: Scopul său este de a elimina toate distincțiile de majuscule/minuscule, convertind caracterele în echivalentul lor "minuscule" decât lower().
Returnează un șir nou:Ca majoritatea metodelor de șir de caractere, casefold() nu modifică șirul original, ci returnează un șir nou cu minuscule.
Fără parametri: Metoda nu acceptă argumente.

Is a string method that returns a case-folded version of a string. This means it converts all characters in the string to their case-folded equivalent, which is a more aggressive and comprehensive form of lowercasing compared to the standard lower() method.

Characteristics:
Case-insensitive comparisons: Its primary purpose is to facilitate reliable case-insensitive string comparisons, especially when dealing with various Unicode characters and different languages.
Unicode-aware: It handles a broader range of characters beyond basic ASCII, including those with unique casing rules in different languages.
Aggressive lowercasing: It aims to remove all case distinctions, converting more characters to their "lowercase" equivalent than lower().
Returns a new string: Like most string methods, casefold() does not modify the original string but returns a new string with the case-folded characters.
No parameters:The method does not take any arguments.
text_fold1 = "Salut, lume"
text_fold2 = "SALUT, LUME"
text_fold3 = "Stradă"
text_fold4 = "STRADĂ"

print(text_fold1.casefold()) ==> salut, lume
print(text_fold2.casefold()) ==> salut, lume
print(text_fold3.casefold()) ==> stradă
print(text_fold4.casefold()) ==> stradă

# Comparație folosind casefold()
if text_fold3.casefold() == text_fold4.casefold():
    print("Șirurile sunt egale după casefolding.")    ==> Șirurile sunt egale după casefolding.
else:
    print("Șirurile nu sunt egale după casefolding.")

swapcase()

Sintaxă: șir.swapcase()

Este o metodă încorporată pentru șiruri care returnează o copie în care toate caracterele majuscule sunt convertite în minuscule, iar toate caracterele minuscule sunt convertite în majuscule. Caracterele non-alfabetice (numere, simboluri, spații) rămân neschimbate.

Cum funcționează:
Iterează prin fiecare caracter din șirul original.
Dacă un caracter este o literă mare, îl convertește în echivalentul său cu litere mici.
Dacă un caracter este o literă mică, îl convertește în echivalentul său cu litere mari.
Dacă un caracter nu este o literă, rămâne așa cum este.
Apoi returnează un nou șir cu aceste modificări de majuscule/minuscule; șirul original nu este modificat, deoarece șirurile în Python sunt imuabile.

Is a built-in string method that returns a copy of a string where all uppercase characters are converted to lowercase, and all lowercase characters are converted to uppercase. Non-alphabetic characters (numbers, symbols, spaces) remain unchanged.

How it works:
It iterates through each character in the original string.
If a character is an uppercase letter, it converts it to its lowercase equivalent.
If a character is a lowercase letter, it converts it to its uppercase equivalent.
If a character is not a letter, it remains as is.
It then returns a new string with these case changes; the original string is not modified, as strings in Python are immutable.
text_swap = "SaLUT, lUmE"
text_case_schimbate = text_swap.swapcase()
print(text_case_schimbate)                 ==> sAlut, LuMe

șir = "Salut, Lume 123!"
șir_interschimbat = șir.swapcase()
print(șir_interschimbat)                   ==> sALUT, lUME 123!

alt_șir_swap = "pYThoN"
altul_schimbat = alt_șir_swap.swapcase()
print(altul_schimbat)                      ==> PytHOn

.encode()

Sintaxă: şir.encode(encoding='utf-8', errors='strict')

În Python, metoda encode() a unui șir de caractere convertește un șir Unicode într-o secvență de octeți folosind o codificare specificată.

encoding: Acest parametru opțional specifică codificarea care va fi utilizată. Dacă este omis, UTF-8 este valoarea implicită. Codificările comune includ 'utf-8', 'ascii', 'latin-1', 'utf-16' etc.

Argumentul errors din cadrul metodei encode() specifică modul de gestionare a caracterelor care nu pot fi codificate de codificarea aleasă. Argumentul errors controlează comportamentul atunci când un caracter din șir nu poate fi reprezentat în codificarea țintă.

In Python, the encode() method of a string converts a Unicode string into a sequence of bytes using a specified encoding.

encoding: This optional parameter specifies the encoding to be used. If omitted, UTF-8 is the default. Common encodings include 'utf-8', 'ascii', 'latin-1', 'utf-16', etc.

The errors argument within the encode() method specifies how to handle characters that cannot be encoded by the chosen encoding. The errors argument controls the behavior when a character in the string cannot be represented in the target encoding.

Valori de eroare comune în python encode()
python encode() Common error values

strict (implicit):
Aceasta generează o eroare UnicodeEncodeError dacă întâlnește un caracter necodificabil. Aceasta este cea mai sigură opțiune, deoarece vă avertizează imediat asupra unei potențiale pierderi sau coruperi de date.
strict (default):
This raises a UnicodeEncodeError if an unencodable character is encountered. This is the safest option as it immediately alerts you to potential data loss or corruption.
# Codificarea unui șir simplu în UTF-8 (implicit)
text = "Salut, lume!"
octeți_codificați = text.encode()

print(f"Șir original: {text}")                                  ==> Șir original: Salut, lume!
print(f"Octeți codificați (UTF-8): {octeți_codificați}")        ==> Octeți codificați (UTF-8): b'Salut, lume!'
print(f"Tipul de octeți codificați: {type(octeți_codificați)}") ==> Tipul de octeți codificați: <class 'bytes'>

# Codificarea unui șir de caractere cu un caracter special într-o codificare specifică
şir = "stradă!"
try:
    şir_codificat = şir.encode(encoding='latin-1')
except UnicodeEncodeError as e:
    print(f"Eroare: {e}")

==> Eroare: 'latin-1' codec can't encode character '\u0103' in position 5: ordinal not in range(256)

# Folosirea parametrului strict'(va genera o eroare UnicodeEncodeError)
şir = "Salut, lume! 😊"
try:
    şir_codificat = şir.encode('ascii', errors='strict')
except UnicodeEncodeError as e:
    print(f"Eroare: {e}")

==> Eroare: 'ascii' codec can't encode character '\U0001f60a' in position 13: ordinal not in range(128)
ignora
Caracterele care nu pot fi codificate sunt pur și simplu evitate și omise din secvența de octeți rezultată. Acest lucru poate duce la pierderea de date fără nicio eroare explicită.
ignore
Characters that cannot be encoded are simply skipped and omitted from the resulting byte sequence. This can lead to data loss without any explicit error.
şir = "Salut, lume! 😊"
şir_codificat_ignor = şir.encode('ascii', errors='ignore')
print(şir_codificat_ignor)  ==> b'Salut, lume! '
înlocui
Caracterele necodificabile sunt înlocuite cu un caracter de înlocuire (de obicei, un semn de întrebare ? sau un provizoriu similar) în codificarea țintă. Aceasta indică faptul că datele au fost pierdute, dar se păstrează lungimea șirului.
replace
Unencodable characters are replaced with a replacement character (usually a question mark ? or a similar placeholder) in the target encoding. This indicates that data was lost but maintains the length of the string. 
# Gestionarea erorilor de codificare cu replace
text_cu_erori = "Acest text conține 2 caractere necodificabile:  😊"
caractere_înlocuite = text_cu_erori.encode('ascii', errors='replace')

print(f"Șir original: {text_cu_erori}") 
==> Șir original: Acest text conține 2 caractere necodificabile:  😊

print(f"Octeți codificați (ASCII cu 'replace'): {caractere_înlocuite}") 
==> Octeți codificați (ASCII cu 'replace'): b'Acest text con?ine 2 caractere necodificabile:  ?'
xmlcharrefreplace
xmlcharrefreplace: Caracterele necodificabile sunt înlocuite cu referințe de caractere XML (de exemplu, 😄 pentru emoji-ul cu fața zâmbitoare). Acest lucru este util la generarea de ieșiri XML sau HTML.
xmlcharrefreplace
xmlcharrefreplace: Unencodable characters are replaced by XML character references (e.g., 😄 for the smiling face emoji). This is useful when generating XML or HTML output.
şir = "Salut, lume! 😊"
şir_codificat_xml = şir.encode('ascii', errors='xmlcharrefreplace')
print(şir_codificat_xml) ==> b'Salut, lume! &#128516;'
backslashreplace
Caracterele necodificabile sunt înlocuite cu secvențele de escape backslash din Python (de exemplu, \U0001f60a pentru emoji-ul cu fața zâmbitoare). Această funcție este adesea folosită pentru repareare sau atunci când aveți nevoie de o reprezentare imprimabilă a caracterului necodificabil.
backslashreplace
Unencodable characters are replaced by Python's backslash escape sequences (e.g., \U0001f60a for the smiling face emoji). This is often used for debugging or when you need a printable representation of the unencodable character.
şir = "Salut, lume! 😊"
şir_codificat_backslash = şir.encode('ascii', errors='backslashreplace')
print(şir_codificat_backslash) ==> b'Salut, lume! \\U0001f60a'

Alegerea strategiei adecvate de gestionare a erorilor depinde de cerințele specifice ale aplicației dvs. și de modul în care doriți să gestionați datele care nu pot fi reprezentate în codificarea aleasă.

Choosing the appropriate errors handling strategy depends on the specific requirements of your application and how you want to manage data that cannot be represented in the chosen encoding.

Pentru a converti o listă într-un șir de caractere, cele mai comune și eficiente metode sunt str.join() și map(). Aceste metode concatenează elementele unui iterabil (cum ar fi o listă) într-un singur șir de caractere, folosind un șir ca separator aplicat funcției join().

To convert a list to a string, the most common and efficient methods are str.join() and map(). This methods concatenates the elements of an iterable (like a list) into a single string, using a string on which join() is called as a separator.

.join() pentru liste de șiruri de caractere:
.join() for lists of strings: 

fructe = ["mere", "pere", "cireșe", "caise"]

separator = ", "
șir_fructe = separator.join(fructe)
print(șir_fructe)  ==> mere, pere, cireșe, caise

separator2 = " "
șir_fructe2 = separator2.join(fructe)
print(șir_fructe2) ==> mere pere cireșe caise
.join() pentru liste care conțin elemente care nu sunt șiruri de caractere (de exemplu, numere):
Dacă lista conține elemente care nu sunt șiruri de caractere (cum ar fi numere întregi sau alte tipuri de date), trebuie să le convertiți în șiruri de caractere înainte de a utiliza join(). Acest lucru se poate face eficient cu o expresie generatoare sau map().
.join() for lists containing non-string elements (e.g., numbers):
If your list contains elements that are not strings (like integers or other data types), you need to convert them to strings before using join(). This can be done efficiently with a generator expression or map(). 
numere = [1, 2, 3, 4, 5]
separator = "-"
șir_numere = separator.join(map(str, numere))

print(șir_numere)  ==> 1-2-3-4-5

Utilizarea unei expresii generatoare: Aceasta este adesea cea mai lizibilă și "Pythonic" abordare pentru listele de tip mixt.

Using a generator expression: This is often the most readable and "Pythonic" approach for mixed-type lists.

listă_mixtă = ['Ultimele', 'patru', 'cifre', 'ale', 'numărului', 'de', 'telefon', ':', 7936]

# Convertește fiecare element într-un șir de caractere și unește-l cu spații
rezultat = ' '.join(str(item) for item in listă_mixtă)

print(rezultat)  ==> Ultimele patru cifre ale numărului de telefon : 7936

Buclare și concatenare: Puteți itera prin listă și construi șirul prin concatenarea elementelor. Acest lucru este mai puțin eficient pentru listele mari.

Looping and concatenation: You can iterate through the list and build the string by concatenating elements. This is less efficient for large lists. 

litere = ["a", "b", "c"]
șir_rezultat = ""
for literă in litere:
    șir_rezultat += literă

print(șir_rezultat) ==> abc

Conversia str() a întregii liste: Aceasta convertește lista însăși în reprezentarea sa sub formă de șir de caractere, inclusiv parantezele și virgulele.

str() conversion of the whole list: This converts the list itself into its string representation, including the brackets and commas.

lucruri = ["uşă", "vază", "pocal", "polonic", "rindea"]
reprezentare_șir = str(lucruri)

print(f"{lucruri} / {type(lucruri)}")  
==> ['uşă', 'vază', 'pocal', 'polonic', 'rindea'] / <class 'list'>

print(f"{reprezentare_șir} / {type(reprezentare_șir)}") 
==> ['uşă', 'vază', 'pocal', 'polonic', 'rindea'] / <class 'str'>
Ce metodă ar trebui să alegeți?
Pentru liste de șiruri de caractere: Folosiți sintaxa simplă separator.join(listă_de_șiruri). Este cea mai eficientă și directă abordare.
Pentru liste cu tipuri mixte: Folosiți separator.join(str(item) for item in listă_mixtă). Este o soluție curată, pe o singură linie, care se ocupă de conversie.
Pentru o reprezentare simplă: Dacă doriți pur și simplu reprezentarea sub formă de șir a listei în sine, completă cu paranteze și virgule, puteți utiliza funcția str() încorporată, deși aceasta este mai puțin comună.
Which method should you choose?
For lists of strings: Use the simple separator.join(list_of_strings) syntax. It's the most efficient and direct approach.
For lists with mixed types: Use separator.join(str(item) for item in mixed_list). It's a clean, single-line solution that handles the conversion for you.
For simple representation: If you simply want the string representation of the list itself, complete with brackets and commas, you can use the built-in str() function, though this is less common.

În Python, JSON (JavaScript Object Notation) este un format ușor de schimb de date, gestionat prin intermediul modulului bibliotecii standard json încorporat. Acesta vă permite să analizați răspunsurile API-ului web, să stocați configurații și să convertiți structurile de date Python în șiruri de text simplu pentru transfer în rețea.

Utilizarea funcției json.dumps(): Pentru convertirea unui dicționar într-un șir de caractere formatat JSON, utilă în special atunci când se lucrează cu API-uri sau aplicații web, se preferă utilizarea funcției json.dumps().

In Python, JSON (JavaScript Object Notation) is a lightweight data interchange format handled through the built-in json standard library module. It allows you to parse web API responses, store configurations, and convert Python data structures into plain-text strings for network transfer.

Using json.dumps(): For converting a dictionary into a JSON-formatted string, especially useful when working with APIs or web applications, the json.dumps() function is preferred.

Utilizarea unei bucle și a șirurilor f pentru formatare personalizată: Această metodă oferă mai mult control asupra formatului șirului prin iterarea listei și construirea șirului cu f-șiruri.

Using a loop and f-strings for custom formatting: This method offers more control over the string format by iterating through the list and building the string with f-strings.

date_personale = [
    {"nume": "Virgil", "vârstă": 85, "oraş": "Turnu Severin"},
    {"nume": "Tatiana", "vârstă": 75, "oraş": "Craiova"},
    {"nume": "Sever", "vârstă": 81, "oraş": "Hunedoara"}
]
rezultat = ""
for dicţionar in date_personale:
    rezultat += f"Nume: {dicţionar['nume']}, Vârsta: {dicţionar['vârstă']}, Oras: {dicţionar['oraş']}\n"
print(rezultat)

==> Nume: Virgil, Vârsta: 85, Oras: Turnu Severin
    Nume: Tatiana, Vârsta: 75, Oras: Craiova
    Nume: Sever, Vârsta: 81, Oras: Hunedoara
