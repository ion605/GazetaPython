ASCII (American Standard Code for Information Interchange) în Python se referă la interacțiunea cu acest standard de codificare a caracterelor în cadrul limbajului de programare Python. ASCII este un standard de codificare a caracterelor pe 7 biți care reprezintă 128 de caractere, inclusiv litere, cifre, semne de punctuație și caractere de control din limba engleză.

ASCII (American Standard Code for Information Interchange) in Python refers to the interaction with this character encoding standard within the Python programming language. ASCII is a 7-bit character encoding standard that represents 128 characters, including English letters, digits, punctuation marks, and control characters.

funcţia ord() - ord() function

ord() built-in function returnează valoarea întreagă ASCII (sau punctul de cod Unicode) a unui anumit caracter.

ord() built-in function returns the integer ASCII value (or Unicode code point) of a given character.

Caracteristici:
Intrare: Acceptă un șir de caractere de lungime unu, reprezentând un singur caracter.
Ieșire: Returnează un număr întreg, care este punctul de cod Unicode al caracterului de intrare.
Scop: Elimină decalajul dintre caractere și reprezentarea lor numerică, util pentru sarcini care implică codificarea caracterelor, manipularea sau înțelegerea valorilor numerice subiacente ale caracterelor.
Inversa funcției chr(): Funcția ord() este inversa funcției chr(), care preia un punct de cod întreg și returnează caracterul corespunzător.
Characteristics:
Input: It accepts a string of length one, representing a single character.
Output: It returns an integer, which is the Unicode code point of the input character.
Purpose: It bridges the gap between characters and their numerical representation, useful for tasks involving character encoding, manipulation, or understanding the underlying numerical values of characters.
Inverse of chr(): The ord() function is the inverse of the chr() function, which takes an integer code point and returns the corresponding character.
text = "Salut"
for literă in text:
    print(f"Numărul de cod Unicode pentru '{literă}' este: {ord(literă)}")
==> Numărul de cod Unicode pentru 'S' este: 83
    Numărul de cod Unicode pentru 'a' este: 97
    Numărul de cod Unicode pentru 'l' este: 108
    Numărul de cod Unicode pentru 'u' este: 117
    Numărul de cod Unicode pentru 't' este: 116

print(ord('A'))  ==> 65
print(ord('p'))  ==> 112
print(ord('~'))  ==> 126
print(ord('!'))  ==> 33
print(ord('€'))  ==> 8364  # Unicode for Euro sign
print(ord('\n')) ==> 10    # Caracter new line

Conversia unui șir întreg într-o listă de valori ASCII - Converting an entire string to a list of ASCII values

şir = "salut"
listă = [ord(caracter) for caracter in şir]
print(listă)
==> [115, 97, 108, 117, 116]

Notă: Dacă furnizați un șir de caractere cu o lungime mai mare decât unu pentru ord(), aceasta va genera o eroare TypeError.
Note: If you provide a string with a length greater than one to ord(), it will raise a TypeError.

try:
    print(ord("AB"))
except TypeError as e:
    print(f"Error: {e}")
==> Error: ord() expected a character, but string of length 2 found
Aplicații:
Codarea și decodificarea caracterelor: Utilă pentru convertirea caracterelor în reprezentarea lor numerică pentru procesare, stocare sau transmitere.
Algoritmi de criptare: Pot fi utilizați în algoritmi care se bazează pe valorile numerice ale caracterelor.
Validarea datelor: Poate ajuta la validarea caracterelor introduse pe baza valorilor Unicode, verificând dacă punctul de cod al unui caracter se încadrează într-un anumit interval (de exemplu, asigurarea faptului că un caracter este o literă majusculă prin verificarea dacă punctul său de cod este cuprins între 65 și 90).
Manipularea caracterelor: Efectuarea de operații aritmetice asupra caracterelor folosind valorile lor întregi.
Applications:
Character encoding and decoding: Useful for converting characters to their numerical representation for processing, storage or transmission.
Encryption algorithms: Can be used in algorithms that rely on numerical values of characters.
Data validation: Can help in validating character inputs based on their Unicode values, checking if a character's code point falls within a specific range (e.g., ensuring a character is an uppercase letter by checking if its code point is between 65 and 90).
Character manipulation: Performing arithmetic operations on characters by using their integer values.
def validare_utilizator(nume_util):
    if not isinstance(nume_util, str):
        return f"Numele de utilizator trebuie să fie un șir de caractere: {nume_util}"
    if not (6 <= len(nume_util) <= 18):
        return f"Numele utilizatorului trebuie să aibă între 6 și 18 caractere: '{nume_util}'"
    
    for caracter in nume_util:
        # Verificați dacă, caracterul este alfanumeric sau o subliniere
        if not (48 <= ord(caracter) <= 57 or  # Cifre (0-9)
                65 <= ord(caracter) <= 90 or  # Litere mari (A-Z)
                97 <= ord(caracter) <= 122 or # Litere mici (a-z)
                ord(caracter) == 95):               # Subliniere (_)
            return f"Invalid character '{caracter}' în numele utilizatorului: '{nume_util}'"
    return f"Numele utilizatorului este valid: '{nume_util}'"

# Exemple
validare1 = validare_utilizator("user_name123")
print(validare1) ==> Numele utilizatorului este valid: 'user_name123'

validare2 = validare_utilizator("user!")
print(validare2) ==> Numele utilizatorului trebuie să aibă între 6 și 18 caractere: 'user!'

validare3 = validare_utilizator("nume_user3!")
print(validare3) ==> Invalid character '!' în numele utilizatorului: 'nume_user3!'
Considerații:
Deși ord() este eficient pentru validarea la nivel de caracter, pentru potrivirea unor modele mai complexe, expresiile regulate (folosind modulul re) oferă adesea o soluție mai concisă și mai puternică. Cu toate acestea, ord() oferă o modalitate fundamentală de a inspecta și valida caractere individuale pe baza reprezentării lor numerice.
Considerations:
While ord() is effective for character-level validation, for more complex pattern matching, regular expressions (using the re module) often provide a more concise and powerful solution. However, ord() offers a fundamental way to inspect and validate individual characters based on their numerical representation.

funcţia chr() - chr() function

chr() built-in function este inversa funcției ord(). Preia o valoare întreagă ASCII (sau un punct de cod Unicode) și returnează caracterul corespunzător.

chr() built-in function is the inverse of ord(). It takes an integer ASCII value (or Unicode code point) and returns the corresponding character.

print(chr(65))  ==> A
print(chr(90))  ==> Z
print(chr(112)) ==> p
print(chr(126)) ==> ~
print(chr(33))  ==> !

Conversia unei liste de valori ASCII înapoi într-un șir de caractere.
Converting a list of ASCII values back to a string.

listă_ascii = [115, 97, 108, 117, 116]
şir_listă = "".join([chr(valoare) for valoare in listă_ascii])
print(şir_listă) ==> salut


# Exemplu folosind ord() și chr() împreună
caracter = 'B'
punct_cod = ord(caracter)

caracter_convertit = chr(punct_cod)

Cazuri de utilizare comune
Validarea datelor: Verificarea dacă un caracter se încadrează într-un interval specific (de exemplu, verificarea dacă un caracter este o literă mare prin verificarea faptului că punctul său de cod este între 65 și 90).
Criptografie simplă: Implementarea cifrurilor de bază, cum ar fi cifrul Caesar, prin deplasarea valorilor numerice ale caracterelor.
Manipularea caracterelor: Efectuarea de operațiuni asupra valorilor numerice ale caracterelor care ar fi dificil de realizat direct cu șiruri de caractere.
Common Use Cases.
Data Validation: Checking if a character falls within a specific range (e.g., checking if a character is an uppercase letter by verifying its code point is between 65 and 90).
Simple Cryptography: Implementing basic ciphers like the Caesar cipher by shifting the numerical values of characters.
Character Manipulation: Performing operations on the numerical values of characters that would be difficult to do directly with strings.

Aplicație pentru ord() și chr()
Application for ord() and chr()

def cifrarea_textului(text, schimb):
    text_cifrat = ""
    # Asigurați-vă că schimbarea este în intervalul 0-25
    schimb %= 26
    for caracter in text:
        if 'a' <= caracter <= 'z':
            # Convertește caracterul în numărul său de cod Unicode
            caracter_cod = ord(caracter)
            # Aplică schimb, înfășurând literele în jurul alfabetului
            schimbat_cod = ((caracter_cod - ord('a') + schimb)% 26) + ord('a')
            # Convertește noul punct de cod înapoi într-un caracter
            text_cifrat += chr(schimbat_cod)
        elif 'A' <= caracter <= 'Z':
            caracter_cod = ord(caracter)
            schimbat_cod = ((caracter_cod - ord('A') + schimb)% 26) + ord('A')
            text_cifrat += chr(schimbat_cod)
        else:
            # Păstrează caracterele non-alfabetice neschimbate
            text_cifrat += caracter
    return text_cifrat

def descifrare(text, schimb):
    # Descifrarea este pur și simplu o cifrare cu o deplasare negativă
    return cifrarea_textului(text, -schimb)

# Exemplu de utilizare
mesaj = "Am trimis un mesaj cifrat!"
schimb_valoare = 3

mesaj_cifrat = cifrarea_textului(mesaj, schimb_valoare)
print(f"Mesaj original: {mesaj}")       ==> Mesaj original: Am trimis un mesaj cifrat!
print(f"Mesaj cifrat: {mesaj_cifrat }") ==> Mesaj cifrat: Dp wulplv xq phvdm fliudw!

descifrare_mesaj = descifrare(mesaj_cifrat , schimb_valoare)
print(f"Mesaj descifrat: {descifrare_mesaj}")  ==> Mesaj descifrat: Am trimis un mesaj cifrat!
Explicația codului:
ord(char): funcția Python încorporată convertește fiecare caracter într-o valoare întreagă pentru un anumit caracter.
Operatorul Modulo (% 26): efectul de înfășurare al cifrului. Când o literă deplasată trece de "z" sau "Z", operația modulo asigură că revine la "a" sau "A".
chr(value): funcția Python încorporată convertește numărul întreg modificat înapoi în caracterul corespunzător, formând ieșirea cifrată.
Caractere non-alfabetice: Blocul else asigură că numerele, spațiile, semnele de punctuație și alte caractere sunt incluse în textul cifrat fără a fi modificate.
Decodificarea inversează acest proces prin aplicarea unei deplasări negative.
Explanation of the Code
ord(char): built-in Python function converts each character to integer value for a given character.
Modulo Operator (% 26): wraparound effect of the cipher. When a shifted letter goes past 'z' or 'Z', the modulo operation ensures it loops back to 'a' or 'A'.
chr(value): built-in Python function converts the modified integer back into its corresponding character, forming the encrypted output.
Non-Alphabetic Characters: The else block ensures that numbers, spaces, punctuation, other characters are included in the encrypted text without being modified.
Decryption reverses this process by applying a negative shift.

funcţia ascii() - ascii() function

ascii() built-in function returnează o reprezentare imprimabilă a unui obiect, eliminând caracterele non-ASCII folosind caracterele de escape \x, \u sau \U. Acest lucru este util pentru reprezentarea obiectelor într-un mod compatibil cu ASCII.

ascii() built-in function returns a printable representation of an object, escaping non-ASCII characters using \x, \u, or \U escapes. This is useful for representing objects in a way that is compatible with ASCII.

print(ascii("Pythön este interesant")) ==> 'Pyth\xf6n este interesant'
fruct = "măr"
print(ascii(fruct)) ==> 'm\u0103r'

# ascii() pe o listă
listă = ["Salut", "în", 5, "minute"]
print(ascii(listă))   ==> ['Salut', '\xeen', 5, 'minute']

.isascii() string method checks if all characters in a string belong to the ASCII character set. It returns True if all characters are ASCII, and False otherwise.

print("salut".isascii()) ==> True
print("Bacău".isascii()) ==> False

.ascii_letters constant from the string module is a string containing all uppercase and lowercase ASCII letters.

metoda encode() - encode() method

Obiectele șir de caractere din Python au o metodă encode() care poate fi utilizată pentru a converti un șir de caractere într-o secvență de octeți folosind o codificare specificată. Pentru a codifica un șir de caractere în ASCII, puteți transmite 'ascii' ca argument.

String objects in Python have an encode() method that can be used to convert a string into a sequence of bytes using a specified encoding. To encode a string into ASCII, you can pass 'ascii' as the argument.

text = "Salut, lume!"
ascii_codificat = text.encode('ascii')
print(ascii_codificat)  ==> b'Salut, lume!'

Deși ASCII este o codificare fundamentală, Python și sistemele moderne utilizează în principal Unicode (și implementările sale, cum ar fi UTF-8) pentru un suport mai larg pentru caractere, deoarece ASCII acoperă doar un set limitat de caractere. Cu toate acestea, înțelegerea ASCII și a interacțiunii sale cu Python este esențială pentru lucrul cu sisteme vechi, protocoale de rețea specifice și sarcini de procesare a textului în care este necesară compatibilitatea ASCII.

While ASCII is a fundamental encoding, Python and modern systems primarily use Unicode (and its implementations like UTF-8) for broader character support, as ASCII only covers a limited set of characters. However, understanding ASCII and its interaction with Python is essential for working with legacy systems, specific network protocols, and text processing tasks where ASCII compatibility is required.
