Indexarea și felierea șirurilor de caractere sunt metode utilizate pentru a accesa caractere specifice sau părți ale unui șir de caractere în multe limbaje de programare. Indexarea preia un singur caracter, în timp ce felierea extrage un subșir sau o secvență de caractere.

String indexing and slicing are methods used to access specific characters or parts of a string in many programming languages. Indexing retrieves a single character, while slicing extracts a substring, or a sequence of characters.

Indexarea șirurilor - Indexing strings

Indexarea
Permite să accesați un caracter individual dintr-un șir de caractere după poziția sa numerică sau indice.
Șirurile de caractere sunt secvențe ordonate, iar fiecărui caracter i se atribuie un indice numeric.
Indexarea pozitivă începe de la 0 pentru primul caracter și crește cu unu pentru fiecare caracter ulterior.
Indexarea negativă numără invers de la sfârșitul șirului de caractere. Indexul -1 se referă la ultimul caracter, -2 la penultimul și așa mai departe.
Sintaxă: Folosiți paranteze pătrate [] cu numărul de indice pentru a preia un caracter: şirul_meu[indice].
Indexing
Allows you to access an individual character in a string by its numerical position, or index.
Strings are ordered sequences, and each character is assigned a numerical index.
Positive indexing begins at 0 for the first character and increases by one for each subsequent character.
Negative indexing counts backward from the end of the string. The index -1 refers to the last character, -2 to the second-to-last, and so on.
Syntax: Use square brackets [] with the index number to retrieve a character: my_string[index].

Sintaxă: șir[indice]

# Indexare pozitivă
cuvânt = "Python"
print(cuvânt[0]) ==> P
print(cuvânt[3]) ==> h

# Indexare negativă
print(cuvânt[-1]) ==> n
print(cuvânt[-3]) ==> h
IndexError:
Încercarea de a accesa un index care se află în afara intervalului valid al șirului (de exemplu, un index mai mare sau egal cu lungimea șirului sau un index negativ mai mic decât lungimea negativă) va duce la o eroare IndexError.
IndexError:
Attempting to access an index that is outside the valid range of the string (e.g., an index greater than or equal to the string's length, or a negative index smaller than the negative length) will result in an IndexError.
cuvânt = "Python"
print(cuvânt[6])
==> IndexError: string index out of range

Felierea șirurilor - Slicing strings

Sintaxă: şir[start:end:step]

Secționarea
Extrage o secvență de caractere dintr-un șir de caractere. Este o modalitate puternică de a obține subșiruri prin specificarea unui interval de indici.
start: Indicele unde începe felia (inclusiv). Dacă este omisă, implicit va fi începutul șirului de caractere.
end: Indicele unde se termină felia (exclusiv). Dacă este omisă, implicit va fi sfârșitul șirului de caractere.
step: Numărul de caractere de omis. Dacă este omisă, implicit va fi 1.
Slicing
Extracts a sequence of characters from a string. It is a powerful way to get substrings by specifying a range of indices
start: The index where the slice begins (inclusive). If omitted, it defaults to the start of the string.
end: The index where the slice ends (exclusive). If omitted, it defaults to the end of the string.
step: The number of characters to skip. If omitted, it defaults to 1.
șirul = "Salut, Lume!"

# Secționare de bază: de la indexul 0 la 4 (exclusiv)
subșir1 = șirul[0:5]

# Secționare de la început la un index specific
subșir2 = șirul[:5] 

# Secționare de la un index specific până la sfârșit
subșir3 = șirul[7:]

# Secționare cu un pas
subșir4 = șirul[::2]

# Utilizarea indicilor negativi (numărând de la sfârșit)
subșir5 = șirul[-6:-1]

print(subșir1) ==> Salut
print(subșir2) ==> Salut
print(subșir3) ==> Lume!
print(subșir4) ==> Slt ue
print(subșir5) ==> Lume
Puncte cheie:
Separarea șirurilor de caractere creează un șir nou; șirul original rămâne neschimbat.
Indicele de oprire este întotdeauna exclusiv.
Indicii negativi se numără de la sfârșitul șirului de caractere, -1 fiind ultimul caracter.
Key Points:
String slicing creates a new string; the original string remains unchanged.
The stop index is always exclusive.
Negative indices count from the end of the string, with -1 being the last character.

slice()

slice() este o funcție încorporată care returnează un obiect felie. Acest obiect reprezintă un set de indici utilizați pentru a extrage o porțiune (sau "felie") dintr-o secvență, cum ar fi un șir de caractere, o listă sau un tuplu.

slice() is a built-in function that returns a slice object. This object represents a set of indices used to extract a portion (or "slice") of a sequence, such as a string, list, or tuple.

Sintaxă: slice(start, end, step)

Parametri:
start (opțional): Indexul de început pentru felie. Dacă este omis, implicit va fi începutul secvenței (index 0).
stop: Indexul de sfârșit pentru felie. Elementul de la acest index nu este inclus în felie.
step (opțional): Incrementul dintre fiecare index pentru feliere. Dacă este omis, implicit va fi 1. O valoare negativă a pasului poate fi utilizată pentru felierea inversă.
Valoare returnată:
Funcția slice() returnează un obiect slice. Acest obiect poate fi apoi utilizat cu notația paranteză pătrată [] pentru a felia o secvență.
Parameters:
start (optional): The starting index for the slice. If omitted, it defaults to the beginning of the sequence (index 0).
stop: The ending index for the slice. The element at this index is not included in the slice.
step (optional): The increment between each index for slicing. If omitted, it defaults to 1. A negative step value can be used to slice in reverse.
Return Value:
The slice() function returns a slice object. This object can then be used with the square bracket [] notation to slice a sequence.
nume = ["Cristina", "Andrei", "Mihai", "Vasile", "Alexandru", "Elena", "Ioana", "Costel", "Eugenia"]

# Creați un obiect slice pentru a obține elemente de la indicele 1 (inclusiv) până la 6 (exclusiv), cu un pas 2
felie = slice(1, 6, 2)
# Aplică obiectul felie listei
listă_feliată = nume[felie]
print(listă_feliată)        ==> ['Andrei', 'Vasile', 'Elena']
Utilizare comună
Deși felierea directă cu [start:stop:step] este mai frecventă pentru cazuri simple, funcția slice() este utilă atunci când trebuie să:
Stocați o definiție de felie într-o variabilă pentru reutilizare ulterioară.
Transmiteți o definiție de felie ca argument pentru o funcție sau metodă.
Construiți dinamic obiecte felie pe baza anumitor condiții.
Common Usage
While direct slicing with [start:stop:step] is more common for simple cases, the slice() function is useful when you need to:
Store a slice definition in a variable for later reuse.
Pass a slice definition as an argument to a function or method.
Dynamically construct slice objects based on certain conditions.

Inversarea șirurilor - Reversing Strings

Inversarea cu un pas negativ

Aceasta este metoda cea mai concisă și mai frecvent utilizată.
This is the most concise and commonly used method.

nume = ["Cristina", "Andrei", "Mihai", "Vasile", "Alexandru", "Elena", "Ioana", "Costel", "Eugenia"]
# utilizarea unui obiect felie pentru inversare
felie_inversă = slice(None, None, -1)
listă_inversată = nume[felie_inversă]
print(listă_inversată) ==> ['Eugenia', 'Costel', 'Ioana', 'Elena', 'Alexandru', 'Vasile', 'Mihai', 'Andrei', 'Cristina']

șir_original = "salut"
șir_inversat = șir_original[::-1]
print(șir_inversat)  ==> tulas
Pas cu pas pentru [::-1]
Sintaxa generală pentru felierea în Python este string[start:stop:step]. Când utilizați [::-1], fiecare parte a sintaxei este interpretată după cum urmează:
: (Primele două puncte): Aceste două puncte indică începutul feliei. Când indexul de început este omis, Python folosește implicit începutul secvenței (index 0).
: (A doua două puncte): Aceste două puncte indică sfârșitul feliei. Când indexul de oprire este omis, Python folosește implicit sfârșitul secvenței, incluzând efectiv toate elementele până la sfârșit.
-1 (Valoarea pasului): Valoarea pasului determină direcția și intervalul traversării. Un pas de -1 îi spune lui Python să se deplaseze înapoi prin secvență, câte un element pe rând.
Prin combinarea acestora, [::-1] înseamnă efectiv: "Începeți de la început, mergeți la sfârșit și luați fiecare element în ordine inversă."
Step-by-Step of [::-1]
The general syntax for Python slicing is string[start:stop:step]. When you use [::-1], each part of the syntax is interpreted as follows:
: (First Colon): This colon indicates the start of the slice. When the start index is omitted, Python defaults to the beginning of the sequence (index 0).
: (Second Colon): This colon indicates the end of the slice. When the stop index is omitted, Python defaults to the end of the sequence, effectively including all elements until the end.
-1 (Step Value): The step value determines the direction and interval of the traversal. A step of -1 tells Python to move backward through the sequence, one element at a time.
By combining these, [::-1] effectively means: "Start at the beginning, go to the end, and take every element in reverse order."
nume = ["Cristina", "Andrei", "Mihai", "Vasile", "Alexandru", "Elena", "Ioana", "Costel", "Eugenia"]
listă_inversată = nume[::-1]
print(listă_inversată) ==> ['Eugenia', 'Costel', 'Ioana', 'Elena', 'Alexandru', 'Vasile', 'Mihai', 'Andrei', 'Cristina']

Pentru tuplu, înlocuiți [] din lista de mai sus cu () și aplicați [::1]
For tuple replace [] from above list with () and apply [::1].

# aplică felierea și inversarea unui subșir.
șirul_meu = "Python este grozav"

# Obține un subșir de la indexul 7 la 10
subșir = șirul_meu[7:11]
print(subșir)  ==> este

# Inversează subșirul
subșir_inversat = subșir[::-1]
print(subșir_inversat)  ==> etse

funcția reversed()

Funcția încorporată reversed() din Python returnează un obiect iterator inversat, oferind o soluție eficientă din punctul de vedere al memoriei, care generează elementele în ordine inversă pe măsură ce este nevoie de ele, fără a crea o copie în memorie. Aceasta nu modifică structura de date originală. Este, în general, metoda cea mai Pythonică și eficientă.

The built-in reversed() function in Python returns un obiect iterator inversat, providing a memory-efficient object that generates reversed items one-by-one as it needed, without making a copy in memory. It does not alter the original data structure. Is generally the most Pythonic and efficient method.

şir1 = "salut"
for caracter in reversed(şir1):
    print(caracter, end=" ")   ==> t u l a s

Inversarea șirurilor într-o buclă for - Reversing strings within a for loop

Utilizarea unei bucle oferă o înțelegere mai explicită a procesului de inversare.
Using a loop provides a more explicit understanding of the reversal process.

for loop și concatenare de șiruri de caractere iterează prin fiecare caracter al șirului original și îl adaugă înaintea unui nou șir rezultat. Aceasta construiește efectiv șirul inversat caracter cu caracter (în acest caz, literă cu literă).

for loop and string concatenation iterates through each character of the original string and prepends it to a new result string. This effectively builds the reversed string character by character (in this case letter by letter). 

şir = "Python"
for i in range(len(şir) - 1, -1, -1):
    print(şir[i], end=" ") ==> n o h t y P

def șiruri_invers_buclă(text):
    text_inversat = ""
    for caracter in text:
        text_inversat = caracter + text_inversat
    return text_inversat

# utilizare într-o buclă
șiruri_de_inversat = ["Cristina", "Andrei", "Mihai", "Vasile", "Alexandru"]
șiruri_inversate = []
for șir in șiruri_de_inversat:
    șiruri_inversate.append(șiruri_invers_buclă(șir))
print(șiruri_inversate) ==> ['anitsirC', 'ierdnA', 'iahiM', 'elisaV', 'urdnaxelA']
reversed() și join() în cadrul unei bucle:
În Python, funcția reversed(), metoda .join() și buclele for sunt adesea combinate pentru a manipula, inversa și reconstrui șiruri de caractere sau secvențe.
Funcția reversed() primește o secvență (cum ar fi un șir de caractere, o listă sau un tuplu) și returnează un iterator care furnizează caractere în ordine inversă. Metoda "".join() concatenează apoi eficient aceste caractere într-un șir nou. Acest lucru este în general mai eficient decât concatenarea repetată a șirurilor, în special pentru șirurile mai lungi, datorită imutabilității șirurilor în Python.
reversed() and join() within a loop:
In Python, reversed(), .join(), and for loops are frequently combined to manipulate, reverse, and rebuild strings or sequences.
The reversed() function takes a sequence (like a string, list, or tuple) and returns an iterator that provides characters in reverse order. The "".join() method then efficiently concatenates these characters into a new string. This is generally more efficient than repeated string concatenation, especially for longer strings, due to Python's string immutability.
def șiruri_inversate_join(text):
    return "".join(reversed(text))

# utilizare într-o buclă
șiruri_de_inversat = ["pară", "cireșă", "caisă", "smochină"]
șiruri_inversate = []
for șir in șiruri_de_inversat:
    șiruri_inversate.append(șiruri_inversate_join(șir))
print(șiruri_inversate) ==> ['ărap', 'ășeric', 'ăsiac', 'ănihcoms']

Inversarea șirurilor într-o buclă while - Reversing strings in a while loop

while loop iterează prin șir de caractere de la ultimul caracter la primul, adăugând fiecare caracter la un șir nou, gol.

while loop iterate through the string from the last character to the first, appending each character to a new, empty string.

def șir_inversat_cu_buclă_while(șir):
    """
    Inversează un șir dat folosind o buclă while.

    Argumente:
    șir (str): Șirul care va fi inversat.

    Returnează:
    str: Șirul inversat.
    """

    șir_inversat = ""
    indice = len(șir) - 1 # Începe de la ultimul indice

    while indice >= 0:
        șir_inversat += șir[indice]
        indice -= 1 # Se mută la caracterul anterior

    return șir_inversat

culori =  ['verde', 'galben', 'roșu']
culoare = 'verde'

culori_inversate = șir_inversat_cu_buclă_while(culori)
print(f"Culori inversate {culori_inversate}")

culoare_inversată = șir_inversat_cu_buclă_while(culoare)
print(f"Culoare inversată {culoare_inversată}")
Explicație:
șir_inversat = "": Un șir gol este inițializat pentru a stoca caracterele în ordine inversă.
indice = len(șir) - 1: O variabilă indice este setată la ultimul indice al șirului. Deoarece indexarea șirurilor este bazată pe zero, ultimul indice este - 1.
while indice >= 0:: Bucla while continuă atâta timp cât indicele este mai mare sau egal cu 0, asigurându-se că toate caracterele de la ultimul până la primul sunt procesate.
șir_inversat += șir[indice]: În fiecare iterație, caracterul de la indicele curent al șirului este adăugat la șir_inversat.
indice -= 1: Indexul este decrementat cu 1 pentru a trece la caracterul anterior din șir pentru următoarea iterație.
return șir_inversat: Odată ce bucla se termină (când indicele devine mai mic decât 0), este returnat șirul complet inversat.
Explanation:
reversed_str = "": An empty string is initialized to store the characters in reverse order.
index = len(input_string) - 1: An index variable is set to the last index of the input_string. Since string indexing is zero-based, the last index is length - 1.
while index >= 0:: The while loop continues as long as the index is greater than or equal to 0, ensuring that all characters from the last to the first are processed.
reversed_str += input_string[index]: In each iteration, the character at the current index of the input_string is appended to reversed_str.
index -= 1: The index is decremented by 1 to move to the previous character in the input_string for the next iteration.
return reversed_str: Once the loop finishes (when index becomes less than 0), the fully reversed string is returned.

Inversarea șirurilor cu recursiune - Reversing strings with recursion

Inversarea unui șir de caractere folosind recursivitatea este definită de un caz de bază și un caz recursiv.

Recursivitatea este proprietatea unui concept, precum o funcție sau o noțiune, de a se defini prin ea însuși, prin autoapelare sau prin referirea la o instanță mai simplă a aceluiași concept. Este utilizată în matematică și informatică pentru a rezolva probleme complexe, descompunându-le în subprobleme identice, care se reduc treptat la cazuri de bază, simple și nedefinite recursiv.

Reversing a string using recursion is defined by a base case and a recursive case.

Recursion is the property of a concept—such as a function or an idea—to define itself through self-reference or by referring to a simpler instance of the same concept. It is used in mathematics and computer science to solve complex problems by breaking them down into identical subproblems that gradually reduce to simple base cases that are not defined recursively.

Caz de bază:
Cazul de bază pentru recursivitate este atunci când șirul de intrare este gol sau are lungimea unu. În aceste cazuri, șirul este deja inversat și nu este necesară nicio acțiune suplimentară. Funcția returnează pur și simplu șirul așa cum este.
Caz recursiv:
Când șirul nu este gol sau un singur caracter, funcția efectuează următorii pași:
Se apelează recursiv cu un subșir (adică, șir[1:]) care exclude primul caracter al șirului original.
Apoi concatenează primul caracter al șirului original (șir[0]) la sfârșitul rezultatului returnat de apelul recursiv.
Acest proces construiește efectiv șirul inversat prin preluarea repetată a primului caracter și plasarea acestuia la sfârșitul versiunii inversate a subșirului rămas, până când se atinge cazul de bază și șirul este complet inversat.
Base Case:
The base case for the recursion is when the input string is empty or has a length of one. In these instances, the string is already reversed, and no further action is required. The function simply returns the string as is.
Recursive Case:
When the string is not empty or a single character, the function performs the following steps:
It recursively calls itself with a substring (i.e., string[1:]) that excludes the first character of the original string.
It then concatenates the first character of the original string (string[0]) to the end of the result returned by the recursive call.
This process effectively builds the reversed string by repeatedly taking the first character and placing it at the end of the reversed version of the remaining substring, until the base case is reached and the string is fully reversed.
def șir_inversat_recursiv(șir):
# dacă șirul este gol sau are un caracter, îl returnează așa cum este
    if len(șir) <= 1:
        return(șir)
    else:
        # Caz recursiv:
        # Apelați funcția cu subșirul de la al doilea caracter încolo
        # Adăugați primul caracter al șirului original la rezultat
        return șir_inversat_recursiv(șir[1:]) + șir[0]
    
# Exemplu de utilizare
culoare = "galben"
șir_inversat_culoare = șir_inversat_recursiv(culoare)
print(f"Șir original: {culoare}")  ==> Șir original: galben
print(f"Șir inversat: {șir_inversat_culoare}")  ==> Șir inversat: neblag

fruct = "gutuie"
șir_inversat_fruct = șir_inversat_recursiv(fruct)
print(f"Șir original: {fruct}")  ==> Șir original: gutuie
print(f"Șir inversat: {șir_inversat_fruct}")  ==> Șir inversat: eiutug

Şiruri inversate cu functools.reduce() - Reverse strings with functools.reduce()

Pentru a inversa un șir de caractere folosind functools.reduce(), este necesară o funcție care primește două argumente (rezultatul acumulat și caracterul curent) și concatenează caracterul curent cu începutul rezultatului acumulat.

To reverse a string using functools.reduce(), a function is needed that takes two arguments (the accumulated result and the current character) and concatenates the current character to the beginning of the accumulated result.

from functools import reduce
def șir_inversat_prin_reducere(șir):
    return reduce(lambda a, b: b + a, șir, "")

șir_inversat_prin_reducere("Salut, lume!") ==> '!emul ,tulaS'


șir_original = "Salut, lume!"

# Funcția lambda concatenează caracterul curent (y) cu
# șirul acumulat (x) în ordine inversă.
șir_inversat = reduce(lambda x, y: y + x, șir_original)

print(f"Șir original: {șir_original}")  ==> Șir original: Salut, lume!
print(f"Șir inversat: {șir_inversat}")  ==> Șir inversat: !emul ,tulaS
Explicație
import functools: Această linie importă funcția reduce.
reduce(lambda x, y: y + x, original_string):
Funcția lambda definește o funcție simplă, în linie, care primește două argumente, x (acumulator) și y (caracterul curent) și returnează y + x.
reduce iterează prin șirul original.
Inițial, x (acumulatorul) este primul caracter ('S') și y este al doilea caracter ('a'). Funcția returnează 'a' + 'S' ==> 'aS'.
În pasul următor, x devine 'aS' și y este următorul caracter ('l'). Funcția returnează 'l' + 'aS' ==> 'laS'.
Acest proces continuă până când toate caracterele sunt procesate, rezultând șirul complet inversat.
Explanation
import functools: This line imports the reduce function.
reduce(lambda x, y: y + x, original_string):
The lambda function defines a simple, inline function that takes two arguments, x (accumulator) and y (current character), and returns y + x.
reduce iterates through original string.
Initially, x (the accumulator) is the first character ('H') and y is the second character ('e'). The function returns 'e' + 'H' ==> 'eH'.
In the next step, x becomes 'eH' and y is the next character ('l'). The function returns 'l' + 'eH' ==> 'leH'.
This process continues until all characters are processed, resulting in the fully reversed string.

Pentru mai multe modalități de utilizare a metodei reduce() în Python, consultați documentația Python. Rețineți că pentru inversarea standard a șirurilor de caractere, metoda de feliere (s[::-1]) sau "".join(reversed(s)) este în general considerată mai idiomatică și mai eficientă.

For more ways to use reduce() in Python, refer to the Python documentation. Note that for standard string reversal, the slicing method (s[::-1]) or "".join(reversed(s)) is generally considered more idiomatic and efficient.

Pentru a sorta un șir de caractere în ordine alfabetică inversă (descrescătoare) în Python, puteți utiliza funcția sorted() cu argumentul reverse=True și apoi puteți uni caracterele înapoi într-un șir de caractere.

To sort a string in reverse alphabetical (descending) order in Python, you can use the sorted() function with the reverse=True argument and then join the characters back into a string.
