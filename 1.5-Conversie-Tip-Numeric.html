1.0 Tipuri numerice - Numeric Types

1.5 Conversie de tip numeric - Numeric type conversion

  • În acest capitol veți studia:
  • Conversie implicită

  • In this chapter you will study:
  • Implicit conversion

Python acceptă conversia între tipuri numerice, care poate fi făcută fie implicit de către interpretor, fie explicit de către programator.

Python supports converting between numeric types, which can be done either implicitly by the interpreter or explicitly by the programmer.

Conversie implicită (coerciție)-Implicit conversion (coercion)

Conversia implicită, cunoscută și sub denumirea de tip coerciție, se referă la conversia automată a unui tip de date în altul de către interpretorul Python fără instrucțiuni explicite din partea programatorului. Acest lucru se întâmplă de obicei în situațiile în care este sigur să se facă acest lucru fără pierderi de date sau precizie.

Cum funcționează conversia implicită:

Python urmează o ierarhie de tipuri de date pentru conversia implicită, promovând în general un tip de date "inferior" la unul "superior" pentru a preveni pierderea datelor. De exemplu, atunci când un număr întreg și un număr cu virgulă mobilă sunt implicate într-o operație aritmetică, numărul întreg este convertit implicit într-un număr cu virgulă mobilă înainte de efectuarea operației, iar rezultatul va fi un număr cu virgulă mobilă.

Implicit conversion, also known as type coercion, refers to the automatic conversion of one data type to another by the Python interpreter without explicit instruction from the programmer. This typically occurs in situations where it is safe to do so without loss of data or precision.

How Implicit Conversion Works:

Python follows a hierarchy of data types for implicit conversion, generally promoting a "lower" data type to a "higher" one to prevent data loss. For example, when an integer and a float are involved in an arithmetic operation, the integer is implicitly converted to a float before the operation is performed, and the result will be a float.

# Operații numerice.
x1 = 7    # int
y1 = 4.5  # float 
rezultat_adunare = x1 + y1 # x este implicit convertit în float 
print(rezultat_adunare, "/", type(rezultat_adunare)) ==> 11.5 / <class 'float'>

x2 = 9  # int
y2 = 4  # int
rezultat_împărțire = x2 / y2
print(rezultat_împărțire, "/", type(rezultat_împărțire)) ==> 2.25 / <class 'float'>

x3 = 8  # int
y3 = 4  # int
rezultat_împărțire2 = x3 / y3
print(rezultat_împărțire2, "/", type(rezultat_împărțire2)) ==> 2.0 / <class 'float'>

Operații booleene și cu numere întregi: True este tratat ca 1, iar Fals ca 0 în operațiile numerice.

Boolean and Integer Operations: True is treated as 1 and False as 0 in numeric operations.

este_activ = True
număr = 10
total = este_activ + număr
print(total)
print(type(total)) ==> 11 / <class 'int'>

Nu se întâmplă conversia implicită:
Conversia implicită nu are loc atunci când ar duce la pierderea datelor sau când tipurile sunt fundamental incompatibile. De exemplu, Python nu va converti implicit un număr într-un șir de caractere pentru concatenare.

Implicit Conversion Does Not Happen:
Implicit conversion does not occur when it would lead to data loss or when the types are fundamentally incompatible. For instance, Python will not implicitly convert a number to a string for concatenation.

text = "Adună cu : "
număr = 42
try:
    adunate = text + număr
    print(adumate)
except TypeError:
    print('Nu se poate concatena "şir" cu "număr"') ==> TypeError

Concluzii:
Conversia implicită simplifică codul prin gestionarea automată a ajustărilor de tip în scenarii compatibile. Prioritizează integritatea datelor, convertind la un tip de date „superior” pentru a evita pierderile. Nu se efectuează pentru tipuri incompatibile, unde este necesară o conversie explicită.

Conclusions:
Implicit conversion simplifies code by automatically handling type adjustments in compatible scenarios. It prioritizes data integrity, converting to a "higher" data type to avoid loss. It is not performed for incompatible types, where explicit conversion is necessary.

Conversie explicită (transformare de tip) - Explicit conversion (type casting)

Conversia explicită de tip, cunoscută și sub denumirea de tipcast, în Python implică convertirea unei valori dintr-un tip de date în altul prin utilizarea explicită a funcțiilor de conversie de tip încorporate. Aceasta se face atunci când trebuie să vă asigurați că o valoare este de un anumit tip pentru o operație sau pentru a preveni un comportament neașteptat.

Explicit type conversion, also known as type casting, in Python involves converting a value from one data type to another by explicitly using built-in type conversion functions. This is done when you need to ensure a value is of a specific type for an operation or to prevent unexpected behavior.

int(x): Convertește x într-un număr întreg, trunchiind orice parte zecimală.
float(x): Convertește x într-un număr cu virgulă.
boo(x): Convertește x într-o valoare booleană.
complex(x): Convertește x într-un număr complex cu partea imaginară zero.

int(x): Converts x to an integer, truncating any decimal part.
float(x): Converts x to a float.
bool(x): Converts x to a boolean value.
complex(x): Converts x to a complex number with an imaginary part of zero. 

# int(): Convertește o valoare într-un număr întreg.
şir = "123"
conversie_la_întreg = int(şir) # Convertește șirul de caractere "123" în întreg 123
print(conversie_la_întreg, "/", type(conversie_la_întreg)) ==> 123 / <class 'int'>
număr_zecimal = 3.14
număr_trunchiat = int(număr_zecimal) # Convertește un număr cu virgulă mobilă 3.14 în întreg 3 (trunchiază partea zecimală)
print(număr_trunchiat, "/", type(număr_trunchiat)) ==> 3 / <class 'int'>

# float(): Convertește o valoare într-un număr cu virgulă mobilă.
şir2 = "3.141593"
conversie_la_număr_zecimal = float(şir2) # Convertește șirul de caractere "3.141593" în float 3.141593
print(conversie_la_număr_zecimal, "/", type(conversie_la_număr_zecimal)) ==> 3.141593 / <class 'float'>
număr_întreg = 10
număr_întreg_la_zecimal = float(număr_întreg) # Convertește întregul 10 în float 10.0
print(număr_întreg_la_zecimal, "/", type(număr_întreg_la_zecimal)) ==> 10.0 / <class 'float'>

# bool(): Convertește o valoare într-o valoare booleană.
zero = 0
boolean1 = bool(0) # Convertește întregul 0 în Fals
print(boolean1, "/", type(boolean1)) ==> False / <class 'bool'>
număr_întreg = 5
boolean2 = bool(număr_întreg) # Convertește întregul întreg 5, diferit de zero, în True
print(boolean2, "/", type(boolean2)) ==> True / <class 'bool'>
șir_gol = ""
boolean3 = bool(șir_gol) # Convertește șirul gol în Fals
print(boolean3, "/", type(boolean3)) ==> False / <class 'bool'>
şir = "Vă salut"
boolean4 = bool(şir) # Convertește șirul care nu este gol în True
print(boolean4, "/", type(boolean4)) ==> True / <class 'bool'>
Puncte cheie:
Conversia explicită oferă control asupra tipurilor de date, asigurând compatibilitatea operațiilor.
Pierderea de date poate apărea în timpul conversiilor explicite (de exemplu, conversia unui număr cu float într-un număr întreg trunchiază partea zecimală).
Este esențial să vă asigurați că valoarea poate fi convertită în mod semnificativ la tipul țintă pentru a evita ValueError sau alte erori. De exemplu, int("Vă salut") ar genera o eroare.
Key Points:
Explicit casting provides control over data types, ensuring compatibility for operations.
Data loss can occur during explicit conversions (e.g., converting a float to an int truncates the decimal part).
It is crucial to ensure the value can be meaningfully converted to the target type to avoid ValueError or other errors. For example, int("hello") would raise an error.

Pentru a combina un șir de caractere și un număr întreg, trebuie să convertiți explicit numărul întreg într-un șir de caractere folosind funcția str() sau să utilizați metode de formatare a șirurilor de caractere.

To combine a string and a integer you must explicitly convert the integer to a string using the str() function or use string formatting methods.

# str() function (recomandat pentru concatenare simplă):
text = "Vă salut spion faimos făra doi de zero: "
număr = 7
result = text + str(număr)
print(result)

# f-strings (Python 3.6+): Aceasta este, în general, metoda cea mai lizibilă
text = "Vă salut spion faimos făra doi de zero: "
număr = 7
result = f"{text}{număr}"
print(result)

# metoda .format():
text = "Vă salut spion faimos făra doi de zero: "
număr = 7
result = "{}{}".format(text, număr)
print(result)
Rezultat pentru cele trei variante: Vă salut spion faimos făra doi de zero: 7

# try...except plus str() pentru Gestionarea erorilor
text = "Vă salut spion faimos făra doi de zero: "
număr = 7
try:
    adunate = text + str(număr)
    print(adunate)               ==> Vă salut spion faimos făra doi de zero: 7
except TypeError:
    print('Nu se poate concatena "şir" cu "număr"')

Conversia la un număr complex: - Converting to a complex number:

Un singur argument numeric (întreg sau număr cu virgulă): Argumentul devine partea reală, iar partea imaginară este setată la zero.

A single numeric argument (integer or float): The argument becomes the real part, and the imaginary part is set to zero.

număr_real = 5
complex_din_număr_întregi = complex(număr_real)
print(complex_din_număr_întregi) ==> (5+0j)

număr_zecimal = 2.04
complex_din_număr_zecimal = complex(număr_zecimal)
print(complex_din_număr_zecimal) ==> (2.04+0j)

Două argumente numerice (parte reală și imaginară) - Two numeric arguments (real and imaginary parts).

parte_reală = 3
parte_imaginară = 5
număr_complex = complex(parte_reală, parte_imaginară)
print(număr_complex) ==> (3+5j)

Conversia unui număr complex în alte tipuri (cu potențială pierdere de date). Deși puteți converti alte tipuri de numere în numere complexe, conversia unui număr complex într-un tip necomplex implică adesea eliminarea părții imaginare sau convertirea acesteia într-o reprezentare sub formă de șir de caractere.

Converting from a complex number to other types (with potential data loss) While you can convert other types to complex numbers, converting a complex number to a non-complex type often involves discarding the imaginary part or converting it to a string representation.

# Către un șir de caractere: Folosiți funcția str().
număr_complex = 11 + 5j
complex_ca_șir = str(număr_complex)
print(complex_ca_șir, "/", type(complex_ca_șir)) ==> (11+5j) / <class 'str'>

Către un număr întreg sau un număr cu număr float: Acest lucru nu este, în general, posibil direct folosind int() sau float() pe numărul complex în sine, deoarece ar duce la o eroare TypeError din cauza componentei imaginare. Trebuie să extrageți mai întâi partea reală.

To an integer or float:This is generally not directly possible using int() or float() on the complex number itself, as it would lead to a TypeError due to the imaginary component. You must extract the real part first.

număr_complex = 11 + 5j
parte_reală = int(număr_complex.real)
parte_imaginară = int(număr_complex.imag)
print(parte_reală) ==> 11
print(parte_imaginară) == 5

parte_reală_ca_zecimală = float(număr_complex.real)
parte_imaginarăca_zecimală = float(număr_complex.imag)
print(parte_reală_ca_zecimală) ==> 11.0
print(parte_imaginarăca_zecimală) ==> 5.0
