Ranges

help(range) ==> Help on class range in module builtins:

  • Tipul range reprezintă o secvență imuabilă de numere și este utilizat frecvent pentru a repeta o acțiune de un anumit număr de ori în cadrul instrucțiunilor repetitive de tip for.
  • Argumentele funcție Range trebuie să fie numere întregi.
  • Range nu stochează toate numerele în memorie simultan, ci le calculează la cerere, ceea ce îl face foarte eficient din punctul de vedere al utilizării memoriei, indiferent de dimensiunea intervalului.
  • The range type represents an immutable sequence of numbers and is commonly used for looping a specific number of times in for loops.
  • The arguments of the Range fuction must be integers.
  • Range does not stor all numbers in memory at once, it computes them lazily, making it very memory-efficient regardless of the size of the range.
Sintaxa funcției este:
range(stop, /...)
range(start, stop, step, /...)

Sintaxa range(start, stop, step, /...) indică faptul că toți parametrii sunt exclusiv poziționali (fapt semnalat prin simbolul /), ceea ce înseamnă că nu pot fi transmiși ca argumente cu nume (de exemplu, range(start=0, stop=10) va genera o eroare TypeError).

The syntax range(start, stop, step, /...), indicates that all parameters are positional-only (signaled by the / symbol), meaning they cannot be passed as keyword arguments (e.g., range(start=0, stop=10) will raise a TypeError)

Reguli și comportamente esențiale
Valoarea de oprire nu este inclusă niciodată în secvență.
range() acceptă doar numere întregi.
Valoarea pasului nu poate fi 0. Setarea step=0 va genera imediat o eroare de tip ValueError.
Poți număra invers specificând un pas negativ. Valoarea de început trebuie să fie mai mare decât cea de oprire.
Key Rules & Behaviors
The stop value is never included in the sequence.
range() only accepts integers.
The step value cannot be 0. Setting step=0 will instantly raise a ValueError.
You can count backward by providing a negative step. The start must be greater than the stop.

Navighează cu pas negativ - Navigate With Negative Step

start trebuie să fie mai mare decât stop: dacă valoarea de start este mai mică sau egală cu cea de stop, Python va returna o secvență goală

Valoarea de oprire este exclusivă: secvența se va opri înainte de a atinge valoarea de oprire. Dacă doriți să includeți un anumit număr final, valoarea de oprire trebuie să fie cu un pas dincolo de acel număr.

start must be greater than stop: If start's value is less than or equal to stop, Python will return an empty sequence.

stop is exclusive: The sequence will stop before it reaches the stop value. If you want to include a specific final number, your stop value must be one step beyond that number.

# Secvența se oprește la 1 deoarece 0 este exclus
for i in range(5, 0, -1):
    print(i, end=", ") ==> 5, 4, 3, 2, 1,

# Sărituri peste numere (pas de -2)
for i in range(10, 0, -2):
    print(i, end=", ")  ==> 10, 8, 6, 4, 2,

# Numărătoare inversă până la 0 (inclusiv 0)
for i in range(5, -1, -1):
    print(i, end=", ")    ==> 5, 4, 3, 2, 1, 0,

# Alternativă, Utilizarea funcției reversed()
for i in reversed(range(0, 6)):
    print(i, end=", ")     ==> 5, 4, 3, 2, 1, 0,

# Parcurgerea inversă a indicilor unei liste
fructe = ["mere", "prune", "gutui"]

# Începe de la ultimul indice și oprește-te înainte de -1 (ceea ce include și 0)
for i in range(len(fructe) - 1, -1, -1):
    print(f"Indice {i}: {fructe[i]}")

==> Indice 2: gutui
Indice 1: prune
Indice 0: mere

Repetă o operație folosind range() - Repeat an operation with range()

# Va repeta codul indentat exact de 2 ori

for _ in range(3):
    print("Salut, salut, salut")
    print("Pe curand!")

# Rezultat
Salut, salut, salut
Pe curand!
Salut, salut, salut
Pe curand!

Sublinierea (_): Atunci când dorești doar să repeți o operație și nu ai nevoie efectiv să folosești numărul repetiției în interiorul buclei, se recomandă utilizarea _ ca nume al variabilei. Acest lucru îi transmite oricui citește codul tău faptul că variabila contor este ignorată în mod intenționat.

Limită exclusivă: Funcția range(n) din Python generează numere începând de la 0 și mergând până la n (fără a-l include pe acesta). Astfel, range(2) generează valorile 0 și 1, ceea ce înseamnă, în total, exact două iterații.

The Underscore (_): When you just want to repeat an operation and don't actually need to use the repetition number inside your loop, it is recomanded to use _ as your variable name. This tells anyone reading your code that the counter variable is intentionally being ignored.

Exclusive Boundary: Python's range(n) generates numbers starting from 0 and goes up to, but does not include, n. So, range(2) generates 0, 1 which still equals exactly 2 total iterations.

If your operation relies on knowing which repetition you are currently on, replace the underscore with a variable name like "i" or "appear".

Aceasta buclă exterioară controlează rândurile tabelului.

A doua buclă (for produs in range(număr, număr * 8, număr):)
Aceasta este bucla interioară care generează numerele de pe fiecare rând.
start = număr: Începe exact cu valoarea rândului curent.
stop = număr * 8: Se oprește înainte de acest produs (deci se va opri la număr * 7).
pas = număr: Sare din număr în număr (adică adaugă valoarea lui număr la fiecare pas, generând multiplii acestuia).
Afișarea și formatarea (print(...))

end="" oprește comportamentul implicit al funcției print de a trece la un rând nou, forțând numerele din bucla interioară să fie afișate pe aceeași linie.
print(): Este plasat în bucla exterioară, imediat după ce se termină bucla interioară. Nu are niciun text, având doar rolul de a introduce un linie nouă (Enter) înainte de a trece la următorul rând.
First loop (for număr in range(1, 5):)
This is the outer loop that controls the table rows.
The range(1, 5) function generates numbers from 1 to 4 (the upper limit, 5, is excluded).
Consequently, the code will run 4 times, with număr taking the values ​​1, 2, 3, and 4 in turn.
Second loop (for produs in range(număr, număr * 8, număr):)
This is the inner loop that generates the numbers in each row.
start = număr: Starts exactly at the value of the current row.
stop = număr * 8: Stops before this product (so it stops at număr * 7).
step = număr: Steps by the value of număr (i.e., adds the value of număr at each step, generating its multiples).
Display and formatting (print(...))
f"{produs: >4d}" formats the number as an integer (d) and reserves a fixed space of 4 characters, right-aligned (>4). This ensures that the numbers align perfectly in columns, even if they have one or two digits.
end="" stops the print function's default behavior of moving to a new line, forcing the numbers from the inner loop to be displayed on the same line.
print(): Placed in the outer loop, immediately after the inner loop finishes. It contains no text, serving only to insert a new line (Enter) before moving to the next row.

Pentru a efectua o iterație paralelă asupra mai multor secvențe folosind un indice și funcția range(), poți determina lungimea celei mai scurte secvențe, genera un interval de indici și accesa manual elementele.

To perform parallel iteration across multiple sequences using an index and the range() function, you can determine the length of your shortest sequence, generate a range of indices, and look up elements manually.

# Definește-ți secvențele paralele
fructe = ["mere", "pere", "gutui", "caise"]
costuri = [12, 24, 17]  # Listă mai scurtă

# Determină lungimea minimă pentru a evita o eroare de tip IndexError.
lungime_minimă = min(len(fructe), len(costuri))

# Parcurge intervalul de indici
for i in range(lungime_minimă):
    # Accesează elementele simultan folosind indicele.
    fruct = fructe[i]
    cost = costuri[i]
    
    print(f"{fruct} costă {cost} lei")
==> mere costă 12 lei
pere costă 24 lei
gutui costă 17 lei
Aspecte importante
IndexError: Dacă nu utilizezi min(len(A), len(B)), la executarea codului va apărea o eroare IndexError în cazul în care listele nu au aceeași lungime.
Eficiență: Documentația Python clasifică, în general, gestionarea manuală a indicilor la parcurgerea secvențelor drept un anti-tipar.
Important Considerations
IndexError: If you do not use min(len(A), len(B)), when you run the code the result is IndexError if the lists do not have the same length.
Efficiency: Python documentation generally classifies manual index tracking as an anti-pattern when reading sequences.

Pentru a itera până la epuizarea celei mai lungi liste folosind un indice și funcția range(), trebuie să utilizezi max(len(...)) în loc de min(). Deoarece listele mai scurte vor rămâne fără elemente înainte ca bucla să se încheie, trebuie, de asemenea, să adaugi o verificare condițională (sau un bloc try/except) pentru a gestiona elementele lipsă și a furniza o valoare implicită de rezervă.

To iterate until the longest list is exhausted using an index and range(), you must use max(len(...)) instead of min(). Because the shorter lists will run out of items before the loop finishes, you must also add a conditional check (or a try/except block) to handle the missing elements and provide a default fallback value.

    print(f"{fruct}: {cost}")

Pentru a adăuga dinamic valori de completare astfel încât listele să aibă aceeași lungime înainte de parcurgere, poți calcula diferența de lungime și extinde listele mai scurte folosind metoda extend() combinată cu multiplicarea listelor.

Astfel, te asiguri că fiecare listă ajunge la lungimea celei mai lungi dintre ele, permițându-ți să utilizezi o buclă standard, bazată pe indici, fără a avea nevoie de instrucțiuni condiționale (if) sau blocuri try/except în corpul buclei.

To dynamically append placeholder values so your lists are the same length before looping, you can calculate the length difference and extend the shorter lists using the extend() method combined with list multiplication.

This ensures every list matches the length of the longest one, allowing you to use a clean, standard index loop without any if statements or try/except blocks inside the loop body. 

fructe = ["mere", "pere", "gutui", "caise"]
costuri = [12, 24]
umple_valoarea = "N/A" # Valoarea de rezervă pentru elementele lipsă

# Găsește lungimea maximă
max_lungime = max(len(fructe), len(costuri))
# Completează dinamic listele mai scurte pentru a corespunde lungimii maxime
fructe.extend([umple_valoarea] * (max_lungime - len(fructe)))
costuri.extend([umple_valoarea] * (max_lungime - len(costuri)))

# Buclă de indexare curată și sigură
for i in range(max_lungime):
    fruct = fructe[i]
    cost = costuri[i]
    
    print(f"{fruct}: {cost}")
==> mere: 12
pere: 24
gutui: N/A
caise: N/A

[fill_value] * 2 creează o listă de forma ['N/A', 'N/A']. Dacă o listă are deja lungimea maximă, expresia max_length - len(list) are valoarea 0, rezultând o listă goală [ ].

Apelarea metodei .extend([ ]) cu o listă goală nu produce niciun efect, fiind astfel complet sigur să o aplici tuturor listelor tale fără a verifica în prealabil care dintre ele este mai scurtă.

[fill_value] * 2 creates a list of ['N/A', 'N/A']. If a list is already the longest, max_length - len(list) evaluates to 0, producing an empty list [ ].

Calling .extend([ ]) with an empty list does absolutely nothing, making it completely safe to run on all of your lists without checking which one is shorter first.

Accesarea elementelor - Accessing the items

În Python, funcția range() returnează o secvență de numere imuabilă. Deoarece se comportă ca o secvență (similar cu un tuplu sau o listă), aceasta suportă operații comune specifice secvențelor – precum indexarea, felierea, despachetarea și verificarea apartenenței – fără a fi necesară conversia prealabilă într-o listă or tuplu.

In Python, the range() function returns an immutable sequence of numbers. Because it behaves like a sequence (similar to a tuple or list), it supports common sequence operations like indexing, slicing, unpacking, and membership testing without converting it into a list or tuple first.

Numărul de elemente dintr-un interval - Number of elements in a range

Cea mai eficientă metodă este utilizarea funcției încorporate len().
The most efficient way is to use the built-in len() function.

# Formă cu un singur parametru: range(stop) -> începe de la 0, numără până la (dar fără a include) 10
my_range = range(10)
print(len(my_range))  ==> 10

# Formă cu doi parametri: range(start, stop) -> de la 5 la 14
my_range = range(5, 15)
print(len(my_range))  ==> 10

# Formă cu trei parametri: range(start, stop, step)
my_range = range(5, 15, 2)
print(len(my_range))  ==> 5

Reverse a Range

Cele mai comune două modalități de a inversa un interval în Python sunt utilizarea funcției încorporate reversed() sau aplicarea unui pas negativ în cadrul funcției range().

The two most common ways to reverse a range in Python are using the built-in reversed() function or applying a negative step within the range() function itself.

# Utilizarea funcției reversed() (recomandat pentru lizibilitate)
#pentru a parcurge o buclă inversă
for i in reversed(range(1, 6)): 
    print(i, end=", ") ==> 5, 4, 3, 2, 1, 

# Pentru a materializa într-o listă
listă_inversată = list(reversed(range(1, 6)))
print(listă_inversată) ==>  [5, 4, 3, 2, 1]

# interval(start, stop, step) -> numără invers de la 5 la 1
for i in range(5, 0, -1):
    print(i, end=", ")
==> 5, 4, 3, 2, 1,
